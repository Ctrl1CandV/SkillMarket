# 三层分工

先问：**这张图以后还要不要改，内容是否必须精确**。要反复改、要准确数值或要能交互，直接写 HTML/CSS/SVG/TikZ/PPT 原生形状；可接受栅格成品时，再选本机或订阅。

## 三层

| 层 | 用什么 | 适合 | 边界与成本 |
|---|---|---|---|
| 一 | 本机 **FLUX.2 klein 4B**，默认；显式增配 **Z-Image Turbo** | FLUX：极速素材、无字底图、风格探索、参考编辑。Z：短中文标题等低密度文字的可选尝试 | 本轮后续服务端中位数 FLUX 3.914 秒、Z 24.035 秒；都不能保证准确文字、数量或连线 |
| 二 | **官方 GPT 订阅原生生图** | 本机不适合，或需要较高完成度的论文/PPT 配图、页面视觉稿，且允许栅格成果与云上传 | 必须看图；可能漏字、加元素或服务拥堵。额度只报告当前账户观测，不给固定单价 |
| 三 | **HTML/CSS/SVG/TikZ/PPT 原生形状** | 内容精确、数字可靠、可编辑、交互与反复修改 | 有设计和审图成本；渲染几秒不等于整个设计过程几秒 |

模型不会因读到“写实”“网页”就自动切换或下载。`--model flux-klein-4b` 是默认；短标题可显式选 `--model z-image-turbo`。Z 只文生图，参考编辑仍用 FLUX。`z-image-turbo-fp8` 是另一个显式精度配置，不是失败后的自动降档。

## 第一层：硬件与复用

| 条件 | 建议 | 实测范围 |
|---|---|---|
| 16GB 显存＋32GB RAM | 可启用；先查空队列与其他 GPU 工作 | 本卡完整跑过两模型配对评测；整卡显存接近满载，整机 RAM 最大采样 16612 MiB，并非最低要求 |
| 真 12GB 卡 | 可知情试 FLUX，先 1024²；优先有 32GB RAM 的现有环境 | 16GB 卡 `reserve-vram 6.5` 下两尺寸各成功一次；**真 12GB 未验证** |
| 真 8GB 卡 | 默认订阅或原生绘制；接受排障成本时可选择实验性 FLUX 1024²，不承诺速度或稳定性 | `reserve-vram 10.5` 下 FLUX 两尺寸各成功一次、整卡最大约 7.2 GiB；**真 8GB 未验证**。Z FP8 探针达到 8863 MiB，不能据此推荐其 8GB 可用 |
| 更低显存、核显、无 N 卡 | 不默认部署本机，先选订阅或原生绘制 | 未验证 |

默认预留 2.5 GiB；6.5/10.5 是额外加 4/8 GiB 的卸载预算模拟，**不是物理显存硬隔离**。资源为约一秒采样的整卡/整机读数，含桌面和缓存，不能当模型最低门槛。系统 RAM 只有约 32GB 实机数据；没有验证 16GB RAM。五次模拟均为单次探针，不称稳定性测试。

先 `discover`，复用现有 ComfyUI、Python 和权重。FLUX 三组件 12.45 GB；Z 与它共享 BF16 文本编码器，只另加约 6.54 GB 扩散与 VAE，不把两个 VAE 混用。没有现成环境时，由用户选择先用订阅，或自己安装官方 ComfyUI；本技能不运行安装器、不升级原环境。详细做法见 [部署](deployment.md)。

## 内容契约与验收

把字符串、节点和边单列，目的是让要求清楚、结果可查，不是证明它是 GPT 表现改善的单一原因。历史订阅样例中有逐项通过的论文图、PPT 图与页面，也有错边、额外坐标刻度和翻页箭头；不能据少量成功宣称稳定全对。

上面表格里的 0/9、0/8 只是本机两种模型的结果，不能拿来说明 GPT 也画不对连线。2026-11-12 的一张 GPT 订阅图：组会用的 RAG 流程契约（11 个节点含副标题、10 条有向边、2 个阶段标签、脚注）全部正确，用时 98 秒。只有 1 张，不代表稳定。结构图在 GPT 和原生绘制之间怎么选，看的是以后要不要改、能不能接受栅格图，不看这组本机数据。

本轮正式云端脚本还完成了独立中文高密度界面验收：提交前冻结的 130 处指定可见文字/数值均匹配，七行交易、两行发票及关键分区完整，方向稿可用；但模型补了 18 处轴刻度/月标，并偏离卡高、行高与副表宽度要求，完整契约仍不通过。这不是与本机 28 处产品页的同题排名，也不是 Unicode、原生 CSS 或稳定性证明。

- 文字逐字核对，数值连同符号、千分位和单位一起核对；整字符串错字不得给全分。
- 独立节点与有向边另计；标签可读不代表框没有合并，箭头只能按准确端点和方向认。
- 本机素材可在用户同意后有限比较 2–4 个 seed；文字、计数、拓扑错误先改 brief 或换路径，不靠重抽补过。云端仍逐张授权、单次提交。
- 底图叠真实字体、局部修补、分层合成、整图重建都要与模型原图区分，见 [修补](raster-repair.md) 与 [内容前置](content-first.md)。

本机提示词不强制词数，也不声称正面描述必然优胜；26 张对照的结论已落实到 [任务写法](task-briefs.md#本机提示词怎么写)。云端是否可用由登录、能力、额度和真实回执共同判断，见 [可执行订阅入口](cloud-fallback.md)，不是无条件兜底。
