# 写作判断：立意、笔力与篇章

好文章不止于字句通顺。要让读者读完真有所得、真被打动，靠四个写作动作：**找准切口直接进场，挖出材料内部关系与真实摩擦，按篇幅配额把笔力压透主场景，按文体定准温度与事实边界**。

**事实、时态与边界底线**：
- 非虚构写作中，事实、数据、承诺与**时态进度（将要/正在/已经）**严格照材料守恒；关键资料缺失时直接询问、收窄主张或用 `〔待确认：……〕` 标出；无外部数据时靠真实机制与处境写实，不编造“第 12 页、47 个模块、20%”这类无来源随机整数。
- **区分两类叙事**：改写他人**非虚构真实经历**时，严格停在原稿已有的动作与观察，靠语序和留白出分量，绝不补造原稿没有的触感、气味或心理归因；**虚构故事创作或续写**则在设定世界内放开写场景温度、反差幽默与高潮张力，绝不写成 37°C 动作录像机或办事流程。
- 守边界体现在“只交代已知影响与下一步安排”，绝不在正文里写“因此这里不给原因判断以免误导”之类规则台词。

## 一、动笔前定两件事：文体温度与篇幅配额

1. **定文体温度**：报错与通知冷峻干脆；评论与评审锋利算账；讲稿与口播带讲台现场感；故事与情感留住烟火气与情绪涨落——绝不拿“极简冷淡白描”一刀切所有文体。
2. **定篇幅配额（反等权重流水账）**：全篇只挑 **1–2 处真正改变认识或情绪的主场景/主关节**，把**过半篇幅**砸进去写透（给足推导、对抗、感官或情绪蓄势）；其余过渡事件（赶路、寒暄、常规背景、例行手续）硬压成 **1–2 句快剪**，不给过场配独立对话与琐碎动作清单。

## 二、切口：第一段直接踩在支点上，绝不报幕

删掉换题目也能照搬的万能开场，也省去“先给结论：”“结论先说：”“先看一个具体的问题：”“先把账算清楚：”“我的意见是：”这类报幕冒号——直接把判断、事实或现场本身说出来：

| 写作类型 | 进场支点 |
| --- | --- |
| **说理与深度评论** | 直接亮出**反直觉的区分、真实矛盾，或决定成败的边界条件** |
| **教学与机制讲解** | 抛出读者**最容易卡住的具体问题或算例**，顺势引出概念 |
| **叙事与故事** | 落在**在场的动作、反常细节或带温度的现场感官**上 |
| **工作汇报与沟通** | 第一句直接写**要解决的事项、核心结论或待拍板的决定** |

## 三、写厚：挖内部关系、写真实摩擦，替代空洞清单

1. **有数据时算清反差（先核分母再落笔）**：算出倍数、占比或均值分摊时，写清分子分母各自指代谁并验算，把“对整体均值的分摊贡献”与“子集自身均值”分开算清。
2. **往前推一步因果与适用边界**：交代“少掉这一步会在哪里出事”，写清判断成立的前提与失效的临界点。
3. **提方案/对策时“写一条、配一坑”**：不列 5 条人人都知道的正确清单；挑最关键的 **2–3 条做法**，每条顺手写透“照着做最容易踩什么坑、改动边界划在哪里”，让方案长出真实摩擦力。
4. **篇幅与文体相称**：深度评论、教学推导与故事主场景写透；日常变更邮件与通知清爽够用即可停笔。

## 四、走势与时机：因果咬合，拒绝机械展板

- **以问带段，长短错落**：段与段靠“前一段留下什么新问题”自然推进，拆掉“四条原因 + 五条药方”的展板骨架；连贯的文章、讲稿、评审与汇报用自然段推进，不插 `**顺序与验收：**` `**代价与边界：**` 类加粗卡片；长推演句后配短句定音。
- **金句限流**：千字长文最多留 **1–2 处** 顺理成章的短句定音，其余段落平实落到后果、条件或下一问，防止每段结尾强行拍桌反转。
- **时机贴合阅读过程**：边看边操作的文档，前提条件必须写在动作前面；连续阅读或故事叙事则先用反常细节或冷热落差托住悬念与蓄势。

## 五、随任务选择操作

- **从零新写**：动笔前先打开 [四类文体的立意与展开范例](references/exemplars.md) 对照目标文体的温度、切口与主场压透示范 → 定温度与篇幅配额 → 沿因果推进写透核心场。
- **实质改稿**：先读 [实质改稿与文本诊断清单](references/revision-and-diagnosis.md) → 先保住原稿立得住的亮点与声音 → 抓最伤阅读的 1–2 个结构或内容病灶（含冷淡流水账、过场过肥、前提放反、方案无摩擦）→ 核对数值口径、时态与事实边界。
- **只作诊断（审校模式）**：先读 [实质改稿与文本诊断清单](references/revision-and-diagnosis.md) 第四节，按“初读印象 → 已立住的亮点 → 1–3 个核心病灶与位置 → 1 段改写样板（缺数据标 `〔待确认：……〕`）”简洁输出。

## 六、交稿前 3 秒扫三处“一票否决区”

1. **扫第一句**：确认零报幕冒号（“先给结论：”“先看一个具体的问题：”“先把账算清楚：”）与万能背景铺垫。
2. **扫骨架与笔力**：确认连贯文体零 `**粗体标签：**` 卡片，过渡段短促、主场景/核心关节占足篇幅，无段段甩金句表演。
3. **扫出口边界**：确认正文零规则台词、零“比草稿里那句……”元指代；新写与改稿**只输出可直接使用的成品正文**，从正文第一句起笔、最后一句结束（仅在用户明确要求审校或解释改动时例外）。
