# 修改中的依据与得失

适用于实质改写和重要取舍。简单修字句无须增加记录流程；以下区分用于判断，只有用户需要时才写成修改说明。

## 先辨认要保留的成就

原稿可能已经有准确的判断、有用的解释、独特的观察、合适的迟疑或有效的节奏。先辨认这些，才能判断“更顺”是否以丢失内容或声音为代价。审校也应指出成就，不能只寻找可删的东西。

保留范围由任务决定。若只润色，事实、立场、说话者身份及承诺强度应稳定；若用户要重构或改换立场，允许相应改变，同时保证事实与证据没有被悄悄改写。修正原稿事实错误时说明依据，不把忠实原文误用为保留错误。

## 对着问题选择改法

| 具体发现 | 可以尝试 | 需要一起观察的损失 |
| --- | --- | --- |
| 有结论，关键区别或理由没有展开 | 从材料中补出比较、条件或联系；资料不足时收窄主张 | 新展开是否抢走重点，推断是否被写成事实 |
| 内容有依据，读者仍难以接上 | 重新引入对象、补必要提示、换一个进入点 | 是否造成不必要的复述，提前消除了应保留的悬念 |
| 读到后来仍在同一处打转 | 合并重复、推进事件或认识，重分详略 | 是否删去提醒、累积情绪、声音或关系作用 |
| 措辞带入不合场景的确信或教导 | 调整语气、责任归属与预设 | 是否把明确判断改成含糊退让，削弱用户需要的力度 |
| 句子清楚，但词义、搭配或节奏不贴切 | 精确换词、调整句法与停顿，再放回段落读 | 是否改变对象、程度、观察位置或原有声线 |
| 提示层层叠加，或动词周围堆叠“进行、作出”等泛化表达，使动作与重点难以把握 | 尝试直接写清谁做什么，合并提示，再比较理解与语气 | 是否丢失必要导航、规范术语、正式程度或郑重意味 |
| 强调很多，后文却没有相称的区别、依据或展开 | 从材料中补出值得强调的内容，或减弱强调 | 是否削弱确有必要的警示、提醒、情绪力度或关系表达 |

同一种“不自然”可能来自不同问题。必要时先简记初读感受，再寻找文字与情境依据；全篇声音或节奏的判断可以来自分散位置。后续分析可以修正初读判断，也允许只记录尚难解释的不适，不急于替它发明成因。这类自评仍是当前模型的判断，不是独立读者已经验证的效果。

## 区分新增了什么

- **新增事实、经历、数据或承诺：**需要来源或明确创作授权。补造的细节不能冒充原作者经验。
- **根据已有材料形成的推断：**保留相应的不确定程度，考虑其他解释；重要推断在交付说明中标明依据或待确认处。
- **组织与表达变化：**虽然事实未变，重排、强调、隐喻与结尾仍可能改变关系和态度，须回到全文判断。

这些变化可以相互作用，不强行把收益精确分成“内容几分、表达几分”。展开已有材料之间的联系，本身也可能是写作改善；比较时说明多出来了什么、依据在哪里以及产生了何种可见变化，避免把整体收益全部归因于某一个表达操作。

## 比较与停止

保留、删除与改写都可以成为候选。观察变化是否解决了原问题，以及信息、理解、注意、节奏、语气或整体感受是否损失。多个线索可能共同支撑一种效果，删去一个后效果还在，不能推出这个线索从未起作用。

若比较后未发现相关损失，可以保留删减候选；仍要观察效果的强弱、连贯程度和被把握的难易。连续删减后回看整段与全篇，避免每次单独看似无损，合在一起却失去必要的铺垫、累积或声音。

改稿没有明确收益时可以保留原稿；存在不同成立方向时可以给出少量实质不同的备选。用户已指出不满意的地方，应响应这项反馈作具体尝试，而不是用“各有偏好”结束工作。关键材料不足时说清缺口，避免无限换词或凭空扩写。
