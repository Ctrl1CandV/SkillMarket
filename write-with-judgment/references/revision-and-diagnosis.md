# 实质改稿与文本诊断清单

用于实质改写、多版本取舍与审校诊断。日常字句微调直接输出成品即可；用户要求解释改动或只做审校时，按本文结构处理。

## 一、改稿前：先认准原稿哪些地方不能改掉

动刀前通读一遍原稿，圈出已经成立的亮点：
1. **准确的判断与分寸**：原稿对证据强弱的把握（如“初步迹象”“在中小样本下成立”）、对未知原因的坦诚（如“为什么会这样，现在还没查清”）。
2. **有现场感的细节与独特观察**：作者亲眼看到的动作、顺手举出的真实例子、带个人印记的冷峻或幽默句子。
3. **有效的呼吸与停顿**：为强调某个转折特意放慢的铺垫，或干脆利落的一句定音。

改稿的目标是帮原稿把没立住的地方撑起来，绝不是把有棱角的作者声音磨成千篇一律的公文。

## 二、六类实质病灶的动刀方向与复查项

| 原稿病灶 | 动刀动作 | 改后复查（防止矫枉过正） |
| --- | --- | --- |
| **1. 只有干瘪结论，关键理由或区别没展开** | 回到材料，把数字反差、因果链条、具体处境或反例展开写透；材料不够时收窄结论或用 `〔待确认：……〕` 标出 | 验算比率与分摊的分子分母；检查推论是否被误写成了既定事实 |
| **2. 材料有据，但读者读到半途接不上** | 在读者产生疑问的位置提前引入对象与前提，或换一个更具体的切口进场 | 检查是否提前剧透了叙事本来要留到后文的悬念 |
| **3. 几段话在同一处原地打转** | 合并同义复述，按“前一段解决什么、下一段推进什么”重分详略 | 检查被删掉的句子里是否藏着独立的限定条件、例外提醒或情绪铺垫 |
| **4. 说话姿态偏离场合（居高临下或过度讨好）** | 调整措辞暗含的双方关系与责任归属，回到平视陈述 | 检查是否把作者原本明确有力的立场改成了模棱两可的退让 |
| **5. 强调和预告很多，后文却没分量** | 把“极具颠覆性、必须高度重视”换成真正站得住的差异与证据；若只是普通事项则放平语气 | 检查真正的安全警示、高风险提示是否依然醒目 |
| **6. 局部句子漂亮，放进全篇却抢重心** | 从前后段落的走势重看该句：喧宾夺主的枝节收短，把篇幅让给核心关节 | 通读相邻三段，确认主线推进顺畅、结尾分量相称 |

## 三、严格区分改稿中的三类变化与四项复核

修改幅度较大时，在内部（或按用户要求在交付说明中）分清三类变化：

1. **只动了组织与表达**：事实、观点、时态与不确定程度完全未变，仅调整了进场切口、操作前提顺序、详略比例或句法呼吸。这是最安全的默认改写范围。
2. **展开了材料内部的隐含关系**：没有引入外部新事实，而是把原材料里已有的数字做对比（如从 `100、100、100、100、500` 算出总销量 900 与第五天占比过半）、把已给代码代入 `n=1` 验算。这类展开能显著提升文章厚度，直接采用。
3. **新增了外部事实、经历、感官或承诺**：必须来自用户补充的材料或明确的虚构创作授权。在非虚构改稿中，任何待确认的外部原因都用 `〔待确认：……〕` 标出，绝不混入正文冒充原作者经验。

**出稿前四项快核**：
- **数值口径**：凡是新算出的占比、倍数、均值贡献，分子与分母是否与文字表述一致？
- **时态进度**：原文的“将要/正在/已经”是否原样保留，没有把计划中的排查写成已完成？
- **非虚构感官**：是否顺手补进了原文没有的触感、气味、外观或心理归因？若有，立即删回原稿范围。
- **零规则台词**：正文里是否混进了“这里不给原因判断以免误导”“以下区分已知与未知”这类技能元话语？若有，直接删掉，改用事实陈述体现边界。

## 四、“只作诊断”模式的标准输出结构

当用户要求“先看看这篇稿子有什么问题 / 帮我审校一下，先别大改”时，直接按下面四步给出紧凑、可落地的诊断报告（无需空谈写作理论，也不拿规则条目给文章打分）：

1. **整体印象（1–2 句）**：直说读第一遍时最直观的感受——主线清不清楚、读到哪里开始发闷或卡壳。
2. **已经立住的地方（1–2 点）**：明确指出原稿哪一段、哪一个观察或哪一句判断写得好，改稿时应当保留。
3. **核心问题与具体位置（1–3 点）**：
   - 引用原稿的具体句段；
   - 直指问题本质（例如：“第 2 段连用三句四字词夸方案重要，但没写出新旧方案在耗时上的具体差距”“第 4 段把备份配置写在了执行升级命令后面，读者照着做会先覆写配置”）；
   - 给出明确的修改动作。
4. **局部改写样板（1 段）**：挑原稿最核心或问题最集中那一段，直接附上一版改好的文字，缺数据处用 `〔待确认：……〕` 标出，让作者一眼看清“按建议改完后长什么样”。
