---
description: Mechanical pre-submission checks against venue requirements and a countdown plan for the deadline.
argument-hint: "<venue>, such as ICLR / NeurIPS / ACL"
skill: submission-gate
---

Read the rules for the specified venue and check each item (page limits, checklist, Limitations, anonymity, placement of related work, LLM-use disclosure, and so on). Distinguish items checked automatically from those requiring human confirmation. Fetch the deadline from ccfddl and build a reverse schedule. When responding to reviewer comments, classify rebuttal points using the ARR list of invalid criticisms and rank them by importance.
