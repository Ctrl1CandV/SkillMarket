# 完整综述中文导读

适用：“完整总结这篇综述，重点讲 X”。指定章节讲解仍走单篇选读。完整处理针对综述本身，不代表独立读完被引论文。

## 1. 固定版本与原文清单

记录本次要理解的问题、已有背景及关注主题。默认照顾经验较少的读者，概念铺垫与例子按实际基础调整；已给出读法或专题目标时复用它。用户指定版本就用该版；未指定时确认实际取得版，未确认不猜。先获取摘要、引言、完整目录、分类主图和结论，建立作者的范围与组织骨架；这一步还不是全篇完成。

获取正文所有节、关键图/表/公式、影响主文的必要附录。HTML 先用 arxiv_html.py --outline，再按目录逐节调用 --sections；PDF 用宿主实际能力，物理页与印刷页分开。文件存在、解析成功、返回某节分别不等于实际处理和内容核对。

用一份制作清单记录原文每节/资产：定位、是否取得/处理/核对、对应导读标题、缺口。参考文献/致谢可作索引，非必要附录可不展开但说明原因；主体章节不能以“不相关”为由从完整清单消失。

正式期刊 PDF 没有 arXiv vN 时，用 DOI/来源标识、版本说明及实际取得文件的 SHA-256 固定材料；不能伪造 v1。原文清单与制作清单都记录 `source_id`，核对的是同一论文同一材料，不只是两个清单都写“v1”。获取时间和综述文献检索截止日期分开记录。

## 2. 分批处理全篇

每次按自然章节边界读取，长节拆小段时保留祖先标题、术语、相邻关系及版本。先按 extraction-guide 提取分类、标准、机制、代表文献用途、比较、证据和限制，保留原始提取稿。

关注主题详讲，其他分支交代核心内容、作用和差异，不能只剩标题。跨节分类或术语冲突回到原文，不强行统一不同维度。中间章节、脚注、否定结果、结论及必要附录要专门检查。

中间记录须能回查章节信息、跨节关系及原文项到导读的承接：可用章节提取、比较矩阵和映射清单，也可在一份提取稿中合并；复杂综述分开管理，短篇不强制三个独立文件或同一套列名。比较依据实际分类与本次问题选假设、机制、证据条件、代价和失败等维度。代表工作只读过综述转述时，标为二手依据；需要据其性能、冲突或实现做实质判断时再核原论文，不替综述作者背书。

先完成作者范围内的综合。只有用户要求更新现状，或本次问题确实依赖文献截止后的变化时，才按筛选协议补查相关进展，单独写“后续补充”。其余任务说明作者截止与本次处理范围即可，不自动启动新检索；不以更新之名改写原作者分类和结论。读一篇综述、为该篇写导读、对多篇论文做系统综述是不同任务，不新增未经请求的系统检索承诺。

预算不足时按保存授权保留已处理范围、提取稿和下一节，交付“部分导读”；下轮读取原文与提取稿继续。降低本轮文章数量或分批写，不把全篇挤进固定字数。

## 3. 组织读者看到的导读

```markdown
# <准确题名的中文导读>

<范围、核心问题、为何适合本次需求；固定版本原文链接>
<建议从哪里读；当前是完整导读还是部分导读及实质缺口>

## 阅读目录
<对应下文真实标题的可点击目录>

## <背景与作者组织思路>
<解释必要概念、领域问题和分类依据>

## <按文章特点安排的主题/分支>
<机制、差异、例子/对照、必要图表及条件；关注主题充分展开>
<同类主题按需重复此节，不限定数量>

## <比较、评测或争议>
<设置、证据层级、适用范围；不把综述列举当效果排名>

## <局限、开放问题及与本次需求的联系>
<作者原有局限与编辑分析可区分；注意作者文献截止时间>

## 接下来亲自读什么
<按本次目标给少量实际原文位置与阅读目的；理解检查题按需，结论核查/实现任务可给对应下一步>

## 原文与覆盖
<详细定位/参考入口、实际范围及缺口；制作日志另存>
```

标题按内容写，不能机械填写模板。图/表用于解释分类、流程或差异，原图解读与教学示意分开；不要求每篇生成装饰图。分类维度是否互斥、可组合、层级不同必须讲清。原文列表可整理为附表，主要差异和失败条件留正文。

短出处跟随论点，条件和限制跟随结论。作者转述、辅助例子、编辑联系与时效更新能区分；新增当前进展须单独查来源，不写成原综述内容。参考编号、抓取时间、工具日志不反复进入正文。

## 4. 完整性检查

先逐节对照原文与导读：重要定义、所有主要分类/分支、机制差异、关键证据、限制和必要附录均有承接。目录节点齐全不代表内容充分。关键图像未看或表/公式不可辨认而影响解释时，保持部分导读。

用正文试读发现压缩：只有方案名称、模块职责或未来方向清单时，补回原文怎样做、为什么这样做、何时不成立及代表实现的差异。例如检索不能只写“按相似度”，还应交代写入索引、查询匹配、选取与使用；开放问题不能合成一句并列口号。无需逐条照搬文献表，关键机制与理由须让当前读者理解；默认对初学者友好，有基础时按任务减少铺垫，不能删掉论点依赖的条件。

再按需用 `scripts/survey_check.py` 检查清单是否自洽：

```bash
uv run --no-project "{SKILL_DIR}/scripts/survey_check.py" \
  --outline-file <arxiv_html目录JSON或等价人工目录> \
  --coverage-file <制作清单JSON> --json
```

目录接受 `arxiv_html.py --outline --json` 的完整输出（ok/data），也接受同结构的 data。保留原始目录，不为获得通过删掉章节。覆盖文件格式：

```json
{
  "version": "v1",
  "source_id": "arxiv:2404.13501",
  "sections": [
    {"id": "abstract", "processed": true, "checked": true, "disposition": "taught", "guide_heading": "文章概览"},
    {"id": "S1", "processed": true, "checked": true, "disposition": "taught", "guide_heading": "为什么研究这个问题"},
    {"id": "bib", "processed": false, "checked": false, "disposition": "reference-only", "reason": "保留参考索引，未独立读被引全文"}
  ],
  "assets": [
    {"id": "Figure 1", "kind": "figure", "required": true, "checked": false, "basis": "caption-only", "issue": "尚未查看原图"}
  ]
}
```

sections 覆盖原始目录的每项。numbered/abstract 必须实际处理、核对并在 guide_heading 承接；appendix 默认必要，用同标准，非必要时明确 required=false，可 reference-only 并给原因；bib/ack 等保留索引及原因。资产清单依据实际全文人工建立，必要资产 required=true，图核对需要 visual，表/公式核对可用 text 或 visual；未核且声明非必要的资产须给 reason。未知/未处理的资产不要省掉。cache-fallback 可用于固定的已知缓存版本，需说明线上是否有新版尚未核。

arxiv_html 目录自带 `id`，检查器规范成 `arxiv:<基础ID>`；制作清单填写相同 source_id。人工目录也填 source_id。非 arXiv 材料，两份清单都填相同的非空 `version` 说明与 `source_sha256`（64 位十六进制），目录的 version_status 标 confirmed。旧清单缺身份仍能检查章节，但不报告 coverage_ready，需要补齐真实身份，不能只为了通过检查填写任意值。

已有 Markdown 导读时增加 `--guide-file <导读.md>`，检查 guide_heading 是否真实出现在正文标题中（排除代码块）；缺失标题会报告缺口。它仍不能验证标题下的讲解质量。

`coverage_ready` 只表示登记范围、版本和必要资产声明通过机械检查，不能识别清单外遗漏或虚假登记，更不能证明中文讲解充分。原文事实核对及中文试读仍须分别完成，才可称“完整导读”；无版本确认或实质缺口就交付部分结果。

## 5. 保存

沿用已有授权保存规则。清单、提取稿和正文写到用户指定/项目约定的输出目录；不为制作网页内容初始化个人研究记录。已有 AI 主笔记需要更新时走 reading_record，保护批注与版本范围。完整综述包含旧版补充时不能仅改版本标记冒充新版完整处理。

`reading_record.py --source-version` 目前只接收 arXiv vN；非 arXiv PDF 的 DOI、版本说明与指纹保留在综述清单及正文来源行，save-note 省略该参数，不填伪造 vN 或传入 published。主记录没有 arXiv 版本号不能取代材料清单的追溯信息。

可交付“完整导读”的条件是：身份/版本固定，主体与必要资产覆盖没有实质缺口，跨节关系能解释分类与差异，压缩前后核心信息对账通过，来源核查与面向当前读者的试读分别通过。使用矩阵、合并提取稿或其他适合本篇的组织均可；清单成功不替代内容条件，不满足时按保存授权保留进度并交部分导读。
