# 测量、重复与判断

按当前问题读取相应部分。这里提供设计判断，不规定统一 seed 数、样本量、显著性阈值或统计软件。

## 先分清独立信息来自哪里

| 情形 | 设计时需要写清 |
|---|---|
| 在固定测试集上重复训练 | seed 主要反映训练随机性；不能据此声称跨数据集稳定 |
| 多个方法处理相同任务 | 保存任务 ID 和逐任务结果，分析方法间的配对差；不要把两组当完全无关样本 |
| 每个任务重复采样回答 | 回答嵌套于任务；不能把 20 个任务各生成 10 次当成 200 个独立任务 |
| 同一用户、文档、仓库产生多个样本 | 划分、抽样与不确定性估计尊重同源结构；按样本随机切分可能夸大泛化 |
| 测延迟或吞吐 | 明确并发、输入规模、预热、缓存冷热、硬件和时段；保持生产相关性，必要时交错顺序或按时段分块 |

配对源自相同任务、划分或可对应的随机条件；两个程序用了相同的整数 seed，并不保证随机过程相同。区分固定条件下的算法波动、任务间差异和最终要外推的人群/任务范围。

## 先导与主实验

先导可检查实现、指标计算、失败模式，估计每次成本及波动；选少量有代表性的条件而非只挑最容易成功的案例。先导选择参与后续调参时，它就是开发资料，不再称全新留出评测。

主实验需要多精确，取决于什么差异足以改变决定。做功效或精度计算时明示效应尺度、方差/基线率的来源、独立样本数量、配对/聚类结构及分析假设。缺少这些依据时，可给不同假设下的范围和受预算约束的先导安排，不能把计算器输出当保证。预算只能覆盖少量案例时，提供描述性证据并收窄主张。

标准差描述观测波动，标准误或置信区间描述估计不确定性，三者不能混写。只有一个独立 run 时不捏造 run 间误差条；如从测试样本估区间，须明确它仅覆盖该抽样层次。bootstrap 等方法也应在独立单位或合理的层级上重采样，不能打散相关观测来增大有效样本。

选检验前先写要估计的量，例如同一任务上新旧方法成功率的平均差。方法选择依赖数据类型、配对和分组结构；需要实现统计分析时查相应官方文档，核对假设。差异不显著不等于等效；想主张不退化，需要有依据的容许退化范围及能回答它的精度。

## 调参与最终评测

固定数据版本、去重与拆分规则；预处理、特征选择、阈值调节和超参数搜索只使用允许的训练/开发资料。时间预测遵守可见时间，同源数据按研究目标分组，公开 benchmark 则核实泄漏与任务版本。

给各方法合理且可说明的调参机会，记录搜索范围与预算。公平不总是“每个方法相同超参数”；应避免一个方法得到充分搜索，另一个只用明显不适配的默认值。测试集若用于改方法、选提示词或改阈值，就记录它已参与开发，另找保留数据或收窄结论。

## 多指标、追加与失败

事前指定主要指标、关键约束与有限的理论相关切片；其余结果可以报告为探索。多个指标/切片都作确认性检验时，需要相应的多重比较方案或明确的主次解释，不能只报告最有利的一项。

普通资源分阶段与正式顺序统计设计是两回事。默认按预定预算和检查点作工程决策；若每批都查看显著性并准备提前宣告效果，就需要适用的顺序方法及其假设。没有条件时固定评测方案，把中间观察仅用于排错，避免把普通 p 值套在反复窥看的最终结果上。

预先定义超时、无效回答、拒答、OOM 与基础设施故障的处理。任务成功率通常应把任务级失败计入分母；确定是外部故障而排除时，保留原因与数量，对各条件同等处理。重试上限及其成本要进入预算；质量指标可同时报告成功条件下的数值与整体失败率，不能静默丢掉失败。

## LLM 或人工评审

优先选可客观核对的任务结果；需要主观评审时写清评审对象、量表、盲评方式与评审者。LLM 评审固定模型版本、提示词和推理设置；对顺序敏感的比较交换 A/B 位置，在代表性子集上和人工判断核对，并检查分歧类型。不能用一个未经校准的 judge 分数证明方法有效。

评审者意见的分歧和生成结果的随机性分开记录。已有 `run-provenance` 时可复用逐条评审记录与适用的计算工具，先核对工具约束；样本量、一致性验收与结论边界仍按本研究确定，不直接沿用其他协议中的统一阈值。没有时在计划里指定人工复核子集、记录格式和分歧处置，无需依赖外部 skill。
