# 扩展样例与订阅备选核验（2026-11-01）

## 范围与证据边界

用户希望增加样例，并评估内存/显存不足电脑能否使用 OpenAI 订阅生图。此次沿用已有 FLUX.2 klein 4B distilled FP8 及原 ComfyUI/Python，没有增装权重、依赖、节点或后端，没有升级原环境或改原启动器，也没有调用云端图像生成。

预先固定 `suites/expanded-v1.json` 中的 24 项：20 次文生图、三次单参考编辑和一次双参考编辑。全部单次生成，保留所有结果，没有失败后自动抽卡或只留下好图。参考图均来自本组生成结果，不含真人照片或用户私有素材。公开夹具中的合成提示词不等于用户真实任务记录。

24 个任务均完成，最终 PNG 解码、尺寸和哈希校验通过。助手逐张打开 24 张原图，另看了总览、参考编辑对照和中文排字对照。按主要视觉用途记录 17 项 `accepted`、7 项 `needs-work`；这是带局部限制的本次视觉观察，不是用户最终批准，也不是模型通用成功率。原图哈希在拼图及排字操作前后不变。

真实图片、任务回执、采样、提示词副本、逐张视觉记录、离线验证及一次性拼图脚本保存在工作区外。测试结束确认队列为空后，仅停止自己启动的受管理服务。没有执行原 H3 业务任务，不称为 H3 功能回归。

另用原中文海报作了一张**明确标注的 CPU 排字对照**：清除上方错误文字区域、保留下方花束，以现有本地字体写入正确四字。原失败图保留不变。这是人工指定区域的 Pillow 合成，不是模型生成正确了文字，也不是 CLI 已实现自动修字功能。它支持“模型画背景、真实字体负责准确文字”的任务分工。

## 性能与资源

测试硬件仍为 RTX 4070 Ti SUPER 16GB、约 32GB RAM；核心 ComfyUI 0.31.0，使用已有 Python 与 PyTorch。所有任务 batch=1、4 steps、CFG=1、Euler。大图为约一百万像素；另有一张 512×512。首次人像来自新启动服务，未清除操作系统文件缓存。运行时另有桌面/浏览器等活动，不与首轮不同提示词的时间直接作模型性能比较。

| 样例 | 服务端秒 | 外层墙钟秒 |
|---|---:|---:|
| 首张中文人像 | 6.666 | 16.453 |
| 1024px 陶瓷杯 | 3.801 | 12.547 |
| 512px 同提示/seed 陶瓷杯 | 1.775 | 10.359 |
| 杯子改色 | 6.364 | 16.547 |
| 人像转水彩 | 6.235 | 16.625 |
| 背包换背景 | 6.204 | 16.547 |
| 双参考椅子入室内 | 9.339 | 18.906 |

24 项服务执行时间合计 107.993 秒；外层墙钟合计 336.624 秒（约 5 分 37 秒），单项外层中位数约 12.961 秒。外层时间含完整权重哈希预检、轮询、参考上传、图片取回/校验以及采样线程收尾，不含服务启动。

约一秒采样的**整卡显存峰值 16,026MiB（15.65GiB）**，**全系统 RAM 峰值 17,753MiB（17.34GiB）**。不是模型独占值、不是 PyTorch/进程精确峰值，也可能漏掉短峰。512px 任务当时的整卡采样峰值仍为 14,908MiB；热进程缓存和其他应用都在内，不能由此计算这套模型的最低显存，更不能承诺“分辨率降四倍就只需四分之一显存”。

## 低配与 OpenAI 订阅

官方 [Codex 生图文档](https://developers.openai.com/codex/image-generation) 直接支持交互式 CLI 原生生图及 `$imagegen`。官方 [用量说明](https://developers.openai.com/codex/pricing#image-generation-usage-limits) 表明，订阅原生生图计入通用额度，相似回合平均约以 3–5 倍速度消耗包含用量；用 API key 时走 API 计费。故“订阅只能在网页手动生图，Agent 一律另买 API”并不准确；“任何 Agent 都能直接把订阅当免费 API”同样不准确。

本次仅检查到现有 `codex-cli 0.154.0`。没有检查或搬运登录凭据，没有运行 Codex 模型回合，没有消费其生图额度，没有验证原生工具是否在本账户/会话暴露、文件能否落盘或 `codex exec` 是否可用。官方支持不等于本机已跑通。公开旧版本问题中有 [Plus CLI 工具缺失报告](https://github.com/openai/codex/issues/21640) 和 [已关闭的落盘回归报告](https://github.com/openai/codex/issues/28881)；它们只提示应检验实际产物，不证明当前版本有相同故障。Azure 或 Free 计划的报错不能直接套到付费订阅。

开发者文档可直接读取；部分帮助页受到 403/浏览器验证限制。没有据此承诺任何 API 赠款金额、资格或激活状态。API 独立账本不等于一定没有赠款，须在用户自己的官方账户中确认；不假设订阅本身就是 API key 或免费 API 额度。

建议顺序：本地资源合适且用户选择本地时，沿用当前模型；资源不足且允许上云时，先小样验证官方订阅原生能力；没有可用原生工具则人工交接到官方客户端，或由用户明确批准独立 API 路径。运行指引见 [低配与云端备选](../../imagecraft/references/cloud-fallback.md)。当前仅补充选择与验收说明，**没有云端适配器或自动切换实现**。
