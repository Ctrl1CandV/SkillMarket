用途：学术组会 PPT 的单页流程示意图，投影时可读，栅格成品即可。
画幅：横版宽画幅（越接近 16:9 越好），近白背景（#FAFAF8），四周留出约 5% 的干净白边，方便直接贴在 PPT 白底上。

图的结构：上下两条泳道（横向圆角面板），每条泳道左侧有竖排或横排的泳道标题。
上方泳道「离线索引」，浅靛蓝色底（#EEF1FD），标题文字「离线索引 Indexing」。
下方泳道「在线检索与生成」，浅青色底（#E8F5F3），标题文字「在线检索与生成 Retrieval & Generation」。

上方泳道从左到右 4 个节点（白色圆角卡片，细边框，卡片内上方一个单色线性小图标，下方两行文字：中文主标题 + 灰色英文小字）：
1. 文档库 / Documents
2. 文本切分 / Chunking
3. 片段向量化 / Embedding
4. 向量数据库 / Vector Store

下方泳道从左到右 7 个节点（同样的白色圆角卡片样式，但图标与描边用青色）：
5. 用户提问 / Query
6. 查询向量化 / Embedding
7. 向量检索 Top-k / Retrieval
8. 重排序 / Rerank
9. 提示词组装 / Prompt
10. 大模型生成 / LLM
11. 带引用的回答 / Answer

连线：全部是带箭头实线，箭头清晰可见，只允许下面 10 条，方向必须完全一致，不多不少：
文档库 → 文本切分
文本切分 → 片段向量化
片段向量化 → 向量数据库
用户提问 → 查询向量化
查询向量化 → 向量检索 Top-k
向量检索 Top-k → 重排序
重排序 → 提示词组装
提示词组装 → 大模型生成
大模型生成 → 带引用的回答
向量数据库 → 向量检索 Top-k（跨泳道：把「向量数据库」放在「向量检索 Top-k」的正上方，这条线从上方卡片底部垂直向下，穿过两条泳道之间的空隙，箭头指向下方的「向量检索 Top-k」，不穿过任何其他卡片。注意：只有这一条跨泳道的线）

空白处可有的唯一附加文字：画面底部一行小字脚注「RAG：先检索外部知识，再把上下文交给大模型生成答案」。不要出现任何其他文字、图例、编号、坐标轴或装饰性标签。

风格：干净的扁平矢量信息图，2px 描边，圆角 16px，无渐变、无玻璃质感、无 3D、无投影堆叠、无霓虹、无照片、无 emoji、无 logo、无水印、无浏览器或设备外框。配色只用浅靛蓝、浅青、白、深灰（#2D3436 主文字、#7F8C8D 副标题）；箭头用深灰 #4A5568。所有卡片同一尺寸、同一对齐基线，横向间距均匀；中文字体用思源黑体/Noto Sans SC 一类的无衬线体，中文主标题加粗、字号明显大于英文副标题。

文字要求：上面引号内的中文与英文必须逐字出现，不要翻译、不要改写、不要增补词语、不要出现重复的「Top-k」以外的符号。
