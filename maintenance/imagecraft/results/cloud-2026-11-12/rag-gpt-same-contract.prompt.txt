## 内容契约（必须逐字出现）
节点（11）：
1. 文档库 / PDF · Word · 网页
2. 切分 / Chunking · 按语义切块
3. 向量化 / Embedding · 文本 → 向量
4. 向量数据库 / 写入索引 · 相似度召回   ← 跨两个阶段共享
5. 用户问题 / 自然语言提问
6. 查询向量化 / 与建库同一模型
7. 检索 Top-k / 相似度召回候选
8. 重排 Rerank / 精排取最相关几条
9. 拼装 Prompt / 问题 + 检索片段
10. LLM / 只依据给定上下文
11. 回答 / 带引用，可核对

有向边（10）：
- 文档库 → 切分 → 向量化 → 向量库（索引侧，3 条）
- 向量库 → 检索（跨阶段，1 条）
- 用户问题 → 查询向量化 → 检索 → 重排 → 拼装 Prompt → LLM → 回答（问答侧，6 条）

阶段标签：
- ① 离线建库 Indexing — 一次构建，反复使用
- ② 在线问答 Retrieval & Generation — 每次提问都走一遍

辅助文案：
- 标题：RAG 检索增强生成
- 副标题：先把相关资料检索出来，再让大模型带着证据组织答案
- 右上说明：知识随时更新 / 答案可溯源 / 少一些编造
- 脚注：建库与查询须使用同一嵌入模型，向量维度与语义空间才能对齐。

## 必须避免
- 多余节点、凭空增加的分支（如 Agent、Memory、微调）
- 箭头方向反转、箭头缺失或双向
- 错别字、英文术语拼写错误
- 装饰性插画压住文字
