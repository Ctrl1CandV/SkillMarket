## 一、周四晚间 Redis 主从切换操作步骤

请严格按以下顺序执行。第 1、2 步未确认完成前，不要执行切换命令；否则可能造成未同步的热点缓存数据丢失，并在切换瞬间打满主库。

**1. 确认目标从节点复制偏移量**

确认目标从节点的 replication offset 与主节点差距低于 1 MB。

**2. 在网关侧开启非核心写入限流**

确认 `search.write.ratelimit=on` 已开启并生效。

**3. 触发主从切换**

```bash
redis-cli -h 10.0.8.12 cluster failover
```

**4. 观察业务写入延迟**

切换后观察业务写入延迟是否恢复平稳。
