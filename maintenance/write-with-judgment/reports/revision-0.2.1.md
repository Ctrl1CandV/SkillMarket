## 主要取舍

| 方面 | 0.2.1 的处理及理由 |
| --- | --- |
| 具体检查入口 | 吸收段末惯常总结、固定并列、通用口吻、层叠提示和无依据细节等观察线索；由当前情境判断作用，不将形式列成黑名单 |
| 初读与诊断 | 必要时保留初读感受，随后用局部或分散证据分析；允许修正初读判断，也允许尚难解释的感受；模型自评不冒充独立读者反馈 |
| 改稿操作 | 补充提示叠加、动词周围泛化表达、强调与展开不相称的改法，继续并列可能损失的导航、郑重、声音与情绪力度 |
| 删除比较 | 保留“效果仍在不证明成分无作用”；增加连续删改后回看全篇，检查强度、连贯、铺垫和累积变化 |
| 提示与阅读负担 | 同时判断收益与负担；可推得的关系仍可能值得明确说出，不以形式或字数直接认定成本 |
| 结尾与情感 | 确认、凝聚、回应和收束均可成立，不要求额外新认识；不擅自补事实、动机与原因，未知原因不禁止重排 |
| 版本比较 | 区分新增事实、推断和组织表达，承认内容与表达共同改善；避免将整体收益全部归于单个操作 |
| 周报与手链例 | 统一周报提交日期，说明多个因素同时变化；手链扩写标出新事实、动机和解释框架，不把它误认成已经回答“为什么偏偏今天” |

主 Skill 仍以形成值得展开的内容、组织阅读路径、选择具体语言为主干。较长例子与取舍放在参考中，简单任务不必加载全部文件。
