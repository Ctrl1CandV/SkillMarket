# 写作判断：立意、展开与篇章

好文章不止于字句通顺。要让读者读完真正有所得，靠四个写作动作：**找准切口直接进场，挖出材料内部的关系把内容写厚，按问题推进安排全篇详略，在收束与情感处留出分寸**。

**事实、时态与边界底线**：
- 非虚构写作中，事实、数据、原因、承诺与**时态进度（将要/正在/已经）**均须严格照材料守恒；由材料推导出的结论展现推理链条，关键资料缺失时直接询问、收窄主张或用 `〔待确认：……〕` 标出。
- 改写他人真实经历时，严格停在原材料已有的动作与观察，靠语序、停顿和留白出分量，绝不补造原文没有的触感、气味、物理状态或心理归因。允许虚构的任务可在设定世界内创造具体场景与细节。
- 守边界体现在“只交代已知影响与下一步安排”，绝不在正文里写“因此这里不给原因判断以免误导”之类的规则台词。

## 一、切口：第一段就踩在支点上，砍掉助跑

删掉换个题目也能照搬的万能开场（如“在当今快速发展的时代”“XX是一个至关重要的话题”），也省去“先给结论：”“结论先说：”“先把账算清楚：”“我的意见是：”这类先报幕再说话的冒号起手——直接把判断、事实或动作本身说出来：

| 写作类型 | 进场支点 |
| --- | --- |
| **说理与分析评论** | 直接亮出那个**反直觉的区分、真实的矛盾，或决定成败的边界条件** |
| **教学与机制讲解** | 先抛出读者**最容易卡住的具体问题或一个算例**，再由它引出概念 |
| **叙事与经验随笔** | 直接落在一个**在场的动作、物件、对话或反常细节**上，让处境先浮现出来 |
| **工作汇报与沟通** | 第一句直接写**要解决的事项、核心结论或需要对方拍板的决定** |

## 二、写厚：挖出材料内部的关系，替代同义扩写

文字只剩“重要、复杂、效果显著、令人难过”等空洞结论时，先看手里有没有具体材料。缺关键材料就问；已有材料却写得干瘪时，用以下四招把内部关系展开：

1. **算清具体反差（先核分母再落笔）**：把笼统结论还原成数字或事实的碰撞。计算倍数、占比或均值分摊时，写清每个数字对应的分子和分母（如“对整体均值的分摊贡献”与“子集自身均值”分开算清），心算验算后再写。
   - *平庸*：“平均数是 180，中位数是 100，中位数更适合代表日常销量。”
   - *写厚*：“五天销量分别是 100、100、100、100、500。前四天都稳在 100，只有第五天促销冲到 500，单这一天就占了五天总销量 900 的过半，把日均从 100 拉高到了 180。要看平时一天卖多少，中位数 100 才贴合日常状态。”
2. **往前推一步因果**：交代清楚“为什么非此不可”或“少掉这一步会在哪里出事”，用因果链条替代干巴巴的“因此、所以”。
3. **标明适用处境与边界**：写清这项判断在什么条件下成立、换个问题为何立刻失效（例如上面那组数据，若改问“五天一共卖了多少”，就必须回过头用平均数乘天数或直接求和，不能把中位数吹成全能指标）。
4. **摊开真实的取舍**：写明一个方案得到了什么、同时付出了什么代价，用具体边界换掉面面俱到的套话。

**篇幅与文体相称**：说理评论、教学推导与深度汇报需要把上述关系展开写透；日常工作通知、变更邮件与操作清单以清爽够用为准，把前提顺序、已知影响和下一步排查时间交代清楚即可停笔，绝不把两句话的延期通知扩写成冗长规章。

## 三、走势：按“问题推进”安排详略、时机与呼吸

好文章从来不是把每段写成等长的积木。

- **主次分明**：全篇只挑一两处真正改变读者认识的关节写透（给足推导、算例或场景细节），读者已知的背景和常规过渡一笔带过。
- **以问带段，长短错落**：段与段之间靠**认知推进**衔接——前一段解决了“是什么”，自然引出下一段“那在极端情况下会怎样”；连贯的文章、评论、周会汇报与评审意见用自然段推进，不插“第一、第二、第三”或连续 `**结论：**` `**顺序与验收：**` `**代价与边界：**` 这类加粗小标题卡片；长推演句之后配一句简短判断定音。
- **时机贴合使用过程**：
  - 读者**边看边操作**时，前提条件必须出现在动作之前（写“先备份配置，再切换新版本”，而非“将服务切换到新版本。切换前先备份配置”）。
  - 读者**连续阅读或读故事**时，可以先抛出反常现象（如“推开门，屋里却亮着灯”），让悬念带着读者往下走，留到后文再揭示缘由。

## 四、声音与留白：平视读者，让事实自己显出分量

- **平视同行**：把观察、证据和推导摆在桌面上，删掉“你要明白”“必须指出”等居高临下的指点。注意措辞暗含的双方关系：“收到材料了”是正常确认，“终于收到材料了”则带入等待与责备，按真实处境选准位置。
- **守护情感与经验的未知边界**：写个人经历或情感触动时，原有物件、动作与真实的犹疑本身就有重量。若原稿写“看见那条手链时，我忽然很难过。为什么偏偏是今天，我也说不清”，这份“说不清”正是真实的经验状态——改稿时只理顺动作与停顿，绝不替作者补出“扣子松了”“摸着冰凉”之类的新感官或俗套心理框架。
- **收束在最有分量的地方**：话说到位、画面立住就可以停笔。结尾可以是一句收回核心问题的判断、一个呼应开头的细节，或一次简短确认，省去强行拔高的人生感悟。

## 五、随任务选择操作

### 1. 从零新写
动笔前先打开 [四类文体的立意与展开范例](references/exemplars.md)，对照目标文体的切口与边界示范：
1. 明确读者已有基础与接收方式（连续阅读、快速扫读、听讲、边看边做）。
2. 从材料中挑出最核心的一个反差、问题或场景作为第一段切口。
3. 沿着“问题推进”展开核心段落，把力气花在展开材料内部关系上；有数据推导时先验算分母。
4. 通读全文，砍掉助跑开场、同义复述、规则台词和段尾多余升华，直接交付成品。

### 2. 实质改稿
大幅改稿前先读 [实质改稿与文本诊断清单](references/revision-and-diagnosis.md)：
1. **先认准原稿的亮点**：找出原稿里已经立住的判断、独特观察、恰当犹疑或个人节奏，改稿时重点保护，防止把有棱角的文字磨平。
2. **抓最伤阅读的一两个核心问题**：优先解决切口拖沓、关键理由未展开、前提时机放反、段落原地打转等问题，再顺手修顺词句。
3. **核对增量与时态边界**：对照原稿逐项检查事实、数值口径、时态（将要/正在/已经）、证据强弱与未知边界，清除顺手补出的感官细节或规则元话语。

### 3. 只作诊断（审校模式）
先读 [实质改稿与文本诊断清单](references/revision-and-diagnosis.md) 第四节，再按四项简洁输出：
1. **初读印象**：一两句话概括读完后的真实感受与主线清晰度。
2. **已立住的亮点**：指出原稿 1–2 处写得准确、有画面或有说服力的地方。
3. **关键病灶与位置**：指出最影响效果的 1–3 个具体问题，定位到句段并说明为何卡住读者。
4. **改写样板**：挑最关键的一段，直接给出改写后的示范文本（缺数据处用 `〔待确认：……〕` 标出）。

**交付约定**：新写与改稿默认只输出可直接使用的成品正文，从正文第一句起笔、正文最后一句结束，省去前导寒暄、分隔线、修改说明以及正文中“比草稿里那句……”之类的元指代；仅在用户明确要求解释改动，或处于“只作诊断”模式时，才输出分析说明。
