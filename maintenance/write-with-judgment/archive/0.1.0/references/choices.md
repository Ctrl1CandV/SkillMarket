# 同一判断怎样导出不同选择

这些例子说明怎样选择，不是质量标尺或待模仿范文。改变情境后，原来有用的操作可能不再适用。

## 材料不足与关系未展开

“平均数是 180，中位数是 100，中位数更适合表示通常一天的销量”，对核对答案的熟练读者可能足够。若初学者只拿到五天销量 100、100、100、100、500，还可以展开已有关系：四天是 100，一天的 500 把平均数拉到 180；要回答多数日子的情况，100 更贴近这组数据。这里增加了理解路径，没有增加外部事实。

若问题变成五天总销量，这种选择便不适用。写清“在什么问题下较合适”比把一个指标包装成普遍优越更有用。

相反，只有“进度落后”时，无法凭措辞推出落后是执行慢还是等待确认。可以澄清已知影响和待查原因；需要具体原因才问资料。把一种可能写成既定原因，会使文字更完整却更不可靠。

## 有关系不等于每次都要显式提示

“主管周五上午汇总。周报每周四交。”可以考虑补上两句间的理由，也可以保持简洁，取决于读者是否需要知道安排依据、既有背景是否足够。不能看到连接词就删，也不能把未写连接词视为逻辑缺失。

讲课、间隔较长的解释或边听边做，重申条件可能让信息重新可用。连续阅读中刚刚讲清同一件事，再用几种近义说法宣告，可能妨碍推进。比较的是注意和理解怎样变化，不是字数是否减少。

## 时机跟随阅读或使用方式

“将服务切换到新版本。切换前先备份配置。”在读者逐句操作时，会晚给一个前提；可以改为先交代备份，再交代切换。方案概览则可以先说整体变更，再另列前提。两者都能保留同一操作关系，组织方式由使用过程决定。

叙事中的“屋里却亮着灯”提出预期落差。它可以承接已知背景，也可以开启后文才展开的疑问，不必立刻解释。若全篇反复制造类似悬念却使场景始终停在同一位置，可以尝试发展事件或减少提示；普通细节仍可自然存在，不必都变成伏笔。

## 说话位置会改变内容

“收到材料了”和“终于收到材料了”都报告收到，后者还赋予等待一份分量。确实共同经历了等待时可能贴切；正常提交时可能增加不合适的责备意味。修改可以改变这项关系预设，无须一律减弱语气。

一句确认、适度的小结或郑重重复，也可能是对方此刻需要的回应。读者已经能自行得出一句话的意思，不代表听到它没有意义。

## 从局部返回全篇

局部更准确的句子，放进全篇后仍可能抢走重心、打断节奏或提前说尽。完成重要修改后，重读相邻段落与全文：文章在展开什么，哪里发生变化，哪些内容相互支撑，结尾如何改变前文的分量？这些观察帮助决定保留、再改或回退，不要求全文只有一个意义。
