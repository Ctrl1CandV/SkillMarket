# 写作判断

让文字呈现值得接触的内容，并使这些内容在阅读中成立：一个区别被看清，一项判断获得依据，一种处境或感受有了具体形状。事实正确、要求齐全之后，仍要判断读者实际接触到了什么、怎样接触到它。普通确认、直接通知和熟悉经验也可以充分成立，无须额外制造新意或深意。

下列判断用于解决当前写作中的选择，不是每篇都要逐项执行的流程。可以在材料、想法、写出和修改之间往返；只处理影响这次成品的部分。

## 确认这次要交付什么

根据用户要得到的成品决定处理方式：有资料不等于改稿，有草稿也可能需要重新构思。区分从零写作、修改已有作品、只作诊断，以及用户允许的改动幅度。

利用已有情境判断这次文字要回应什么、希望读者获得什么，作者知道什么、能够承诺什么，读者已有何种基础，以及文字会怎样被接收：连续阅读、扫描查找、听讲，还是边看边操作。只补充会影响内容选择的信息；一般语气可以直接判断，关键事实缺失则询问、标出待补处或收窄主张。不要根据身份替读者编造心理。

开放写作可以从一个对象、片段、问题或触动开始，让意图在写作中逐渐形成。无需先为感受命名，也无需把每段文字换算成行动目的。

## 形成内容，并决定怎样展开

先找出材料里真正值得展开的区别、联系、问题或经验。若文字只剩“重要、复杂、令人感动”等结论，判断它缺的是可用材料，还是已有材料之间尚未展开的关系。前者需要补资料、调整范围，后者可以通过比较、推导、场景展开或重新组织形成内容。表达中的发现也可以促使你回头改思路。

依据、分量和出现时机需要一起看：

| 判断 | 对写作选择的影响 |
| --- | --- |
| **有据：这项联系怎样成立？** | 事实有来源，推论有相称的理由，承诺符合权限；叙事可由场景、前后文或悬置的发展承接。感受自述可以直接成立，不必证明情绪合理。缺理由时补关系或收窄结论，不能只加“因此”。 |
| **值得：这次展开带来了什么？** | 考察理解、注意、节奏、语气、关系和体验的变化。解释可以帮人接上，也可能遮住重心；重复可以提醒、积累或凝聚，也可能使阅读停滞。篇幅与形式本身不能决定取舍。 |
| **及时：读到这里时，所需内容是否可用？** | 在实际需要的位置引入对象、条件和联系，安排详略与重心。允许读者等待后文、回看或修正理解；即时操作的前提则要在操作前可取得。 |

同时留意说话位置。措辞会改变确信程度、双方距离、责任与预期：“终于收到”带入等待，“你要明白”安排教导关系。结合这次交流选择确信、迟疑、亲近或郑重的程度；自然不等于口语化。

这些问题帮助解释常见差异，不能包办全部质量。声音、节奏、幽默和复杂情感仍需要结合成品判断；暂时解释不全的好处可以保留。

## 让具体语言与全篇共同起作用

选择能准确区分对象、动作和程度的词，使指代、句法和句间关系可跟随；需要精确化时可以换词，已经贴切时不为显得新鲜而替换。判断句子怎样承接前文，又把注意引向哪里，避免局部都通顺、整体却不知重点。

按内容安排轻重。展开真正改变理解的地方，让辅助内容承担相称的分量；在解释、场景或观点已经形成之后，观察读者的认识或感受是否有所发展。发展可以是旧内容获得新分量，并不要求每句新增信息。句长、停顿、重复、对称与留白都可参与形成声音，不固定成一种整齐或刻意不整齐的文风。

## 随任务选择操作

**新写：**从可用材料或开放片段发展内容，选择读者进入它的方式。必要时改变构思、主张或篇幅。非虚构中的经历、原因、数据和承诺须有依据；允许虚构的任务可以创造事件与人物，但要符合任务给出的世界和事实边界。不要为模仿真人补造个人经历。

**改稿：**先辨认已有的成就与最影响阅读的问题，保留事实、立场、证据强弱和有价值的声音；在授权范围内补充、重排、重写或删减。重要改动要比较所得与损失，必要时回退。新增事实、依据材料作出的推断以及纯粹的组织变化需分清，不能把自行补造内容当作润色。重构、转变立场或风格时按用户明确要求处理，不以“保留原文”为由拒绝获准的改变。

**只作诊断：**先指出作品已经完成了什么，再定位主要问题和可尝试的选择。区分可核对的错误、有文本根据的解释、个人阅读感受与尚未确定的判断。用户要评分时依据其量表；没有量表时先明确评价口径，不将本 Skill 的条目数变成分数。

情感改写保留已知与未知的边界。作者说不清原因时，不替其确定原因；重排、象征、直抒感受和感悟结尾都可在依据或创作授权内考虑。感受的发生、作者的整理和读者的效果各不相同，没有一种叙述顺序天然更真诚或自然。

## 回看与交付

回看影响成品的重要取舍：缺口是否真的补上，重点是否更可把握，改动是否损失准确性、必要条件、节奏或个性。可以比较保留、删除、改写的候选；删除后某种效果仍在，不证明原表达毫无作用。已经成立的内容不必继续改，无明确收益时保留或回退。

默认交付可直接使用的成品。按请求补充简短的关键改动理由、待确认事实或实质不同的备选，不展示逐句功能说明或整套自评。用户明确不满意时，针对其反馈形成有实质区别的尝试；信息不足以完成关键改变时，指出缺口。

判断自然度、质量与个人偏好时保留差别。词语、连接词、修辞或标点不是黑名单，形式计数和来源猜测也不证明优劣。以具体成品的得失结束这次工作，不宣称已经验证普遍效果。
