# 开工确认单｜城市交通最短路径

日期 2026-11-17

状态 **已确认并验收（2026-11-17）**

## 一句话目标

在 Windows 本地浏览器里，用天津五大道—小白楼一带的真实二维机动车路网演示最短路径。老师可以选起终点，观察同一对起终点在距离、预计通行时间和路面条件三种策略下的路线和代价。

## 项目档位

- 规模为一个完整课程设计功能，覆盖路网数据、路径算法、地图界面和自动化验证。
- 使用周期以课程提交和课堂演示为主。使用者为学生、老师和现场观看演示的同学。
- 交付可运行项目、随项目附带的路网、README 启动与演示说明、测试和本确认单。论文与 PPT 由学生负责。
- 按课程提交档逐项验收。开发者先自测，然后由未参与实现的新子代理独立复核。修完并复核后提交一次到本地 Git。推送范围为无。

## 使用者与任务

学生在课堂上打开页面，用一键演示载入一对有名称的起终点，依次切换策略，结合高亮路线和代价讲解 Dijkstra 的选择。老师可自行选择其他起终点，重复查询并查看结果。

## 倾向

- Python 后端手写基于优先队列的 Dijkstra。NetworkX 用于测试中独立计算最优代价。
- 界面用本地网页呈现。Windows 现有 Python 3.12、NetworkX 3.6.1、pytest 9.1.1 和 Edge、Chrome 可用于开发及验证。应用运行依赖为 Python 标准库。
- 安装新包、新建 Python 环境、修改项目目录外的任何内容前，由用户明确同意。实现按当前环境安排。

## 功能与架构

### 数据与图模型

- 使用天津五大道—小白楼一带的 OpenStreetMap 定版道路数据。候选矩形西界 117.193°E、南界 39.102°N、东界 117.220°E、北界 39.126°N，交付记录最终范围、提取日期、保留道路类别、筛选规则和来源。候选样本初筛得到 508 条机动车道路记录，其中 397 条带名称、9 条带路面材质标注，样本中无道路限速标注。最终路网的数量以交付数据为准。
- 道路形状取自原始几何，连通关系按实际共享的 OSM 节点建立。过滤步行道和明确禁止机动车通行的道路，按适用标签建立有向边，保留单行、双向和反向单行的含义。道路在地图上的投影交叉由已有路网拓扑决定是否相通。
- 预置多处可辨认的地标，映射到路网上的机动车接入点。地标选项和教学案例使用项目内随附的数据；案例应有至少两条实际不同的最优路线。
- 地图展示和路网数据按 OpenStreetMap 的 ODbL 要求提供署名和来源。数据随项目保存，课堂演示可离线进行。 [OpenStreetMap 许可与署名](https://www.openstreetmap.org/copyright)

### 路径与权重

| 策略 | 边权重 | 含义 |
|---|---|---|
| 最短距离 | 道路线段长度，单位 m | 沿原始道路几何逐段计算，路线总值为实际通过路段的长度之和 |
| 预计最快 | 长度 ÷ 参考车速 × 教学情景拥堵倍率，统一为秒参与计算 | 参考车速按道路等级设教学默认值，模拟拥堵倍率明确列出 |
| 优先路面条件 | 长度 × 路面惩罚倍率，显示为加权 m | 已知路面材质按项目说明中的材质映射取倍率，缺失时按道路等级的教学默认值取倍率 |

三种策略分别取对应边权之和的最小值。权重均为有限非负值。走过的实际边用于重算全部路线指标，包含可能连接同一对节点的不同道路。实际路网来源和教学参数采用明确的页面标签，README 列出具体参数和缺省规则。

项目按城区样本内的二维有向路网寻路。模型范围覆盖机动车道路连接和单行，转向限制、临时管制及实时交通属于模型边界，页面或 README 说明该边界。交互范围为下拉选点、逐一切换策略和一键演示。

### 运行与部署

在项目根目录用 README 中的一条 Python 启动命令运行，浏览器打开本机回环地址。网页文件、路网和教学参数随项目交付。课堂运行无需联网、地图瓦片服务、账号或密钥。

## 内容与展示

- 单页中文地图。主要区域展示城区路网、起终点和当前路线，侧栏放起点、终点、策略、一键演示和路线结果。
- 用户切换策略后，地图和结果同步更新。结果显示经过道路、距离、预计通行时间与路面加权代价，明确单位。无名称的道路有可读的缺省名称。
- 同一起终点显示零代价。路网不可达时给出清楚的提示，并清除上一次的路线。页面提供 OpenStreetMap 署名和简短的教学权重说明。

## 审美

- 浅色中文地图工具。城区路网作底图，当前路线与起终点在课堂投影上醒目。起终点用文字或标记形状区分，结果数值与单位成组显示。
- 优先照顾 Windows 桌面 Edge 或 Chrome 的课堂演示。地图区域在桌面布局中大于侧栏。
- 确认后用 product-design 和 frontend-craft 完成页面布局与视觉核验。

## 假设与委托决定

- 确切的地标与演示路线由开发者从最终路网中选定，以中文可辨认、有效接入并复现策略差异为准。
- 采用一套固定的课堂拥堵情景和可复算的参数。具体参考速度、倍率与道路类别映射由开发者确定，结果和 README 同时注明教学用途。
- 视口尺寸用于复核课堂常见的两档桌面画面。浏览器以本机已装的 Edge 或 Chrome 为准。
