# 确认单：城市交通最短路径规划（图论课程设计）

日期：2026-11-17　状态：已确认（2026-11-17）

## 一句话目标

交付一个可在浏览器中交互的城市交通路径规划程序：自建示例路网，自己实现 Dijkstra 与 Floyd-Warshall，按距离 / 拥堵 / 路况三个权重计算最优路径并可视化，附一份课程设计报告。

## 项目档位

- 规模：一次会话内完成主体，报告与收尾另占时间
- 寿命：一次性课程作业，交老师评分
- 交给谁：老师评分；同学可能现场点几下
- 验证档位：交给别人评分 → 每项功能逐条验证；核心算法用自动化测试（标准库 `unittest`，`networkx` 仅作对照）

## 使用者与任务

- 使用者：演示者（本人）操作，老师和同学观看；使用者要在现场快速选起终点、改权重、封路，展示不同方案为何不同。
- 任务：选定起点和终点 → 看到按当前权重的最优路线与备选方案 → 调整权重或封路 → 路线实时变化 → 查看分段明细与两种算法的对比。
- 成果交给老师：可运行程序 + Markdown 报告 + 启动说明。

## 倾向

- 想要：Python 3.12（conda `skillmarket` 环境）；后端只用标准库 `http.server`；前端原生 HTML/CSS/JS + SVG，无构建步骤；自己实现最短路算法；`networkx`、`numpy` 仅用于测试对照与离线校验；浅色电子地图风，参考高德地图网页版。
- 不要：Flask/Django 等 Web 框架；安装任何新包（无 matplotlib / pytest / 前端依赖）；用现成最短路库冒充实现；A*；动画炫技。

## 功能与架构

- 做：
  - **路网**：8 列 × 6 行 = 48 个路口，110 条双向道路（横向构图）；含中轴主干道与一条环路；道路有路名、距离（米）、拥堵系数（1.0–3.0）、路况等级（好 / 中 / 差）。
  - **权重模型**：`w = α·(距离/500m) + β·拥堵系数 + γ·路况惩罚`，路况惩罚好=0、中=0.5、差=1.2；默认 α=1、β=1、γ=0.5；三个滑块实时重算；预设「最短距离 / 最快通行 / 最舒适」。
  - **Dijkstra**：自实现，二叉堆；返回代价、节点序列、边序列。
  - **Floyd-Warshall**：自实现，全源最短路代价矩阵 + 前驱矩阵；提供单次对比。
  - **交互**：点选起终点；地图高亮路线；结果面板给出总代价、总距离、预计通行时间、逐段明细（路名 / 距离 / 拥堵 / 路况）。
  - **方案对比**：显示前 2 条不同走向的方案（最优 + 1 条备选），各自总代价与差异；主路径蓝色、备选橙色。
  - **封路模拟**：点击路段禁行/恢复，自动重算；不可达时明确提示。
  - **算法对比面板**：Dijkstra 与 Floyd-Warshall 结果一致性、各自耗时；可切换查看 Floyd 全源最短路矩阵。
  - **报告**：`报告.md`，8–12 页当量，章节见「内容与展示」。
  - **测试**：`unittest` 覆盖最短路正确性、权重合成、不可达、负权拒绝、备选路线去重等；随机小图上与 `networkx` 对照。
- 不做：真实 OSM 数据接入；用户注册/数据库/持久化；A*；移动端 App；Docker 部署。
- 数据：路网由 Python 代码生成（固定随机种子）并输出 `data/network.json`，前端与后端共用；不依赖网络下载。
- 运行与部署：`python server.py` 启动 `http.server`，浏览 `http://127.0.0.1:8000`；`python -m unittest discover -s tests` 跑测试。端口 8000，可用参数改。
- 结构：`server.py`（路由 + 静态文件）、`app/`（路网、权重、算法、API）、`data/network.json`、`static/`（页面、JS、CSS）、`tests/`、`报告.md`、`README.md`。

## 内容与展示

- 单页，中文界面：
  - 顶部：标题、一句话说明、运行状态。
  - 左侧约 2/3：SVG 城市地图，路口可点，路线高亮，路段可点封路，图例（主路径 / 备选 / 拥堵 / 封路）。
  - 右侧约 1/3：起终点选择与交换、三个权重滑块与预设按钮、方案卡片（前 2 条，含总代价/距离/时间/路段数）、逐段明细表。
  - 底部：算法对比区（结果一致性、耗时、Floyd 矩阵折叠面板）。
  - 宽屏双栏；窄于约 900px 上下堆叠，地图不横向溢出。
- 报告章节：问题与需求、路网与权重建模、Dijkstra 与 Floyd-Warshall 原理及复杂度、实现与正确性验证（含 networkx 对照）、权重敏感性实验（表格）、封路与备选路线实验、结论与改进。

## 审美

- 风格与参考：高德地图网页版浅色样式；浅灰底图、白色/浅灰道路、主干道加粗、主干道与环路有区分；主路径蓝色（如 #1a73e8），备选橙色（如 #f29900），拥堵路段红色标记，封路灰色虚线。

- 交给：product-design（页面职责与构图）、frontend-craft（页面实现与精修）。

## 假设与“你定”的选择

- 备选路线数量按「共 2 条方案（最优 + 1 条备选）」理解；若本意是最优 + 2 条备选，实现前告知即可调整。
- 预计通行时间 = 距离 × 拥堵系数 / 40km/h 基准速度，仅作展示，不参与权重。
- 路网生成使用固定种子，数据结果可复现；具体路名与拥堵分布由实现时确定。
- 「不同走向」定义为节点序列不同且与已选方案不共享首尾外的完整路径；若找不到第二条，明确提示只有一条。
- 权重归一化距离基准 500m，滑块范围 α/β/γ 各 0–2、步长 0.1。
- 空输入（未选起终点）时面板显示引导文案，不发请求。
