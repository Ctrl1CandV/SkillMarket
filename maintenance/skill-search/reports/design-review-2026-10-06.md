# skill-search 设计与静态审查

日期：2026-10-06。本轮新增中文方法型技能 `skill-search`（v0.1.0），主题为领域路由与检索纪律。运行目录只含 `SKILL.md`；维护资料单独存放。所有改动待用户审查，未提交，也未更新用户安装目录。

本文保留初稿设计与检查记录；用户随后提出的触发条件与范围优化，见 [v0.2.0 审查记录](scope-review-2026-10-06.md)。当前正文以该次优化后的版本为准。

## 依据与范围

- 用户交接提供了已完成的生态核验：CLI 在前端等有头部供给的领域较可靠，论文与综述类查询出现飞书文档、邮件条目污染；目录指标存在仓库级统计与路径副本重复问题。本轮据此编写方法，不重复联网调查，不把这些既往结果包装成新实测。
- 原样收录的 `find-skills`（上游 `vercel-labs/skills`，MIT）及其维护资料已按用户决定于 2026-10-06 移除，收录核验（文件 SHA256 `c00eeea0e13e74fe4a9d84ba0a8542205a1b736d65f13134fe1a6647eb14976f`，对应上游提交 `773fb2c7`，2026-10-05 核验）见 Git 历史；当时确认的旧副本指令漂移（缺 `--owner`、仍列已移除的 `check`）已吸收进本技能正文。后续检索事实来自用户交接，不改写历史记录。
- 参考仓库 `de-ai-flavor`、`readable-reply` 的中文写法，保留具体反例与交付自查。
- 读取 `grad-radar`、`thesis-cn`、`run-provenance`、`submission-gate` 的现有正文，路由按实际能力限定。尤其 `thesis-cn` 只负责中文学位论文合规，不能泛称论文写作工具；`grad-radar` 明确不做系统性文献检索。

## 设计选择

| 选择 | 理由 |
| --- | --- |
| 独立命名 `skill-search`，保留 `find-skills` 原文件 | 上游文件作为 CLI 使用入口；本地方法处理值不值得搜、领域路由与推荐证据 |
| 普通一次性任务直接做；明确搜技能请求照常处理 | 避免检索成为所有任务的前置步骤，同时尊重用户明确目的 |
| 已知准确技能免发现检索 | 只核对来源、标识与命令，不再搜索同一技能 |
| 读研需求优先本地四个入口 | 使用已知能力；读正文守住边界，不把用户身份当万能路由 |
| 单独安装时允许本地入口缺失 | 宿主技能清单与仓库源文件分开；不写死机器路径、不假装插件已安装 |
| 前端与工作流只做少量 CLI 查询 | 默认一轮，必要时改词一轮；命中足够就停，持续污染也停 |
| CLI 帮助先于调用 | 不继续沿用旧副本的 `check` 等指令；不能执行时如实标为未验证 |
| 正文匹配优先，官方来源优先，指标先查口径 | 避免仓库级 installs/stars 冒充技能质量；低于 100 的信号仅适用于已确认的单技能口径 |
| 不接 SkillsMP API 或职业、语言过滤 | 当前常用场景无需多目录客户端；接口限额、认证等事实不进入运行正文 |
| GitHub 能力只用于候选源文件核验 | 开源项目发现由宿主覆盖，避免与其职责重叠 |

## 桌面推演

以下按正文逐条审查决策分支，未运行真实检索、安装或独立代理试跑。

| 请求或情形 | 应采取的行为 | 静态审查结果 |
| --- | --- | --- |
| “帮我调整一次按钮间距” | 直接做，不先找技能 | 一次性任务刹车覆盖 |
| “找一个前端视觉设计 skill” | 检查已有技能；需要补充时核对帮助、短查询、读正文、推荐少量结果 | 前端检索分支覆盖 |
| “就要 anthropics 的 frontend-design，给安装命令” | 核实准确来源与标识，核对 CLI，不再跑 find | 已知技能分支覆盖 |
| “有没有帮我精读这篇论文的技能” | 优先定位并读取 grad-radar；只求推荐时不自行读论文 | 本地阅读路由与授权边界覆盖 |
| “有没有写英文会议论文引言的技能” | 不把 thesis-cn 当通用写作；查已有适合能力，明确要外部替代时目录检索 | 能力缺口分支覆盖 |
| “帮我登记 run 和回查论文数字” | 路由 run-provenance，不启动实验 | 本地记录路由覆盖 |
| “检查投稿稿件，再写 rebuttal” | submission-gate 只负责对应核对与分类，写作按其他实际能力处理 | 混合任务拆分覆盖 |
| 仅安装 skill-search，找不到 grad-companion | 说明缺失，不能宣称已安装；按请求处理任务或外部替代 | 路径与可用性边界覆盖 |
| paper reading research 返回 740K+ 的 lark-doc/mail | 看正文排除不相关项，不按安装量硬推，按阅读/综述需求分别处理 | 真实反例覆盖 |
| 同仓库多条候选都显示同一 installs/stars | 分清仓库级与未知口径，不写成单技能热度 | 指标口径分支覆盖 |
| 两轮无合适结果 / CLI 网络失败 | 前者说明本次没找到，后者说明检索失败；有已授权任务则继续做 | 停止与失败分支覆盖 |
