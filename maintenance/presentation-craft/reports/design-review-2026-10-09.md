# presentation-craft 收录与审查

日期：2026-10-09。用途是组会、论文讲解、实验进展和课程 presentation。用户要求免费制作、内容完整、排版清晰、样式美观，并加入正常报告所需的基本动态；优先用 skill 解决，工程放在 SkillMarket。

## 方案与范围

默认 PptxGenJS 制作原生文本、形状、表格、图表、图片与备注，Python 标准库脚本添加按点击出现/淡入。LibreOffice 渲染最终 PPTX，PDF/PNG 作为阅读与版面审查证据；动态成品仍是 PPTX。Slidev 是偏公式、代码与网页演示的可选路线，不强制同时使用两套引擎。

工具不依赖新增付费模型 API、素材订阅或云平台额度，宿主已有 AI 仍使用用户自己的额度。无需 plugin、永久 MCP 或浏览器账户。运行时路径从宿主探测，不写入技能和示例代码。

技能流程要求材料与事实核对、叙事组织、内容决定的构图、逐页实际看图及最终 hash 对齐。脚本只提供确定性辅助：结构检查不证明学术真实性、字体排版或审美；`complete: true` 只证明当前文件与记录覆盖一致，无法独立证明模型实际看图或播放。

## 本轮优化

1. 样式原本没有固定，但选择依据不够明显。新增 `references/styles.md`，给出清晰学术、黑白论文、深色数据、暖色编辑、图解教学、机构模板六种可调整方向。方向同时描述内容场景、构图与颜色，不只是换色。学校/实验室模板和用户偏好优先；方向表不是六套已验证模板，也不限制其他风格。
2. 原生动画写入前校验 ZIP 重名和 CRC，避免损坏的不相关资源在生成输出途中导致失败。结构审查也将 ZIP 重名记为错误。未知/重复对象 ID、已有目标页动画和覆盖输入/已有输出继续被拒绝。
3. 最终核对要求当前审查含每页动画/转场信息。缺少信息的旧记录必须重跑审查，不能绕过播放门槛。页码必须是真正整数，JSON 布尔值不能冒充页码；错误 JSON 类型返回清楚错误，不以异常堆栈代替结果。严格要求 `structural_pass` 为布尔真值。
4. 更新设计参考中对基本原生动画和完整静态阅读预览的说明；修正质量参考的检查类型标题。
5. `agents/openai.yaml` 只含可选界面显示字段，没有 invocation policy、工具依赖或运行配置，按用户要求删除整目录。技能通过 `SKILL.md` 保持可发现，运行必需脚本和参考保持自包含。

## 文件与分支

main 运行技能 12 个文件：`SKILL.md`，6 个 `references/*.md`，5 个 `scripts/*.py`；根 README 增加入口。无代理配置、模板包、生成成品、缓存、测试或报告。

dev 同步完全相同的运行文件与根 README，另在 `maintenance/presentation-craft/` 维护本报告、TODO、标准库检查和真实示例源稿/资产/点击计划；维护目录 README 增加登记。没有旧的已提交技能版本，本次不创建无意义 archive。提交沿用仓库“日期＋中文变更说明”惯例；仅本地提交，不推送远端。
