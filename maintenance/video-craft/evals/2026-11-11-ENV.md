# 机器环境

- Linux（WSL2），没有显卡。浏览器里的 WebGL 是软件渲染（SwiftShader），能用但慢。
- Node v24。`playwright-core` 装在 `/home/claude-dev/.local/share/fc-eval/render/node_modules/playwright-core`，不在当前目录，需要用绝对路径或 `createRequire` 引入。
- 浏览器只能用 headless shell，路径在环境变量 `VC_CHROME` 里（`/home/claude-dev/.cache/ms-playwright/chromium_headless_shell-1187/chrome-linux/headless_shell`）。完整版 Chromium 在这台机器的沙箱里起不来。
- ffmpeg 4.4.2：`/usr/bin/ffmpeg`、`/usr/bin/ffprobe`，带 libx264、aac、libvpx-vp9、libopus。
- 中文字体：Noto Sans SC、Noto Serif SC（常规和粗体），另有 Ubuntu 字体。文件在 `/home/claude-dev/.local/share/vc-eval/ab-1111/fonts/`。浏览器通过 `FONTCONFIG_FILE` 已经能找到 Noto Sans SC 和 Noto Serif SC。
- 已经设好的环境变量：`VC_NODE_MODULES`、`VC_CHROME`、`VC_FFMPEG`、`LD_LIBRARY_PATH`、`FONTCONFIG_FILE`。启动浏览器的进程需要继承后两个，否则会缺系统库或没有中文字体。
- Python 3 可用（没有 numpy）。
- 没有语音合成，没有外部素材。
- 你看不到也听不到视频。需要检查画面时，截图或抽帧，再用读文件工具看图片。
