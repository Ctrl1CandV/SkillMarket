# 电影化短片

先写一段可拍的动作，包含角色要改变的事、阻力、最后看得见的结果。可以是人、船、机器，或只露出一只手。试着关掉声音，把分镜缩成五张图，确认谁在做什么、发生了什么变化。三个镜头足够拍完整的动作时，给动作和余韵留出时间。

## 用镜头交代因果

| 镜头职责 | 观众应当看见 |
| --- | --- |
| 全景交代局面 | 人物、目标与障碍分别在哪儿，谁在向哪里行动 |
| 中景交代选择 | 人物注意到什么、犹豫多久、身体怎样准备 |
| 近景呈现动作 | 手碰到哪一处，哪个东西动了，动作在哪一刻完成 |
| 反应和回望 | 结果传到哪里，人物或环境如何响应，开头的哪个关系变了 |

- 先在俯视草图上画人、目标、运动路线和摄像机。相邻镜头沿同一侧拍时，保留近侧与远侧、来向与去向。越过轴线时，跟拍转向或插入正面、全景等能重新交代方位的镜头。《回光》让船先朝左，观众看着船头在画面内转向，再回到同一个地理关系。
- 在切前留够时间读到选择或准备动作。切在动作中段时，两边都留出动作的前后量，从同一个物理时刻接上。以手的握住、触点闭合、灯实际亮起或头转完等可见的状态定帧。让开关的声响准时，让惯性、余震或风继续走几帧。
- 改变景别或切到观众正在找的事物。切出时记下视线落点，下一镜在附近给到入口，或者留下足够时间让观众转移视线。机位推进可以逐渐揭露信息，快速横移会占用观众辨认空间的时间，按动作需要选用。
- 全片有一个轻重顺序。可以在危险将近时延长停留，在决定之后快速给两个因果镜头，结果出现后回到一镜稍长的远景。故事里反复出现的物件、声音或构图适合做首尾呼应。

## 光、材质和合成

1. 先完成无效果的色块稿，检查主体剪影、明暗关系和前中后景。可以先指定窗光、火光、车灯等画内光源，再选曝光和色调。控制高光面积，把最亮的一小块留给当前的动作或可见结果。暗调片在小屏和普通亮度下也要认得出方向、动作轮廓和关键表情。
2. 给每镜写明光源的位置、颜色、遮挡和发生变化的时刻。相邻镜头里让同一束光照在相应的一侧。光进入雾层产生光柱，到达人物或船体时改变面的颜色，在地面或水面上留下反射。分别画光源、在空气中传播的部分、受光物和反射，最后一起调强度。
3. 把表演和特效分层。背景的云和远景只需少量位移，主体保留细节，近景雨、水花和遮挡可以快些。让多个层以不同速度运动，用遮挡、透视缩放和亮度差把它们放进同一空间。颗粒在最后加，放到原尺寸检查图像的边缘和字幕，交付编码后再看一次暗部。
4. 有素材时先检查它是否已经含有运动模糊、光照和景深。需要接更多镜头，可为同一场景画机位和角色姿态图，记录每个素材的光向、镜头时长和可用边缘。用图生素材时，按固定元素拆成环境底图、角色或道具层、透明特效，再在镜头中合成。需要真实的人、布料、手部或复杂物理时，优先考虑可用实拍或 3D 素材。机器、几何光学、线条运动等可重建的部分适合 Canvas、SVG 或 WebGL。用现有游戏引擎或 3D 工具算体积和阴影时，也能把分层结果预渲染后送入时间线。
5. 每个镜头只保留它确实需要的效果。雨幕用来表现风向和距离，耀斑随入镜强光走，景深交代眼睛先看哪里。运动模糊按可见速度安排，快动的背景可以模糊，观众要读的触点或转向仍要清楚。

**试一个材质镜头。**《显色》先靠得很近，只让光掠过几排鳞片，再拉开到能认出蝴蝶的距离。检验时盯住同一块翅面，比较转翼之前、正对光源和转过去之后三帧的颜色、高光宽度和投影轮廓。第一版的高光虽亮，绝大部分面积始终是橙色；调整光源入射方向与鳞片响应之后，转翼本身就能使一带青紫变成金色。需要表现玻璃、绸缎或金属时也可以用同一方法，先证实一个表面在动光下确实发生了目标变化，再增加烟尘或其他效果。 [《显色》的材质、镜头及成本](../examples/iridescence/brief.md)

## 按空间组织声音

- 场景声先铺环境。相同的风到了屋内会变闷，切回海面再打开声场。暗场里可以先听到声源，再让它进画面，或把上一镜的尾声跨过切点。安静的地方保留一点空间底声。
- 音乐、环境和拟音各自有前后。让观众从汽笛判断船的位置，用衣料声标出手的移动，用近处的咔哒声标出触点闭合。灯开始转动后再引入乐音，船离开危险后才让和声松开。按影片需要取舍，人物呼吸和环境声也可以独自撑起一场戏。
- 用与 [场景和声音](sound.md) 一致的事件表。需要推迟配乐时，在同一事件派生偏移，方便剪辑时一起移动。校准音色的主观距离与音量，再测分轨与成片响度。

## 看画面怎么接起来

先看无声输出，标出第一次读懂目标、关键动作和结果的时间。再听声音能否推断方位和切点，然后把最终成片从头连看一次。逐帧对照切点前后的运动方向、视线、光位与空间关系。检查高光、雨帘、水花和浅景深的高级效果是否能在常用分辨率、码率和小屏上保留。联系表用于快速找到需要回看的镜头，运动质量还要在正常速度下判断。可以对照 [审查](review.md) 使用联系表、切点帧条和解码检查。

[《回光》分镜与渲染示例](../examples/short-film/brief.md) 用五个镜头演示一条可复查的动作链，包含人物拟音、灯和海面的分层合成、船头转向和首尾同机位。
