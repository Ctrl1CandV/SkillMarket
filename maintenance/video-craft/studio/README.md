# video-craft 长期视觉研发工作区（Studio · 第 4 层高阶母版试炼场）

> **建立背景（2026-11-27）**：在完成 `video-craft` 前三层建设（① 硬件与版面/字幕/响度机械护栏、② `因为本片……所以……` 上游导演构思、③ 无风格绑定的 `kit/` 2D/2.5D/3D PBR/光线步进与阻尼混响底座）后，通过拆解外部顶尖批量生成宣发大片（见 [`benchmarks/2026-11-27-openai-showreel/`](benchmarks/2026-11-27-openai-showreel/DECONSTRUCTION.md)），我们确认了一个关键规律：
> **仅有前三层的引擎与原则还不够；真正让成片跃升到“顶级宣发/MV 质感”的，是在专门的试炼场里经多轮亲手制作、肉眼挑片与参数打磨沉淀下来的「第 4 层：高完成度镜头招式库与异构母版（Layer-4 Visual Repertoire）」。**
> 这与此前 `frontend-craft` 先亲手打磨 8 类页面再提炼回技能的成功路径完全一致。

---

## 一、目录分工

| 目录 / 文件 | 用途 | 入库规则 |
|---|---|---|
| `benchmarks/<日期-名称>/` | 外部顶尖参考片的 `shotlist` 镜头解剖、联系表（`sheet.jpg`）、关键静帧与视觉技法拆解（`DECONSTRUCTION.md`） | 联系表与分析文档入库；原始大体积 `.mp4` 留本地不入库 |
| `etudes/<编号-招式名>/` | **6–12 秒单一镜头招式练习曲**（如社论衬线荧光笔快切、2D 画布转等轴测三维爆炸拆解、2.5× 浮出式微距交互卡片、带厚度斜向时间轴、PBR 钛金属微距掠光、三维粒子波浪海等），每支只把一招做到极致 | `index.html`、`scene.js`、`score.js` 与样帧缩略图入库；`out/` 视频忽略 |
| `productions/<项目名>/` | **25–60 秒完整多招式串联成片**（产品大片、高燃 MV），检验多镜头转场、60fps 快慢呼吸与配乐咬合 | 源码与 `brief.md` 入库；渲染母带忽略 |
| `JOURNAL.md` | 长期研发实验手记：记录每轮试做的视觉假设、A/B 对照给用户盲选的结论、踩坑参数，以及哪些成熟零件可以反哺回 `video-craft/kit/` | 全文入库 |

## 二、研发闭环规矩（防早熟写死、保创作自由）

1. **先亲手把单招做到惊艳，再谈写规则**：不要一上来就让弱模型盲跑，也不要没做出真画面就往 `SKILL.md` 加形容词。先由当前最强 Agent 在 `etudes/` 里做出 `1920×1080 @ 60fps` 的真片段。
2. **成对 A/B 让用户挑**：涉及审美判断（字号悬殊度、缓动快慢、光晕强弱、快切密度）时，优先做出只差一个变量的 A/B 两段短片请用户直观二选一；区分**普遍成立的视觉质感规律**与**单次题材口味**。
3. **反哺技能时守住“多母版正交”原则**：
   - 把通用几何/光学/排版动作抽成 `kit/` 里的**无配色纯函数工具**（如 `popoutCard`、`explodedStack`、`highlighterText`、`terrainGrid`）；
   - 把锤炼成熟的完整风格做成 **4–6 套气质截然不同的示例/起手式**（如暖石杂志社论风 vs 精密钛金属暗场微距 vs 日光水晶建筑风 vs 高饱和先锋动态图形），绝不把某一套提示词写死成唯一模板。
