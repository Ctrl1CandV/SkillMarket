# 实验样片任务单：斜拉物块最省力倾角与摩擦角几何证明

## 1. 实验目标与对标设计

本样片用于验证 `video-craft` 第一期重构的「课程与讲题轨」核心假设：**在不安装数 GB TeXLive / Manim 重环境的前提下，依靠纯 Web 增强栈（`lesson.js`：离线 MathJax v3 SVG 子项寻址 + 弧线 FLIP 公式变形 + 世界坐标焦点相机 + 词级时间戳驱动）能否做出显著优于无 Skill 与 `0.9.0` 的硬核理工讲题视频。**

- **画幅与帧率**：1920 × 1080，30 fps（调优阶段用 `--draft` 960×540 @ 15fps 秒级验证）
- **配音与同步**：提供两套实测音轨供横向比选
  - **高质量本地档（`vo/`）**：本地 `VoxCPM1.5` 克隆 `teacher` 声音卡（经 `gpu.py` 确认显存余量 > 11 GB、利用率 < 40% 安全放行），`--takes 2` 择优 + CPU `int8` `faster-whisper` 导出逐词时间戳；
  - **轻量零显卡档（`vo-edge/`）**：`edge-tts` 原生导出 `WordBoundary` 逐词时间戳（零显存占用）；
  - **纯净声场**：零合成器背景垫音干扰，仅保留人声与章节过渡处的 3 声极轻泛音提示，配独立 `.srt` 软字幕轨，彻底消除“配音+大标题+底字幕”三遍同义复读。

## 2. 内容三段式与声画分工

- **观众与痛点**：备考大学物理/考研力学与高数极值题的理工科学生；直觉误以为“水平拉（$\alpha=0^\circ$）力全用在前进上最省力”，忽略了斜向上拉对正压力与滑动摩擦力的折减效应；且遇到 $a\cos\alpha + b\sin\alpha$ 分母极值与“全反力摩擦角”几何法不会贯通。
- **第一段 · 破题抓直觉误区（`c01`–`c02`，约占 22%）**：先展示 $\alpha=0^\circ$ 时 $F=0.75\,mg$，再动态抬起拉力角 $\alpha$，让观众亲眼看到支持力 $\vec{F}_N$ 缩短、滑动摩擦力 $\vec{f}$ 同步变短，抛出“一增一减谁占便宜”的核心悬念。
- **第二段 · 单画布连续推演与代数×几何双解会师（`c03`–`c08`，约占 63%，超过半数时长压透主场景）**：
  1. **词级同步正交分解（`c03`–`c04`）**：随口播念出“重力”“支持力”“向上的分力”“向右的分力”“滑动摩擦力”的精确毫秒时刻，依次长出对应颜色的矢量箭头与右上方平衡方程；
  2. **跨步 FLIP 公式恒等变形（`c05`–`c07`）**：代入 $F_N = mg - F\sin\alpha$ → 弧线移项合并 $F(\cos\alpha+\mu\sin\alpha)=\mu mg$ → 右侧弹出 $3:4:5$ 辅助角直角三角形（$\tan\varphi=\mu=3/4, \varphi\approx 37^\circ$）→ 化为 $F(\alpha)=\frac{\mu mg}{\frac{5}{4}\cos(\alpha-37^\circ)}$，同步在下方绘制 $F(\alpha)/mg$ 函数曲线从 $0.75$ 探底至谷底 $(37^\circ, 0.60)$（省力 $20\%$）；
  3. **几何本质印证（`c08`）**：把支持力与摩擦力合成为方向恒定（偏离法线 $\varphi=37^\circ$）的全反力 $\vec{R}$，平移三力构成闭合矢量三角形 $\vec{G}+\vec{R}+\vec{F}=\vec{0}$，直观演示“点到直线垂线段最短（$\vec{F}\perp\vec{R}$）”。
- **第三段 · 考场易错边界：斜推自锁现象（`c09`，约占 15%）**：拉力翻转为斜向下推力，分母变为 $\cos\theta - \mu\sin\theta$，当 $\theta \ge 53^\circ$（$90^\circ-\varphi$）时曲线发散至无穷大，直观解释工程机械“自锁现象”。

## 3. 单一数据源校验（`data.js`）

给定 $\mu = 0.75 = 3/4$：
- 摩擦角：$\varphi = \arctan(0.75) \approx 36.87^\circ$（常规物理题记 $37^\circ$），$\sqrt{1+\mu^2} = 1.25 = 5/4$
- 水平拉（$\alpha = 0^\circ$）：$F(0^\circ) = 0.75\,mg$
- 最优仰角（$\alpha = \varphi \approx 36.9^\circ$）：$F_{\min} = \frac{0.75}{1.25}\,mg = 0.60\,mg$（较水平拉省力 $20\%$）
- 竖直提离临界（$\alpha = 90^\circ$）：$F(90^\circ) = 1.00\,mg$
- 斜向下推自锁临界角：$\theta_{\text{lock}} = 90^\circ - \varphi \approx 53.13^\circ$（$\cos\theta - \mu\sin\theta \le 0$）
