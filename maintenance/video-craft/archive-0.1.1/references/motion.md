# 运动与转场

好运动的样子：每个运动都有原因——引导视线、表示关系或因果、表示状态变化、把观众带到下一镜；同类元素用同一套缓动和时长；全片方向一致；入场利落，出场更快；关键结果前有片刻静止；任何时候暂停，画面上都有一个焦点正在被讲述。

## 1. 缓动

| 用途 | 曲线 | CSS / Remotion `Easing.bezier` | GSAP | Manim `rate_func` |
|---|---|---|---|---|
| 入场、到位（默认） | 缓出，快进慢停 | `0.16, 1, 0.3, 1`（expo out）或 `0.22, 1, 0.36, 1`（quint out） | `expo.out` / `power4.out` | `rate_functions.ease_out_expo` / `ease_out_quint` |
| 出场、离开 | 缓入，慢起快走 | `0.7, 0, 0.84, 0`（expo in）或 `0.32, 0, 0.67, 0`（cubic in） | `expo.in` / `power2.in` | `ease_in_expo` / `ease_in_cubic` |
| 画面内移动、镜头运动 | 缓入缓出 | `0.65, 0, 0.35, 1`（cubic in-out）或 `0.76, 0, 0.24, 1`（quart in-out） | `power2.inOut` / `power3.inOut` | `smooth`（默认）/ `ease_in_out_cubic` |
| 轻微回弹（小元素弹出） | 过冲 5–10% 后回位 | `0.34, 1.56, 0.64, 1`（back out） | `back.out(1.4)` | `ease_out_back` |
| 匀速 | 线性 | `linear` | `none` | `linear` |

Remotion 的 `spring()`：`{damping: 200}` 平滑无回弹，适合大多数入场；`{damping: 20, stiffness: 200}` 干脆；`{damping: 8}` 明显弹跳，只用在有物理含义的地方。

- 线性只用于持续旋转、匀速进度、跑马灯和播放中的视频本身。
- 弹跳和弹性曲线一部片子里最多用在一两处有物理隐喻的地方（掉落、碰撞）。
- 同一类元素（所有卡片、所有标签）共用同一条曲线和同一时长，片子才显得是一个整体。

## 2. 时长

下面按 30 fps 给出秒数和帧数；60 fps 时帧数翻倍。

| 动作 | 时长 |
|---|---|
| 小元素（图标、标签、点）入场 | 0.25–0.4 s（8–12 帧） |
| 标题、卡片、图表元素入场 | 0.4–0.7 s（12–21 帧） |
| 全屏或大面积变化 | 0.6–1.0 s（18–30 帧） |
| 出场 | 入场时长的 60–75% |
| 错峰间隔 | 每项 2–4 帧（60–120 ms），一组总错峰不超过 0.5 s；超过 8 项时按组错峰，或只错开前几项 |
| 关键结果前的静止 | 0.3–0.75 s |
| 计数器 | 0.8–1.5 s，与对应图形同时到位 |
| 慢推（整镜头） | 1.00 → 1.04–1.08，贯穿整个镜头 |
| 快速推近（转到细节） | 0.6–1.2 s |
| 屏幕文字（没被旁白读出的）停留 | 字数 ÷ 7 + 0.5 秒以上 |
| 结尾画面停留 | 1.5–2 s 以上 |

单个元素入场不超过约 0.8 秒；更长的建立过程用多个元素错峰完成。

## 3. 编排

- **按层级入场。** 容器 → 主体 → 标签 → 细节。主体先到，次要元素跟上，观众的视线跟着顺序走。
- **重叠，不排队。** 下一个元素在上一个完成 60–80% 时就开始，一组动作连成一个流畅的整体。
- **因果相连。** 点击 → 按下反馈 → 结果展开；碰撞 → 被撞物移动。反应从原因发生的那一帧开始，晚几帧就像卡顿。
- **跟随与惯性。** 主体停下时，附着的标签、阴影或尾巴晚 2–4 帧停，可以有很小的过冲。较重的物体回弹慢，较轻的回弹快。
- **引导焦点。** 讲到一个元素时，其他元素降到 30–50% 不透明度、略微缩小或虚化；讲完恢复。
- **静止的镜头也要有进展。** 慢推镜头、进度条在走、计数在跳、高亮从一项移到下一项，或者界面在执行操作。漂浮、呼吸、来回晃动这类没有含义的循环动作不能代替内容；一个镜头入场完毕还剩很多时间，说明需要更多节拍，或者镜头该缩短。

## 4. 文字动画

- 中文按词或短语出现，不逐字蹦出；逐字打字效果只用于代码、终端和对话框。
- 强调关键词：底色从左向右扫入、下划线描出、颜色变为高亮色、轻微放大到 1.05–1.1 倍，选一种并全片沿用。
- 标题入场常用组合：位移 30–60 px（竖屏用 y 方向）+ 不透明度 0→1，时长 0.4–0.6 s，缓出；多行时每行错开 3–4 帧。
- 数字变化用计数器，不是瞬间替换；最终值必须精确，保留单位。
- 同一层级的文字用同一种入场方式。每行文字一种特效，会让画面显得杂乱。

## 5. 镜头运动

- 把所有元素放进一个舞台容器，通过对容器缩放和平移来模拟摄影机，不逐个移动元素。
- 一个镜头一种主运动：推近表示强调或深入，拉远表示揭示，横移串联序列。
- 镜头运动用缓入缓出曲线，持续时间较长；与元素入场的缓出曲线区分开。
- 前景、中景、背景以不同速度移动（背景约为前景的 30–60%），画面就有景深。
- 大范围快速横移在 30 fps 下会抖：缩短移动距离，加 4–8 px 的运动模糊，或者改用 60 fps。

## 6. 转场

全片选 2–3 种，写在分镜的 `transitions` 里，反复使用：

| 转场 | 做法 | 用于 |
|---|---|---|
| 运动中硬切（默认） | 出镜：沿主方向加速离开，0.25–0.35 s，缓入，位移约画面宽度的 12%，不透明度线性降到 0，正好在切点消失；入镜：从反方向约 12% 处、约 35% 不透明度开始，沿同一方向缓出到位，时长不短于出场 | 普通镜头之间 |
| 共享元素过渡 | 上一镜的元素在切点不消失，移动、缩放、变形成为下一镜的一部分 | 同一对象跨场景延续，效果最好 |
| 推进穿越 | 出镜内容放大 1→1.2 并模糊到 8–10 px，切换，入镜内容从 0.75 放大到 1 并清晰 | 深入同一概念 |
| 遮罩擦除 | 主色色块沿主方向扫过画面，下一镜在色块后出现 | 章节切换 |
| 交叉淡化 | 两镜叠化 0.5–1 s | 时间流逝、情绪段落 |

- 切点在运动之中：出镜一侧在切点仍在动，入镜一侧切点时已经在途中。
- 推进穿越时两边都在放大，拉远穿越时两边都在缩小；一边放大一边缩小会显得方向打架。
- 透明度过渡期间两层叠加的总不透明度会低于 1：舞台底层要有不透明的背景色，否则会透出白色，形成白闪。
- 一个镜头内部的多个节拍之间不需要转场，用元素的进出完成变化。

## 7. 示例：一个“三个能力”镜头的编排

8 秒，横屏，产品界面风格。旁白依次讲到三个能力。

```text
0.00  舞台已在慢推（1.00→1.05，持续 8 s）
0.00  左侧界面卡片从 x+60 缓出到位，0.5 s
0.15  卡片里的三行功能列表依次出现，每行间隔 3 帧
0.80  光标从右下进入，0.6 s 移到第一行（缓入缓出）
1.40  点击：按钮按下 2 帧缩到 0.96，同一帧右侧结果面板开始展开（0.45 s）
      旁白说到“一键生成”的同时，结果面板到位；另外两行降到 40% 不透明度
3.40  高亮条从第一行滑到第二行（0.4 s），第二行恢复 100%，结果面板内容横向替换
5.60  高亮条到第三行；0.4 s 静止后，数字“3.2 s → 0.4 s”从 3.2 计数到 0.4（1.0 s）
7.00  计数停住后静止约 0.65 s，让观众读完
7.65  整个界面向左加速离开（0.35 s，缓入），切点在 8.00，下一镜从右侧接着运动入场
```

所有元素沿同一网格对齐；主方向向左；每个变化对应一句旁白；镜头始终有一个焦点在动。
