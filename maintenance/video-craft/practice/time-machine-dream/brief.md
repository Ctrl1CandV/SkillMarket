# 《time machine》副歌 · 梦里才见得到

video-craft 0.8 的练习：同一段副歌（歌曲 1:52.2–2:26.6，34.4 秒），[上一版](../time-machine-chorus/)先想画面（星座、星轨、时光机），这一版先写内容设计再画。1920 × 1080，30 fps，画面全部用代码画成，中英双语歌词字幕。

歌曲和歌词不入库：`out/`、`lyrics.srt`、`lyrics.mjs` 都在 `.gitignore` 里，按下面第 4 节自己生成。

## 1. 内容设计

1. **谁在听**：和一个人分开了（异地，或者已经不在一起），白天看着没事，夜里一个人的时候，只有睡着才见得到对方。
2. **逐段复述**：这段副歌先说想回到过去；再说每次睡着都能在梦里见到你，像坐时光机回去；然后说知道一醒来你就走了，所以别让我睡着。想睡和怕睡是同一个原因：梦里有你。
3. **疼在哪里**：盼着睡，又怕醒；每天早上醒来，等于再失去一次。
4. **温度**：淡，压着。不用奇观，不出现时光机道具。梦是温暖、平常的早晨，现实是冷的、空的。
5. **具体的生活**：一张双人床，他睡左边，右边的枕头一直是平的；两个杯子，她那只白色的缺了一个小口，倒扣在沥水架上很久没用；他们在阳台上看过星星，她指着最亮的那颗。
6. **戳人的句子**：“知道一醒来你就走了”。检查办法：静音看这一句对应的镜头（S9），能看出她在光里变淡、消失。
7. **态度**：不是重逢，也不是放下，而是不敢再睡。结尾停在醒着、一个人、灯开着。

因为观众是只能在梦里见到对方的人，所以拍：空着的那半边床、手放在她的枕头上、梦里平常的早晨、醒来时同一个房间变空；不拍：时光机、星轨、大场面、正脸。人物一律是剪影、背影和手。

## 2. 视觉世界

同一个卧室（机位 A：床尾望向床头）出现四次，只换光：夜里月光、梦里晨光、醒来的冷色黎明、开灯后冷房间里的一小块暖光。窗户在她那半边床后面，所以每一种光照亮的都是她，或者她空着的枕头。厨房的两个杯子出现两次：夜里倒扣着，梦里正放着冒热气。阳台和星星是梦里的回忆，色调偏暖紫。

## 4. 重新生成

```text
python ../../../../video-craft/kit/songmap.py <录音> out/song --lyrics
cp out/song/lyrics.draft.srt lyrics.srt        # 对照录音改词，补中文翻译
node ../../../../video-craft/kit/captions.mjs lyrics.srt lyrics.mjs --from 112.227 --to 146.627
node ../../../../video-craft/kit/render.mjs index.html video out/picture.mp4 --audio out/song.wav --mux out/film.mp4
```

`out/song.wav` 是录音 112.227–146.627 秒的片段。人物和手在 [figures.js](figures.js)，镜头在 [scene.js](scene.js)。

## 5. 和上一版比

[上一版](../time-machine-chorus/)和 DeepSeek Flash 的 0.7 复测版都没讲出“分开以后只能在梦里见面”。两版的人物都画成了星座骨架，近景没画完；DeepSeek 版的怀表、星仪、胶片三个固定镜位分别出现 12、13、7 次。这一版每个镜头都是故事里不同的一刻。只有卧室和厨房的构图重复，每次重复都换了光，也换了人在不在。
