## 一、外部标杆工具与机制拆解

我们对当前主流代码生成教学视频的五条技术路线进行了机制拆解与本地可行性对比：

| 方案 | 核心优势机制（值得吸收） | 依赖代价与 AI 生成痛点（为何不整套照搬） | 结论 |
|---|---|---|---|
| **Manim Community / ManimGL**（3Blue1Brown 路线） | 1. **`TransformMatchingTex`**：将公式按双花括号子串拆成独立矢量组，匹配相同符号键做平滑位移缩放（FLIP），新增/消去项做淡入淡出；<br>2. **`MovingCameraScene`**：把相机视口抽象为世界坐标系里的矩形 `frame (cx, cy, w, h)`，推拉摇移本质是对视口矩形做缓动插值。 | 1. 强依赖完整 TeX 发行版（MiKTeX/TeXLive 数 GB）+ `dvisvgm` + Cairo/Pango，本机未装且普通环境部署重；<br>2. 大模型极易混淆 `manimlib`（GL）与 `manim`（CE）两套不兼容 API，调试报错率高。 | **不装重栈，移植核心机制**：在浏览器 SVG 层原样实现「子表达式键匹配 FLIP 变形」与「世界坐标矩形相机 `FocusCamera`」。 |
| **Motion Canvas** | **`waitUntil('event')` 时间事件锚点**：动画代码不写死绝对秒数，也不按粗糙百分比猜时间，而是绑定到语义锚点，由配音实测时间表驱动，重录配音时画面自动对齐。 | 依赖 TypeScript + Vite 构建服务与 Generator 状态机，破坏 `video-craft` 零构建、纯函数随机访问 `seek(t)` 的轻量优势。 | **移植锚点机制**：用 `narrate.py` 导出词级时间戳（`words.js`），提供 `wordAt(cue, '支持力')` 语义锚点查询，直接驱动 `seek(t)`。 |
| **MathJax v3 (`es5/tex-svg-full.js`)** | 1. **纯 JS 同步矢量渲染**：`MathJax.tex2svg(tex)` 毫秒级同步输出纯 `<svg><path>` 轮廓，内置全部数学字体轮廓，**零外部 `.woff` 字体依赖、零 `file://` 跨域问题**；<br>2. **原生子项寻址**：内置 `\cssId{id}{expr}` 与 `\class{cls}{expr}`，即使嵌在分式、根号、积分上下限或矩阵内部，生成的 SVG `<g id="...">` 节点也能直接读取 `getBBox()` / 屏幕包围盒并独立变色、框选或跨步位移！<br>3. Apache-2.0 许可，单文件约 1.1–1.7 MB。 | 默认 `fontCache: 'global'` 在多公式同屏测量时需注意 `<defs>` 共享或使用 `fontCache: 'none'` 保证单 SVG 自包含。 | **选为核心公式引擎**：相比 KaTeX（输出 HTML span + 外部字体，难以在 SVG 视口内精准几何变形），MathJax v3 `tex-svg` 是零依赖 Web 讲题公式的最优解。 |
| **Typst (`typst-wasm` / CLI)** | 语法简洁，编译快。 | 浏览器端动态编译需加载 >12 MB WASM + 字体包；且大模型对标准 $\LaTeX$ 公式的掌握远胜 Typst 数学语法。 | 不采用；坚持标准 $\LaTeX$ 输入以最大化模型准确率。 |
| **Mafs / JSXGraph** | 声明式数学坐标系、向量箭头、参数曲线、积分阴影区与几何标注设计清晰。 | Mafs 强绑 React；JSXGraph 偏命令式交互状态。 | **吸收原语设计**：用纯 SVG 编写零依赖通用理工图解模块（坐标系、函数/包络曲线、物理学力矢量/角度弧/斜面支座/弹簧截面、框图节点与引线批注）。 |

## 二、教学视频认知负荷理论（为何 0.9.0 像“累人的有声 PPT”）

结合 Richard Mayer 多媒体学习认知理论（Cognitive Theory of Multimedia Learning）对照 `0.9.0` 实测样片（`09-bayes-gpt` 与 `09-bayes-deepseek`），可以精确定位三大反模式：

1. **冗余效应（Redundancy Principle）**：当屏幕同时呈现「图形动画 + 旁白口播 + 逐字复述旁白的大标题与底字幕」时，学习者的视觉通道被迫在“读字”和“看图形变形”之间来回撕裂，理解效果反而显著下降。
   - **转化规则**：讲题轨实行严格**声画分工**——口播负责因果解释与提问，画布只保留题干条件、演化中的公式/几何图与极短批注词（≤8 字），口播字幕默认输出独立 `.srt` 软字幕轨，严禁三遍同义复读。
2. **信号引导原则（Signaling Principle）**：高复杂度理工题目元素多（多力共点、长分式、多分支状态），无引导的全亮画面会让观众找不到焦点。
   - **转化规则**：统一建立**「色彩语义绑定 + 聚光压暗（Spotlight Dimming）」**——例如受力图上的支持力矢量 $\vec{F}_N$ 用青色，则方程里的 `\cssId{fn}{F_N}` 同步用同款青色；当前步骤聚焦某一项时，其余非活跃背景项自动压低透明度至 `0.3–0.45`。
3. **空间与时间邻近原则（Spatial & Temporal Contiguity）**：
   - **空间邻近**：物理量符号、数值批注直接贴在矢量箭尖、角度弧或曲线特征点旁，不放远端图例表；
   - **时间邻近**：说到哪个物理量或哪次消元，对应图形/公式子项必须在**该词发声的同一拍（误差 ≤150ms）**点亮或变形，不能整句开头一股脑全出。

## 三、本期工程改造清单（P0 底座 + P1 讲题实验原型）

### 1. P0 资源安全与快渲底座
- **显卡多采样探针（对齐仓库 `imagecraft` 经验）**：
  - 在 `doctor.mjs`、`narrate.py`、`songmap.py` 中统一采样 `nvidia-smi`（区分 `ok`、`present_but_inaccessible` 沙箱遮挡、`not_detected`）；
  - 实测持续核心利用率（>75% 判忙）与剩余显存（`<4096 MiB` 禁上 VoxCPM1.5，`<7168 MiB` 禁上 VoxCPM2）；
  - `narrate.py` 增加 `--device auto|cuda|cpu` 与显存/负载守卫：GPU 繁忙或余量不足时不静默抢卡，给出明确告警与 `--engine edge` / 等待选项；
  - `songmap.py` 增加 `--device auto|cuda|cpu`，GPU 繁忙时自动回退 CPU `int8` 转写。
- **词级时间戳与软字幕管线**：
  - `narrate.py` 对最终选中的音频（无论来自 `voxcpm` 还是 `edge`）默认运行轻量 CPU `int8` `faster-whisper`（`word_timestamps=True`），直接产出 `vo/words.json` 与 `vo/words.js`（含每句精确时长及逐词 `[t0, t1]`）；
  - `vo.mjs` 支持直接合并导出句长、词级锚点查询函数与独立 `.srt` 软字幕文件。
- **草稿快渲分级（`render.mjs`）**：
  - 支持 `--scale 0.5`（如 960×540 视口缩放截图）与 `--fps 12` / `--fps 15` 预览快渲模式，加上 GPU 繁忙时的可选轻量浏览器启动参数，使调优阶段渲染提速 4–6 倍，仅母带交付跑一次 `1920×1080 @ 30fps`。

### 2. P1 讲题轨实验原型与试金石真题设计
- **本地打包离线公式库**：引入 Apache-2.0 许可的 MathJax v3 `tex-svg` 单文件离线包，封装同步 SVG 公式生成、`\cssId` 子表达式包围盒提取、子项高亮框选与跨步 FLIP 平滑变形助手。
- **通用理工板书与力学/几何模块**：封装世界坐标网格、平滑函数曲线/阴影、物理矢量箭头、斜面/刚体/铰支座/弹簧剖面、角度弧与尺寸线，以及基于矩形视口插值的 `FocusCamera`（支持全景推近特写与局部放大镜）。
- **亲手实验真题选型**：选取一道兼具**「直觉易错题眼 + 工程力学矢量几何分析（摩擦角/临界极值几何圆或正交分解）+ 多步三角恒等/求导公式变形」**的经典考研/大学物理综合题，完整制作带词级同步纯净干声的样片，验证纯 Web 增强栈能否在不装数 GB TeX/Manim 的前提下达到一流教学视频水准。
