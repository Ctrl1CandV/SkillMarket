# grad-radar 0.3.0：三项目标审查与优化

本轮在 SkillMarket 源码上延续已有未提交的 grad-companion 改动。ResearchWorkbench 只作为参考，未修改其文件、个人 `.grad` 或安装插件缓存。最终工作区为 dev；没有执行本轮 commit、push 或发布。

## 原有改动是否满足目标

| 用户目标 | 原稿评估 | 本轮补齐 |
|---|---|---|
| 论文压缩提取质量 | 已有按类型提取、图表/公式核查和出处规则，缺少压缩前后对账 | 分阶段阅读；先留证据与条件；核心项标去向；数值保留设置、分母、单位和负例；独立做事实核查与中文试读 |
| 提高论文/综述筛选要求 | 原稿主要按学习适配选文，刊会、引用与年份只是辅助说明 | 顶刊顶会与近三年为常见起点；按经典基础、时效应用或复现目标重排属性；核正式轨道、论文级影响和正文；硬条件不足给零个已核主读 |
| 增加综述压缩流程 | 已有全篇目录覆盖和导读，检查器只接受 vN，缺少跨论文身份核对 | 章节提取、跨节比较和导读承接可合并记录，再对账与试读；支持期刊 PDF 的来源/版本说明与 SHA-256 声明，另核实际 Markdown 承接标题；时效补充按需启用 |

原稿的来源版本隔离、人工批注保护、摘要降级和单篇主记录继续保留；人的已读状态仍只根据用户表态更新。本轮没有新增强制问卷、后台检索服务或新的研究台账。

## 读者与场景调整

根据用户后续取舍同步了技能入口、命令、选文、每日分级和阅读/综述协议：

- 好论文的共同底线仍是问题相关、身份可靠、证据支持结论；刊会、引用、年份及先修负担的优先级由本次任务决定。经典基础可直接作主读；时效应用通常要求近期且匹配当前环境；用户明确硬条件不自行放宽。
- 每日发现仍保留查询→元数据初筛→分级→少量提取→选中后阅读。范围来自本次输入与同一任务会话；不自动继承历史关键词或推断兴趣，反馈不改长期配置/插件规则。旧配置可在用户本次明确指定时只读使用；新初始化的关键词和分类为空，不预填 LLM/Agent。
- 默认照顾阅读经验较少的读者，按实际基础补概念和例子；有明确读法时复用，理解检查题按需给。准确性、关键条件及未读范围不随读者经验放宽。
- 完整综述仅在请求更新现状或当前问题依赖后续进展时追加检索；中间记录按篇幅和复杂度合并。固定材料与全篇实质覆盖仍是称“完整”的前提。

## 参考材料及采用方式

- ResearchWorkbench 的 READING-TEMPLATES-005、SURVEY-013 内容质量标准、综述生产流程，以及已有 grad-companion 实施报告/示例：吸收全篇处理、有效信息保留、分类/机制/评测差异和制作/用户阅读状态分离。没有将其网站结构或私人路径写进运行要求。
- [Waterloo S. Keshav 的三遍阅读法，UCSD 课程托管版](https://cseweb.ucsd.edu/~dstefan/cse227-spring22/papers/keshav%3Ahow.pdf)：先定位、再核内容证据、必要时重建论证，不把虚拟重建当实验复现。
- [Stanford CS224U 指导](https://web.stanford.edu/class/cs224u/projects.html)：共同问题、比较与冲突、未来工作和准确书目；不沿用固定课程篇数或页数。
- [CCF 2026 第七版目录说明](https://www.ccf.org.cn/Academic_Evaluation/By_category/)：核实际学科/刊会类型与 Full/Regular 轨道，不把 Workshop/Findings 等套为同级正式长文；其说明也反对用刊会级别代替单篇评价。
- [OpenAlex Works](https://help.openalex.org/data/works/attributes/)、[Crossref REST](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) 与 [dblp 官方开放元数据说明](https://blog.dblp.org/2026/04/29/results-and-findings-from-the-2025-2026-dblp-user-survey/)：分别用于论文级影响与版本信息、DOI/出版元数据及计算机书目核查。统计来源、日期与缺值必须保留。dblp FAQ 访问受限，未将其未读正文作为依据。
- [DORA](https://sfdora.org/read/)：指标服务筛选，仍对单篇内容做判断。用户明确硬条件不会因此被取消。

常见三年窗口、按场景重排属性、来源/成熟度标签和压缩对账是本插件的综合设计，不宣称高校或数据库提供了统一算法。OpenAlex 单篇实时 API 试取未成功，本轮没有填入或声称取得实时引用数字。

## 代码与回归

`survey_check.py` 新增：论文身份规范化与比对，非 arXiv 固定材料的声明指纹一致性，导读标题核对（排除代码块），非必要未核资产的理由，以及坏枚举类型的正常报错。它是只读检查器，仍不验证声明的真实性、实际源文件的 hash、所有图像或标题下的讲解质量。

将 ResearchWorkbench 的既有 20 项记录/覆盖回归迁入 dev 的 maintenance，改为直接测试本仓库源码及独立临时目录，先增加 8 项覆盖用例，再增加 7 项配置与每日查询用例。最终 **35 项通过**，涵盖不同论文同 v1、身份缺失、arXiv 目录 ID、期刊 PDF 指纹、DOI 规范化、虚假/代码块标题、未核可选资产理由及坏枚举；新增用例验证无预填偏好、缺范围在联网前拒绝、本次 CLI 不继承项目偏好、显式覆盖不写回、旧配置只读兼容、空范围不接受坏组，以及记住阅读基础不填检索方向。原来的人工批注/版本/摘要降级保护继续通过。

测试均为合成记录，网络响应使用假数据，不读取或写入个人研究进度。配置 init 沿用既有硬链接防覆盖逻辑；首轮新增测试被本机沙箱禁止硬链接，随后在获准执行的独立临时目录中完整通过，没有为测试放宽插件的防覆盖逻辑。

`reading_record.py`、`arxiv_html.py`、`radar_config.py`、`survey_check.py` 及评测脚本语法解析通过；skill-creator 结构验证、相对资源路径及差异空白检查通过。本轮不改变 arXiv 获取/缓存实现，未完整重跑其联网链；35 项回归不证明 AI 的实际选文或讲解效果。

## 真实材料与筛选场景复核

已有记忆综述固定材料 `2404.13501v1` 的人工清单有 53 个目录项、51 个主体/摘要承接项及 17 个声明资产。实际导读标题映射核对通过。旧清单缺 source_id 时准确报告未就绪；仅在临时副本补入从原文 URL 得到的真实标识后就绪，详见 [清单结果](../evals/real-survey-coverage-check.json)。没有修改参考项目的原清单。这证明清单兼容与映射，不是全篇事实或图片重新审计。

原文关键抽核：

| 固定材料 | 本轮抽核与信息保留检查 |
|---|---|
| [ReAct v3](https://arxiv.org/html/2210.03629v3) | §2 的 thought 不改变外部环境；Table 1 的 HotpotQA 中 ReAct 27.4 低于 CoT 29.4、FEVER 60.9 高于 56.3；不能压成所有任务都更好。人工失败分析的抽样范围也保留 |
| [SWE-bench v3](https://arxiv.org/html/2310.06770v3) | Appendix A.4 的 F2P/P2P 与缺失测试判定；Table 5 的 Claude 2 1.97 与正文 1.96 的差异保留定位。先访问 v1 发现与示例版本不同后，改用实际 v3 核查，未混用证据 |
| [记忆综述 v1](https://arxiv.org/html/2404.13501v1) | §5.2 文本/参数表示的区别与 §5.3 读写/管理机制；分类关系、读取方式与限制必须承接，不只保留术语。四类 §8 主题在目录映射中有去向 |

按最终协议人工复核的场景：

| 输入场景 | 规则取舍 |
|---|---|
| 常见主题的论文/综述推荐 | 优先顶刊顶会与近三年；核论文级影响及关键正文，说明其他条件较弱或未知 |
| 学习经典方法，合适原文较旧 | 基础性、刊会信誉及长期影响优先，可以作主读；年份照实标记 |
| 快速变化的实际应用，新作尚无大量引用 | 核近期范围和当前任务/环境匹配；引用积累期不自动降级，不能冒充高引用 |
| 仅 CCF A 正式长文、近三年且引用达到明确数值 | 严格筛硬条件；不达标或不可核时给零个已核主读，不拿经典或预印本凑数 |
| 本次每日查询从方法研究换到应用/理论方向 | 由本次输入定查询与排序；应用/理论不按名称降级，其他主题见过不等于无价值 |
| “今天有什么新论文”，本次会话没有范围 | 简短询问范围，不套默认方向或读取旧简报推断偏好 |
| 初学者导读与已有读法的结论核查 | 前者按需补概念/例子，后者围绕具体问题；均保留证据条件，理解题不强制 |
| 仅要求理解指定综述 | 完成原文范围内导读，不自动补查新文；指定章节任务继续选读，不强制全篇 |

Workshop 不套正式长文等级，引用未取到记未知而非零，旧研究更新 arXiv 版本不重置研究年份。这是协议路径复核，没有冒充不同模型的真实执行评测。

## 文件与后续状态

运行协议、命令和轻量检查器留在插件目录；评测、报告和旧方案状态只在 maintenance。当前三项优化已落实；跨论文 synthesis 新技能及概念台账未纳入本次范围。下一步真实使用时仍应按正文质量门槛核具体候选，不能以测试通过代替原文阅读或将生成笔记写为本人已读。

本次开发变更可进入提交准备：main 仅选 13 个运行文件（命令、技能、7 个参考协议与 4 个脚本），dev 另保留 5 个维护文件（索引、TODO、评测、清单复核 JSON 与本报告）。候选清单没有 testt/private、个人配置、真实阅读记录或缓存。当前均未暂存、未提交/推送；实际提交时仍按精确清单核暂存快照，不能整枝合并 maintenance 到 main。新一轮联网选文与完整阅读体验观察作为后续使用验证，不冒充本次已完成。
