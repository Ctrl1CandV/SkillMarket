- `reader.html`：题目、导语和正文开头优先；正文保留给定的三个章节与事实边界。桌面为正文与问答侧栏，窄屏改为连续阅读后接问答，并保留页首问答跳转。目录与滚动位置共同决定“当前章节”。范围与回答历史放在问答区域，连接和模型设置放在独立对话框。

## 本地模拟范围与操作

所有状态只保存在当前页面内存，刷新页面会重置。没有真实账号授权、模型请求、数据持久化、第三方上传或计费。

### 阅读与问答

- 两个起始问题可直接发送；也可手动输入，使用发送按钮或 Ctrl / Command + Enter。消息保留历史，显示当次选定的范围；“新对话”清空历史。
- 回答是从本文机制和检验方法编写的本地短答；章节范围固定使用对应章节，整篇范围按问题关键词选择相关短答，不推导实验数值或额外结论。
- 订阅初始已连接。模型变更只有点击“保存设置”才生效；取消或关闭不保存。刷新状态以约 800 ms 的本地延迟模拟读取，再恢复已保存模型。
- 设置底部“原型状态测试”可预置下一次模型读取失败。点击“刷新状态”触发后，保留选择并显示重试入口。
- 断开订阅后保持订阅模式；需重新连接或主动选择 API。API 仅接受有效的 http / https 测试用地址，填写前禁用保存；保存后才切换，不访问该地址，也不索取真实密钥。

### 数据导入

- 本地文件使用 UTF-8 严格解码，限制为 `.csv`、不大于 5 MB。解析支持 BOM、CRLF、带逗号或换行的引号字段以及双引号转义。
- 校验必需列、重复列名、行列数、run_id / method 非空、score 为 0 到 1 的有限数值；预览最多显示前 8 行。有效样例为指定三行，错误样例包含 score=1.4。
- 预览与校验不修改记录数。追加为默认；替换先显示当前记录数和不可恢复的后果，必须勾选确认并点击“确认替换并导入”。
- 页脚“原型状态测试”可让下一次导入失败；文件与选项保留、记录数不变，可直接重试。成功后可继续导入，记录计数按操作更新。
- CloudBox 初始关闭。开启动作先展示上传实验记录及文件名、不上传原始 CSV、关闭不删除既有上传记录等说明，点击“同意并启用”才打开。关闭后更新说明。同步状态与计数全部模拟，没有发送网络请求。

### 作品展

- 作品按钮可打开大图与说明；可通过按钮或左右方向键切换作品，通过关闭按钮或 Escape 关闭。
- 大图中的“到访信息”关闭查看并跳转到到访区；导航和页首链接也支持同页跳转。
