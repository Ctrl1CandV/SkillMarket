# 0.4 页面对照记录

日期：2026-10-24。这是一次有限范围的生成与浏览器自检，不是通用 Skill 评测系统，也不是用户盲评。

## 协议（生成前确定）

- 共同输入：[brief.md](brief.md)，SHA-256 `F37B5A8D7F113A84DEEFE01700E6AFD5F9E6317CE7C8D9DB35ADACFE05810F1A`。
- 两个条件：0.3.3 与 0.4.0。旧版来自 `c8d0ef419f96f0b5fb78fe3eab0b0456b6d8153e`，新版生成前文件哈希见 [candidate-hashes.json](candidate-hashes.json)。
- 使用相同继承模型与推理配置，未覆盖模型；每组一个无历史子代理，一次生成三页。最初仅发指定技能、共同 brief、输出目录，不发假设、预期答案或其他组产物。基线代理等待失效临时目录修复时调用代理列表，被动看到了参考研究总结；其 notes 已记录，不能把此轮称为严格盲测或完全隔离的因果比较。候选代理被明确要求不读取代理列表。
- 生成者不启动浏览器，统一由父代理检查画面与交互。因此该对照检查首轮生成，不能证明技能自主“看图—修订”全流程的增益。
- 每组每场景仅一次，无无技能条件，无跨模型复测；不据此计算通用胜率。任务没有用于旧版调参，但设置与聊天源于用户反馈，不称完全留出；导入用作必要说明边界，展示用作视觉表达边界。
- 功能内容一致，分别记录任务完成、关键事实、信息组织、视觉与交互问题。页面更短或字数更少不直接等于更好。
- 原始产物不人工修饰后充作生成结果。若需要修订，另存修订版并标明；若改技能，再生成的案例转为回归材料。

## 检查范围

桌面 1280×800、手机 390×844；默认首屏与整页；问答和模型保存/加载/失败，CSV 校验/覆盖确认/失败恢复/同步同意，作品查看与到访定位。所有请求仅为本地模拟，不接入真实账号或传输实验数据。

## 实际观察

以下是父代理的界面与行为检查，不是用户偏好投票，也不能把单个样本差异唯一归因于技能改动。另一位代理未读父代理结论，独立查看了 14 张默认/设置截图并补看载入样例的导入图；它知晓版本，属于 AI 图片复核，不称盲评。

| 场景 | 观察到的变化 | 保留的问题与结论边界 |
| --- | --- | --- |
| 阅读、问答与设置 | 候选移除了旧样例的额外导语、文中提问式装饰和聊天用途说明；正文更早出现。设置去掉了“授权正常情况下自动续期”“修改后请保存”，保留连接、模型、刷新和显式保存。390px 下标题没有旧样例末尾单独一个“好”字的断行。 | 候选仍有“从一个问题开始”等可删引导；保存后“设置已保存”会重复出现；桌面问答面板偏长，1280×800 初始视口下输入区底部约在 y=865，仍需滚动。去掉说明不自动解决空间分配。 |
| 数据导入 | 候选保留编码、大小、必需列与 score 范围；第三方数据去向在启用前出现。两版都能校验、确认替换和失败重试。 | 两版初始状态不同：旧版自动载入样例，新版未选文件，不能直接用页面长短比较。相同样例状态另有截图。候选仍将选择、预览、模式、同步拆成多个卡片；未选文件时预览留白较大，“预览不会改动项目记录”仍常驻，没有观察到结构全面收敛。 |

### 行为检查

- 阅读：两版均通过章节范围选择、快捷提问与本地回答检查；均检查了显式模型保存、加载、失败与重试入口。候选额外复核了重试恢复为已保存的“深入”、新对话清空和断开订阅后仍停留订阅方式。两版主动选择 API 时都能看见计费提示。
- 导入：两版 score=1.4 都被定位为错误并阻止导入；替换弹窗先显示清除 24 条、导入 3 条及不可恢复性，未确认时不能执行；同步入口先展示 CloudBox、上传范围和关闭后果，并可取消；一次失败保留文件/模式且总数仍为 24，重试后总数为 27。
- 展览：两版均能打开《留白》的大图与说明，用 Escape 关闭，并跳转到到访信息。
- 响应式：六页在 390×844 检查中均未发现文档横向溢出；1280×800 与手机整页截图已保存。模态截图截取视口，其他截图为整页。截图的实际内容宽度可能扣除系统滚动条。

**发现的真实缺陷：候选导入成功后，主结果与项目总数正确为 27，但右栏“导入后”预估又加了 3，显示 30。** 导入按钮已禁用，没有重复写入，但成功状态的信息不一致。生成者冻结后静态复查和父代理浏览器检查均发现此问题。原样保留，不能将该页宣称为交互完全通过，也不为单个样例再往 Skill 添加一条专用计数规则。

未完成：真实账号/网络/持久化、文件选择器与拖放的端到端操作、全部键盘路径、真实触屏/屏幕阅读器、逐元素对比度与实际字体回退检测。生成者执行的脚本语法、CSV 解析和 DOM 桩测试只能支持其各自说明中的代码层结论。

## 本轮结论与后续

0.4 已解除几处相互牵制的内容规则；在本轮阅读与设置样例中，减少常驻解释的方向得到有限支持，必要的错误恢复和决策信息仍在。展示样例保留了视觉表达。独立图片复核同样认为阅读/设置有所改善，导入却从两个主卡片增至四块，载入后仍保留过大的文件选择区，手机操作距离也值得继续检查。导入样例的分区、留白和成功状态仍有问题，因此本轮不作“全面胜出”“可以免验收”或“已降低 token 成本”的结论。

这些页面转为回归材料。下一步用新的真实任务、多次生成、用户偏好反馈与完整“渲染—修订”流程检验稳定性，再考虑跨模型与成本比较。相关未完成项保留在 [TODO](../../TODO.md)；此目录不是 skill-eval 插件的提前实现。
