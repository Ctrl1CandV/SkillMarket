# frontend-craft v0.2.0 应用小样：设计决定与检查记录

日期：2026-10-03。产出：仓库根目录 `evening-radio.html`、`field-notes.html`（自包含，无外部资源），以及本目录（`check.mjs` 与本记录）。拥有范围仅此三处；未改动 frontend-craft 技能、未提交 Git。

## 边界（SKILL 第 1 步）

- 使用情境与任务：两份互链小样用于检验 v0.2.0（布局优先 + 视觉完成度）在真实题材上的效果。电台页主任务=浏览今晚节目单、选定一段并做无声播放演示；植物志主任务=连续阅读一篇观察手记并翻查台账。
- 内容来源：电台名称、频率、时段、曲目、主持人，植物志期号、地点、人物、观察原文均为**标注的虚构创作**；植物学描述取公开常识，不构成鉴定。页面顶栏与页脚各有一处声明，非满屏遮罩。
- 参考角色：`frontend-craft/` v0.2.0（SKILL + layout/visual-style/landing/reading/workspaces/verification）为方法参考；`frontend-design` 技能为视觉方向参考（签名元素、避开通用默认）；`maintenance/frontend-craft/evals/workbench.html`、`reading.html` 为**负面参照**——后台壳（侧栏+工具栏+条目列表）、系统默认字体质感、等权信息条目，本次明确避开，不复刻其布局换皮。
- 假设：桌面主视口 1280×800，手机 390×844；无授权素材 → 全部原创 SVG；无音源 → 明确"无声演示"，不假播放。

## evening-radio.html「晚间电台 92.4」

- **内容关系 → 结构**：主对象是今晚三时段九段曲目；选定与播放是全局状态，播放台必须与节目单同屏 → "节目单行列表 + 右栏 sticky 播放台"的列表加详情结构。节目单按广播习惯以时段分块、以分隔线分行（非卡片网格），行内：起始时间（mono）｜曲名（衬线）｜艺人·氛围｜时长｜选定按钮。
- **字体角色**：展示=中文衬线（宋体系）巨字 clamp(68px→188px)，细画海报感；正文/UI=无衬线；时间/频率/状态=等宽 + tabular-nums。样张在写码前以真实曲目名、中英混排（"Neon Overpass""Rain on the Awning"）推演过换行；曲名 `overflow-wrap:anywhere`。
- **色彩角色与面积**：深墨蓝 #0B1630 底（层级面板 #15264A/#0E1B38），文本三级 #E8EEFB/#AEBBE0/#8B9CC9；主强调酸橙 #CDF25A 只落在"当前选定/播放态/焦点"（小面积指向任务）；珊瑚 #FF8A70 只用于播出标记。16 组对比度对在 check.mjs 中按 WCAG 计算，全部 ≥4.5:1。
- **素材与签名**：hero 一条横贯的原创波形 SVG（pathLength 描画一次，加载动画）；播放台原创唱片 SVG——唱片永不旋转（不假播放），**唱臂**在选定/未选定间摆动，作为选定状态的图形指示（状态有文字同报，不靠颜色）。
- **交互与诚实边界**：氛围筛选（aria-pressed 互斥 + 计数播报）；选定（原地更新行状态，不重建 DOM——焦点不丢失；aria-current + 按钮文案）；播放/暂停只在界面文字与按压态间切换，按钮初始禁用、选定后可用；播放台常驻"无声演示"声明，页面无 `<audio>`、无音源。被筛选掉的选定保留（播放台与播放可用性不变）。
- **窄屏重组（≤960px）**：播放台转底部固定条（隐藏唱片与长声明，保留曲名/元数据/状态两行/播放钮），body 预留底部空间；曲目行重排为两行网格（时间+曲名 / 选定钮），时长并入次要位。
- **动效**：仅载入描画、标题字升入、播出点脉冲、唱臂过渡；`prefers-reduced-motion:reduce` 下全部禁用，内容与功能不变。

## field-notes.html「街角植物志 · 第 14 期」

- **内容关系 → 结构**：一篇连续阅读的手记（四章）+ 按需档案（八条观察台账）。左窄栏（220px，sticky）=目录 + 观察元数据，右宽栏正文约 40em 行宽；台账独立为整宽色带区（纸灰底），与正文用底色和边界分开——与电台页的"行列表+状态面板+筛选"结构明显不同。
- **不对称编辑式版式**：图版（乌桕枝 SVG）≥1200px 时负外边距 -72px 伸入栏沟；首字下沉；楷体引文块带赭色左线；章节号 + 赭色短上规线。目录在桌面常开（summary 隐藏），手机变 details 可展开块（不遮正文）。
- **字体角色**：正文与展示=宋体系（印刷书卷气，17.5px/1.95）；图注、引文、观察摘录=楷体（手记声线）；控件与台账摘要=无衬线；日期=等宽。行宽约 40em（≈40 汉字）。
- **色彩角色**：纸白 #F6F1E6 底 / 台账纸灰 #EFE7D3 / 页脚森林深底 #1F3A28；森林绿 #2E5339 承担标题与链接；赭 #9A5A20 为文本级强调（日期、眉题，纸上 4.87:1），#C97F35 仅作图形填充（短规线、括线），不作小字文本。8 组对比度对全部通过计算。
- **素材与签名**：原创乌桕枝 SVG（role="img"+title）：一根主枝、七片菱形叶（绿→黄→赭三色）、两枚三裂蒴果、地面虚线上落叶与两粒白籽——对应"三色同枝"章节的叙事，不是装饰填空。楷体注释声线 + 首字下沉 + 标本签台账共同构成记忆点。
- **交互**：目录锚点（scroll-margin 防遮挡）；台账 8 条原生 details（日期·物种·地点在摘要行，展开含天气/观察/下一步，"未能定种"如实标注）；全部展开/收起按钮 + role=status 播报。
- **窄屏重组（≤880px）**：单栏；目录 details 可折叠；图版收窄回栏内；台账摘要行重排（地点换行），正文内边距收紧。

## 与通用默认的区分（frontend-design 校准）

Brief 指定了两套色系（深墨蓝/酸橙、纸白/森林绿/赭），按 brief 执行；在此前提下避开 AI 默认面孔：不做"纯黑底+单一酸绿强调"（用分层海军蓝面板、珊瑚副强调、衬线海报字、双角色系统区分），不做"奶油底+赤陶衬线"的落地页脸（用楷体注释声线、标本签 details、图版负边距与台账色带区分）。两页之间结构、字距、组件形态均无复用。

检查分层（对照 verification.md 的四类结论，本脚本只覆盖前两类）：

1. **源码/静态检查**：doctype/lang/viewport/title、恰好一个 h1、地标与跳转链接、页脚互链目标存在、id 唯一、全部锚点可达、无任何外链 src/href、无 `url()`/`@import`/`<audio>`、`prefers-reduced-motion` 两种设置、窄屏断点、`overflow-wrap`、`tabular-nums`、`role="status"`、装饰 SVG `aria-hidden`、植物图版 `role="img"+title`、标签栈配平（剥离 script/style 后逐开合标签校验）。
2. **自动检查（计算类）**：16 组前景/背景对比度按 WCAG 相对亮度公式计算，并核对该色值确实声明在页面里（防漂移）。
3. **mock-DOM 交互模拟**：页面脚本经语法编译后在最小 fake DOM 中执行——电台：初始渲染 9 段 3 块、播放禁用、筛选雨夜 3/9 与计数播报、按压态互斥、选定（aria-current、播放可用、状态播报"没有音频"）、播放/暂停切换文案、被筛掉选定保留、筛选往返高亮保留、切换选定后旧行清理且高亮唯一；植物志：台账全收起初始态、全部展开/收起生效并播报。
   **这是模拟，不是真实运行**：不覆盖 CSS 生效、几何、焦点真实移动与合成事件。

## 未验证事项（不假称通过）

- **视觉未验证**：无浏览器，未生成任何截图；构图、字体气质、色彩面积、素材质量、波形/唱片/乌桕图版的实际观感均未看过，不能宣称视觉通过或达到标杆。
- 浏览器渲染、390/1280 真实几何（含播放台底部固定条与图版负边距）、真实键盘走查、200% 缩放回流、读屏、性能均未验证。
- 已知待观图风险：宋体大字号的实际渲染气质、SimSun 无真粗体（700 为合成粗）、`::first-letter` 首字下沉跨浏览器表现、唱臂 `transform-box:view-box` 需现代浏览器、波形 preserveAspectRatio="none" 拉伸后的观感。
