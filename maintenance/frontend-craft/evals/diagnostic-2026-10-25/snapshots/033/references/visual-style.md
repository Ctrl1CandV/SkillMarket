# 视觉样式

## 大众审美的几条依据

下面几条来自大样本的偏好研究，它们说明的是多数人第一眼的感受，可以作为个人判断之外的参照：

- **复杂度适中偏简洁，但不能空。** 视觉复杂度和好感呈倒 U 形：最受欢迎的页面偏简洁，太复杂扣分最重，太空也会扣分。适中的复杂度来自文字、颜色和图形之间的平衡。降低复杂度靠清楚的分区、统一的对齐和较少种类的样式，不靠删内容。
- **先像这一类页面。** 越接近人们心目中这类页面的样子（原型性），第一眼越被认为好看。管理后台就该像工作区，阅读页就该像文章或书页，作品集要让作品当主角。个性放在一两处主题特有的细节上，骨架遵循惯例。
- **颜色适度丰富，但整体统一。** 色彩丰富度和好感也呈倒 U 形，中文用户整体比北欧用户更能接受颜色丰富的页面。丰富要来自同一色系里的明暗层次，而不是同时出现好几种饱和的色相。
- **配色用相近的色相，拉开明度。** 色相相同或相近、明度差距明显的组合，最常被评为和谐又好看。整套配色控制在 2–3 个色相为宜。

## 方向：在惯例的骨架上找主题特色

- **先确定页面类型的惯例**：管理和数据页是紧凑的工作区，阅读页是居中的单栏加目录，展示和艺术类页面大图、大标题、多留白，产品介绍页按“是什么、为什么信、怎么开始”分段。
- **再找签名元素。** 列出这个主题特有的材料、器物、文档格式和用语，挑一两样做成只有它才有的组件或图形。比如样本库的孔板定位图、任务行里的状态进度点、纪要里指向原话的编号。签名元素放在惯例骨架之上，不去改变骨架本身。
- **有设计参考说明就按它定方向。** 没有的话，先写一句方向描述（比如“像实验室台账一样，密而有序”），后面每个样式决定都拿它来检查。

## 字体

- **角色**：标题、正文、界面文字、数字与编号，各定一种处理方式。一款黑体配几个字重往往就够了；宋体等衬线体适合正文阅读和需要书卷气的标题；等宽字体适合编号、时间码和代码。
- **尺度随页面类型变化**：
  - 数据密集的管理页：界面文字 13–14px，表格行高 36–44px。
  - 十几到几十条的个人列表：条目标题 15–17px。
  - 阅读页：正文 16–18px。
  - 展示页：标题可以很大。
- **至少一级标题要拉开差距**，让层级一眼可见。
- 中文字体的细节见[中文排版](cjk-typography.md)。

## 颜色

**先统一，再谈色相。** 好看的配色首先是整页统一在一个色调里：色相范围窄，饱和度低，状态色也向这个色调靠拢。常规的配色只要统一，同样能做出好页面，优化不等于非要和常见做法不同。白底上同时出现饱和的蓝、红、黄、绿，色相反差太大，页面就会显得突兀。

- **冷暖按场景选。** 管理和工具页多用冷色或中性色，显得冷静、清楚；生活、阅读、展示类页面可以用暖色。两种都可以做得好看，关键是统一。
- **饱和度要低。** 主色的饱和度适中（OKLCH 的 C 约 0.06–0.10）。大面积底色接近中性（C 不超过 0.015）。成功、警告、错误这些状态色也降低饱和度（C 约 0.06–0.09），靠色相区分，不靠鲜艳。
- **避开大面积的暗沉色。** 棕色、暗黄、橄榄绿是大众最不喜欢的几种颜色；研究里就算参与者喜欢巧克力，深橙棕色本身仍然不受欢迎。米色、浅驼色这类低饱和的暖中性色没有这个问题，可以放心用作底色；饱和的深棕色块不要铺满侧栏或首屏。主题自己的颜色可以缩到图标、强调数字这些小面积上。

**生成阶梯**：用 OKLCH 生成一整套明度阶梯，各级明度差距均匀，看起来更舒服：

```css
:root {
  --h: 250;                                   /* 主色相 */
  --bg:      oklch(98% 0.008 var(--h));       /* 页面底，带一点主色倾向 */
  --surface: oklch(95% 0.015 var(--h));       /* 分区底色、浅色色带 */
  --line:    oklch(88% 0.02  var(--h));
  --muted:   oklch(52% 0.03  var(--h));       /* 次要文字 */
  --ink:     oklch(25% 0.03  var(--h));       /* 正文 */
  --brand:   oklch(45% 0.08  var(--h));       /* 主色：标题强调、选中项、主要按钮 */
  --accent:  oklch(62% 0.09  calc(var(--h) + 40));  /* 强调色：相邻色相，小面积 */
  --danger:  oklch(50% 0.09  22);             /* 状态色也降低饱和度 */
  --warn:    oklch(52% 0.07  70);
}
```

- **面积分配**：
  - 大面积用浅色和中性色。
  - 分区优先用浅色色带（`--surface`）。深色饱和的大色块全页最多一两处，比如页脚，或一个最关键的区块。
  - 工具页的导航栏和侧栏用中性色，不要铺满主色。
  - 主色用在选中项、主要按钮、标题强调这类中等面积上；强调色只用在当前状态、需要注意的数字这类小面积上。
- **语义色**：成功、警告、错误单独定，不和主色、强调色混用。
- **状态表达**：用颜色加形状或文字一起表达，比如实心、半实心、空心，图标，文字标签。
- **对比度**：在实际底色上计算。正文 4.5:1 以上，大字和控件边界 3:1 以上。
- **深色主题**：单独调整。大面积降低亮度，强调色适当提亮，状态色重新核对。

## 素材与图形

- **先想清楚它承担什么信息**：说明流程、展示真实对象，还是营造氛围。能由数据本身画成的图形，比如进度点、分布条、孔板、时间轴，优先于装饰插画。
- **没有获得授权的素材时**，用排版、色块和由数据生成的图形完成画面。

## 细节

- **圆角、边框、阴影**：各定 2–3 档，全页统一。
- **阴影**：只给浮在页面上的东西，比如弹层、下拉菜单、拖动中的卡片。
- **图标**：用同一套、同样的线宽，和文字基线对齐。
- **编号、日期、ID**：用等宽字体或 `tabular-nums`，对齐成列。

## 依据

- Reinecke & Gajos，[Quantifying Visual Preferences Around the World](https://www.eecs.harvard.edu/~kgajos/papers/2014/reinecke14visual.shtml)，CHI 2014：约 4 万名参与者，复杂度与丰富度均呈倒 U 形，存在地区差异。
- Tuch et al., The role of visual complexity and prototypicality regarding first impression of websites, IJHCS 2012：低复杂度、高原型性的页面第一眼最被认为好看。
- Palmer & Schloss, An ecological valence theory of human color preference, PNAS 2010：颜色偏好来自它联想到的物体，蓝色最受欢迎，暗黄、棕色最不受欢迎。
- Schloss & Palmer, Aesthetic response to color combinations, Attention, Perception, & Psychophysics 2011：色相相近、明度不同的组合最受偏好。
- O'Donovan, Agarwala & Hertzmann, Color Compatibility From Large Datasets, SIGGRAPH 2011：偏好 2–3 个色相、明度变化明显的配色。
