## 本次改动

只写入 `page.revised.html`，首稿保持不变。

- 400px 以下将文献标题从 15px 改为 16px、元信息从 12px 改为 13px；手机搜索输入改为 16px，备注分享说明改为 13px。
- 手机筛选按钮最小高度从 32px 改为 36px；备注入口最小区域设为 44 × 32px，通过小幅负外边距限制对行高的影响。
- 手机导出区减少标题、选择数、格式与备注组之间的空隙，选择数字从 43px 改为 36px，主按钮最小高度从 44px 改为 46px。保留原有主侧栏排列和桌面样式。
- 将失败文案改为“文件未生成，所选文献与选项已保留。”，减少原有尾部孤行。
- JavaScript 与首稿完全相同，未改变筛选、选择、导出内容、一次失败及重试行为。

## 本轮自检

- 使用 Node.js 比较首稿和修订稿的内联 JavaScript，确认逐字符相同，并通过 `vm.Script` 语法解析。
- 检查响应式修改和新失败文案已写入，旧失败文案已移除。
- 检查静态 ID 无重复、没有远程脚本／样式／资源依赖。
- 校验 `page.initial.html` SHA256 与首稿交付值一致；`notes.initial.md` 也保留原值。
- 本轮未重复运行首稿的 DOM 替身逻辑测试，因为脚本没有变化；此前结果不等于真实浏览器验证。
