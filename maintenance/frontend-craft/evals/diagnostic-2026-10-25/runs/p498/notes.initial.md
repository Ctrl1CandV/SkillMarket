## 实现范围与编排

- 六篇文献完整保留标题、作者、年份、类型、阅读状态和私人备注。
- 主栏提供标题或作者搜索、阅读状态筛选、单篇勾选及选择当前结果；侧栏集中呈现全部已选数量、清空选择、文件格式和备注选项。
- 切换搜索或筛选不删除已选项；侧栏明确提示当前结果之外的已选数量。
- 默认不选择文献，格式为 Markdown，默认不导出私人备注；无选择时禁用导出。
- 导出始终按输入中的集合顺序，下载名为 `组会候选.md` 或 `组会候选.txt`。两种格式包含标题、作者、年份、类型，备注由用户勾选决定。
- 使用原生输入框、复选框、单选框、按钮、details/summary、锚点和可见焦点样式。窄屏 CSS 将导出区域移至列表下方，并提供“前往导出”页内入口。
- “验收入口”可使下一次导出失败；失败路径不创建文件、不触发下载，保留选择及导出设置，并把主按钮改为重试入口。

## 已执行的静态与逻辑自检

未启动浏览器。以下检查由 Node.js VM 的最小 DOM 替身及 Python HTMLParser 完成，不等同于真实 DOM 或浏览器验收。

- 脚本通过 `vm.Script` 语法解析。
- 核对初始六条记录、空选择、禁用导出、默认关闭私人备注。
- 检查按作者搜索、阅读状态与搜索组合、无结果与未读集合结果。
- 检查筛选之外的选择保留，隐藏选择计数正确。
- 逆序加入选择后，导出仍按输入顺序排列。
- 检查 Markdown 和纯文本生成内容，必要字段及私人备注开关。
- 检查模拟失败时未创建 Blob URL、未触发下载；选择、格式及备注选项保留。
- 检查重试成功、成功后选择保留、两种下载文件名，以及清空选择后阻止导出。
- HTMLParser 可解析页面；静态 ID 无重复，静态 label 及页内链接目标存在。
- 检查无外部资源引用、网络请求代码或浏览器持久化代码。
- 检查中文语言声明、viewport、Windows 系统字体与手机断点存在。

以上自检均通过。未保留额外测试脚本或中间产物。

## 本地模拟边界与尚未验证

- 数据为固定原型样例，不对应真实出版记录，不提供全文链接。
- 所有选项和状态仅存在当前页面内存中；刷新恢复初始状态。
- 不请求账号、不连接后台、不发送数据；文件通过浏览器 Blob 与下载链接本地生成。
- “导出成功”表示文件内容已生成并发起下载，不能确认用户是否在浏览器下载界面保存了文件。
- 未查看桌面或手机实际渲染画面，未验证实际使用的中文字体、换行、溢出、对齐、首屏与整页效果。
- 未在真实浏览器验证键盘遍历、焦点可见性、屏幕阅读器播报、真实事件委托、文件落盘和手机触控。
- 视觉检查及必要修订留待统一截图阶段，本阶段没有基于截图的效果结论。
