# 首稿交付记录

## 输入与读取范围

主动读取的任务输入仅为本工作包中的 `common.md`、`research.md`。
代码自检读取了本次生成的 `output/page.initial.html`。未读取仓库文件、其他工作包、设计 Skill 或其他代理信息；未联网，未启动浏览器。
第一次 PowerShell 调用自动加载了环境配置，并出现 conda 配置警告；任务输入仍成功返回。其后 shell 调用均关闭登录配置，所有 shell 调用均显式指定本工作包为工作目录。

## 页面实现

- 单文件 HTML，内嵌 CSS、JavaScript 与 SVG 图形。采用 Windows 系统字体回退，无远程资源及构建依赖。
- 首屏显示集合的全部 6 条样例文献，默认未选择，Markdown 格式，默认不包含私人备注。
- 按标题或作者搜索，按阅读状态筛选；逐条选择、选择当前结果和清空选择。
- 改变搜索与筛选时保留全部选择；导出面板显示筛选结果之外的已选篇数。
- Markdown 与纯文本均按原始集合顺序导出标题、作者、年份、类型；可选包含私人备注。
- 文件名为 `组会候选.md` 或 `组会候选.txt`。生成 Blob 并通过浏览器下载链接发起下载。
- 导出区的「原型验收」折叠入口可以使下一次有选中文献的导出失败。模拟失败不生成文件，保留选择与设置，随后可以重试；成功后继续保留选择。
- 使用原生搜索框、下拉框、复选框、单选框、按钮和 details；提供可见键盘焦点和状态播报。CSS 包含桌面、平板、手机布局断点。

## 模拟边界与尚未验证

- 记录为给定样例，不代表真实论文；不提供全文链接，不连接账号或后台，不发送数据。
- 选择、格式、备注开关和失败标记仅存在当前页面内存，刷新后恢复初始状态。
- 失败为显式验收入口触发的本地模拟，不模拟真实网络故障。
- 下载成功提示表示页面已生成文件并发起浏览器下载，无法确认用户是否在浏览器中最终保存文件。
- 尚未验证：实际浏览器下载、真实键盘操作及屏幕阅读器表现、各视口排版、字体最终呈现、颜色与间距的截图效果。本阶段未启动浏览器，未做截图或视觉修订。
