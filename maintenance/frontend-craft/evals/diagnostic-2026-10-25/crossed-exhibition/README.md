## 精确变化

来源为 `../../v0.4/runs/baseline/exhibition.html` 和 `../../v0.4/runs/candidate/exhibition.html`。每页有三个根 ID 为 `art-0`、`art-1`、`art-2` 的作品 SVG。交叉条件按作品序号逐个用另一来源的完整 SVG 替换：包括 SVG 根属性、viewBox、内部 title、defs、路径、渐变与滤镜。两来源都使用相同根 ID，现有大图脚本仍从对应根节点复制图形，因此无需改变脚本。

- CSS、JavaScript、SVG 之外的页面文字、标记、按钮与链接均保持原来源逐字节一致。
- 两个对角条件是原 HTML 的逐字节副本。
- 原始六个 SVG 都不使用 CSS 变量、`currentColor`、继承颜色或类名样式；填充、线条及渐变颜色已经是字面值，无需按接收页面替换颜色。
- 素材不做裁剪、补画、调色、统一比例或质量修饰；原 CSS 如何缩放/容纳素材就如何保留。
- 源文件、输出文件、非 SVG 内容、CSS 和脚本的 SHA-256 与替换数量见 [manifest.json](manifest.json)。原始生成脚本是上级 `prepare_assets.py`；它保留生成时的 layout-* 命名，现存输出按 A–D 与 `combination` 字段追溯。

## 解释限制

“框架”包含原来源的排版、页面配色、可见文案与行为，不能解释成只有布局几何不同。素材自身的宽高比分别是：旧版 720×680、720×650、620×650；新版 640×650、700×610、520×620。替换后，按原 CSS 自动计算的显示高度或整页高度可能变化；固定比例容器也可能出现不同的边缘留空。这属于素材与原呈现规则的相互作用。

SVG 内部的无障碍标题随素材更换，SVG 之外的作品说明仍随框架保留。两来源使用同一组作品名称，因而不需要改写可见说明。交叉后偏好随素材移动可支持“素材解释了部分原始偏好”，但不能据此推断某版 Skill 一般更强；框架和素材的匹配也可能影响判断。
