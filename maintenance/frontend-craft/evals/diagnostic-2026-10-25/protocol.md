# Frontend craft 诊断对照协议

日期：2026-10-25。状态：准备稿，等待调用者复核、冻结输入后执行。本文不是实验结果。当前目录中的交叉展览页是既有产物的诊断副本，不是本轮待评页面。

## 要回答的问题

1. 在没有额外布局或文案方法提示的任务中，0.4.0 相对 0.3.3 是否产生可重复、用户能感知的改善？
2. 两版相对无设计 Skill 的差异有多大？该条件用于观察模型和共同任务本身已有的能力，不代表去除模型训练中的设计知识。
3. 同一作者获得统一渲染截图后的一次修订，是否改变首稿比较？
4. 另用旧展览产物的 2×2 副本，检查用户的原始偏好是否随素材来源改变。这与新任务实验分开解释。

本轮不修改 Skill，不按单个生成问题追加规则。每格只有两次独立生成，只支持发现大而稳定的差异和定位后续问题，不计算通用胜率或声称统计显著。

## 冻结输入

共同请求是 `inputs/common.md`，每个生成者另读一个任务：

| 任务代号 | 任务文件 | 附加素材 | 新任务与控制范围 |
| --- | --- | --- | --- |
| research | `inputs/research.md` | 无 | 个人文献清单的查找、选择和本地导出；没有聊天、账号续期、CSV 导入或云同步。 |
| collection | `inputs/collection.md` | `inputs/assets/work-01.svg`、`work-02.svg`、`work-03.svg` | 刊物编辑浏览和收藏线上作品；不是旧的线下展览到访页。作品图固定复用旧产物，不能称为完全未见素材。 |

请求给目标、事实、功能、业务边界与运行条件，不给布局、减文案方法、卡片数量、风格排除词或页面配色答案。给定 SVG 的固有颜色仍可能引导页面配色，这是共同素材的一部分，应在解释中承认。

调用者复核后对上述请求、素材及两个完整 Skill 快照计算 SHA-256 并记录冻结清单。0.3.3 来源为 `maintenance/frontend-craft/archive/v0.3.3-2026-10-24/`；0.4.0 来源为 `frontend-craft/`，冻结时复制完整 `SKILL.md` 与 `references/` 到本轮只读快照。冻结后不直接依赖继续维护中的 Skill 文件。执行前记录实际模型、推理配置、工具能力和运行顺序；12 次保持一致，能力或配置变化时另开批次，不混算。

`asset-provenance.json` 和 `crossed-exhibition/` 只供组织者核查，不交给生成者。它们记录旧产物版本，且并非完成新任务所需输入。

## 每个生成者的输入与隔离约定

派发只包含共同请求的绝对路径、本次任务及指定素材的绝对路径、该条件的 Skill 快照入口（无 Skill 时明确没有）、本次输出目录、阶段说明。不要发母会话、协议、研究摘要、待证假设、预期方向、评语或其他组产物。

首稿阶段允许读取：

- 明确指定的共同请求和本次任务文件；collection 可读明确指定的三个 SVG。
- Skill 组的指定快照入口及该快照内部被引用的参考文件；无 Skill 组无此权限。
- 自己本次运行输出目录的文件，以及完成本地写入和代码自检必需的工具使用说明。遵守系统或项目中必须生效的指令，但不主动搜索额外设计资料。

禁止列出、读取或向其他代理/会话发消息；禁止读取其他运行、旧评测页面、仓库其他材料、当前运行 Skill、溯源文件或外部设计参考；禁止加载其他设计 Skill、网页搜索或派生代理。不得通过代理列表查询调度或路径修复进度。路径不可用时只向调用者报告精确路径，等待调用者修正。

这些是实验行为约定，不宣称文件系统已经实现了访问隔离。记录读文件与工具使用；发生意外披露则标记该运行受到污染，从主要比较中剔除，并用新无历史代理替代，原记录保留。任何必须生效的环境指令造成条件差异，也应记录，不能隐去。

## 首稿与一次修订

1. 生成者实现页面并做必要代码自检，交付 `runs/<运行ID>/first.html` 与 `first-notes.md`。首稿不启动浏览器、不读取截图。notes 只记录读取材料、实现与自检、模拟范围、未验证事项，不写跨条件比较。
2. 调用者保存首稿哈希，之后不得覆盖首稿。由同一浏览器、字体环境及缩放设置统一加载页面，复位初始状态，在桌面 1280×800、手机 390×844 获取默认首屏与整页。再按下述固定操作获取一个非默认状态，并记录实际操作。截图保存到该运行独立目录。
3. 调用者把该运行自己的截图路径和客观的视口/状态名称给原生成者，不附“这里太空”“应该更简洁”等评价、他组截图、排名或用户偏好。不选择性只给某组失败截图；统一执行预定状态。若页面无法完成预定操作，仍记录实际画面，并仅陈述阻止该操作的客观错误或未发生的状态，不提供修法。
4. 原生成者仅基于任务、自己首稿和这组截图进行一次修订，交付 `revised.html` 与 `revision-notes.md`。无 Skill 组同样获得截图与同样一次修订机会。不得改首稿；修订阶段只新增读取本运行截图与自己产物的权限。阶段仍由调用者统一渲染，生成者不自行启动追加的浏览器循环。
5. 调用者以相同宽度、状态和操作重新检查修订版。停止本轮修订；未解决问题如实保留。若首稿无需修改，可原样复制为修订版并说明。最终保留 12 个独立生成运行的首稿和修订稿，不把 24 个文件当作 24 个独立样本。

这个安排测试“统一截图后的一次自我修订”，不是任意自主浏览器循环的完整增益。各阶段给所有条件相同操作机会；记录耗时与工具量，不预设或宣称成本降低。

## 统一状态与验收动作

research：

- 默认状态：6 条全部可见，0 条选择，Markdown，不含私人备注。
- 操作：选择 P01 与 P03，搜索“林知远”，确认被筛掉的 P03 仍被选中；切换纯文本并包含备注；使用验收入口使下一次导出失败。在桌面截取失败后的当前画面作为非默认截图。记录是否保留两项选择与导出选项。
- 行为核查：重试应只下载一次，文件含 P01、P03 及对应备注，顺序按输入；清空选择后不能导出。也检查一次 Markdown 不含备注的下载。下载内容是功能证据，不当作视觉分数。

collection：

- 默认状态：全部 3 件作品，收藏数 0。
- 操作：查看《留白》，在桌面截取大图与说明的画面作为非默认截图；关闭查看后收藏《留白》，切到“已收藏”，确认仅此作品，再取消收藏并返回全部作品。
- 行为核查：作品事实和图像准确，开关详情、收藏和筛选可用，键盘能完成主要操作。不得因某版额外增加非必要功能就给审美加分。

所有条件都核对桌面和手机横向溢出、内容可达、必要控件与状态。失败的实现按实际状态留证，不手工修好后才截图。该清单用于组织者一致验收，不额外发给首稿生成者。

## 比较方法与结论边界

评审包隐藏版本、运行 ID 与生成顺序，使用随机标签和随机左右位置。按同一任务、同一阶段、同一状态比较，允许平手。用户可以分别给出整体偏好、排版与空间、阅读/操作清晰度、素材呈现的判断；功能完成、错误与事实保真另列。不要用字数、卡片数量或额外功能直接代替好坏。

首稿比较与修订稿比较分开，同时检查同一运行修订前后的变化。两次重复方向不同就报告不稳定，不挑最好的一次代表条件；视需要仅为有分歧的任务追加第三次，明确属于后续追加。有人已见版本或能从页面识别来源时，标明不完全盲评。

## 原始展览的素材交叉诊断

见 `crossed-exhibition/README.md` 与 `manifest.json`。四份 HTML 来自上轮既有页面：0.3.3/0.4.0 的页面框架分别配 0.3.3/0.4.0 的三件 SVG。只替换完整作品 SVG，非 SVG 内容、CSS 与脚本不变，对角条件逐字节等同原件。素材内部 title、viewBox、颜色和图形随素材整体变化；原页面仍按原 CSS 呈现。

它可以帮助判断现有偏好随哪套图形移动，不能证明 Skill 的一般因果效果。“框架”包含原页面排版、文案、颜色与行为，不是孤立的几何布局变量；SVG 的宽高比差异也可能影响自动高度和整页长度。素材与框架存在匹配关系，交叉后不好看可能是交互作用，不能只算素材或只算布局的责任。诊断副本不混入本轮 12 次生成。
