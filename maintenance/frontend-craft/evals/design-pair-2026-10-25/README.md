# 拾声：档案后台与声音专题

两个页面使用同一套虚构口述档案素材与品牌，各自服务不同的任务。管理后台围绕录音和逐字稿校对；访客页面围绕一段声音展开专题浏览。相同品牌没有让两页采用相同的密度或版式。

- [档案管理后台](management.html)：今日待办、校对队列、逐字稿编辑和录音档案清单。
- [声音艺术专题](river-archive.html)：原创 SVG 渡口构图、专题文字、片段索引与示意地图。

档案、人物和引文均为虚构内容；录音没有接入。按钮只展示本地页面状态，不会提交后台或发布内容。两页使用内嵌 CSS、JavaScript 和 SVG，双击 HTML 即可在支持 HTML 的浏览器中查看，无需安装依赖或运行构建。

## 用户反馈

2026-10-25，用户认可声音艺术专题，认为管理后台难看，并指出使用该技能制作的多个页面配色相似。随后以工作区 frontend-craft 0.4.2 为对象完成[拆解](../management-v042-review-2026-10-25/analysis.md)并重做管理页；用户认为新稿比原稿更差，要求先按项目规范提交两个技能，等其阅读报告、给出思路后再优化。保留两轮原样例，不把它们记录为已验证的整体设计收益。
