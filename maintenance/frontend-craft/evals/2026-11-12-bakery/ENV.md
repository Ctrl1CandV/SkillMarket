# 机器环境

- Windows 10，命令通过 Git Bash 执行。路径可以写成 `/c/Users/...` 或 `C:\Users\...`。
- Node v24。`playwright-core` 装在环境变量 `FC_NODE_MODULES` 指向的目录，不在当前目录。
- 浏览器用本机 Chrome，路径在环境变量 `FC_CHROME` 里。
- 中文字体是系统字体：微软雅黑（Microsoft YaHei）、黑体、宋体、楷体、等线，以及 Noto Sans SC（可变字重）。没有 Noto Serif SC。
- Python 3 可用（`python`），带 numpy、Pillow。
- 没有外部图片素材。
- 你要看页面效果时，用浏览器截图，再用读文件工具看图片。
