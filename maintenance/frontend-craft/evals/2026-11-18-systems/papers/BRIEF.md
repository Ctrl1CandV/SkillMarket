# 课题组文献库

一个六个人的课题组（一位老师、五个学生），读的论文散在每个人的电脑和微信里。同一篇论文常常被两个人各读一遍，读完的笔记别人看不到；组会要讲哪篇也是在群里临时问。

请做一个课题组共用的文献库，真的会用，要好用，也要好看。它有几个页面，要像同一个工具。

## 页面

1. **文献库**：找论文。按主题标签、年份、谁读过来找，能搜标题和作者；一眼看得出哪些组里还没人读、哪些是最近加的。
2. **单篇**：标题、作者、出处、摘要，组里谁读过、读到哪了，每个人的笔记；可以写自己的笔记、改自己的阅读状态、复制引用格式。
3. **添加文献**：粘贴 DOI、arXiv 编号或 BibTeX，或者手动填，加进库里，打上标签。
4. **组会**：下次组会谁讲、讲哪篇，后面几周的安排；可以把一篇论文排进去。

## 已知情况

- 大家在电脑上用，一边读 PDF 一边开着它；老师偶尔在手机上看组会安排。
- 论文标题是英文，笔记和界面是中文。
- 主题标签有六个：长文本、检索增强、评测、对齐、推理、多模态。一篇可以有多个标签。
- “现在”是 2026-11-18（周三）16:00。当前用户是许静怡。

## 数据

- `data/papers.json`：6 位成员、96 篇论文（含每人的阅读状态和笔记）、组会安排。`data/papers.js` 内容相同，写成 `window.PAPER_DATA = {...}`，可以用 `<script>` 引入（双击打开的页面读不了 json 文件）。
- 论文、作者、DOI 都是编的示例，不是真实的论文；没有 PDF 文件。人名都是示例。

## 要求

- 用 HTML、CSS、JavaScript 写，双击文件就能在浏览器里打开，不联网也能用。可以分成多个文件。
- 写笔记、改阅读状态、添加文献、排组会之后，刷新页面还在。浏览器本地存储就够，不需要服务器。
- 添加文献时不能真的去网上查 DOI；粘贴 BibTeX 要能解析，粘贴 DOI 或 arXiv 编号时说清楚需要手动补全哪些信息。
- 成品放在当前目录，交付时告诉我怎么打开、做了什么取舍、哪些没做。
