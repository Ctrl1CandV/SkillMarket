# 课题组试剂与耗材库

课题组有几十种试剂和耗材，分放在三台冰箱、几个试剂柜和耗材架上。现在靠一张共享表格记库存，常常没人更新：要用的时候才发现用完了，过期的试剂一直占着冰箱，谁拿了多少也说不清，周老师每月凭印象下采购单。

请做一个课题组试剂与耗材库的网站，真的会用，要好用，也要好看。它有几个页面，要像同一个网站。

## 页面

1. **库存**：组里的人查有什么、放在哪、还剩多少。能按类别、存放位置找，能直接搜名称；看得出哪些快用完了、哪些批次快过期或已经过期。
2. **单个试剂**：规格、存放位置、危险性、每个批次的剩余量和有效期、最近谁领用过。在这里登记领用（用了多少、做什么用），或者报缺（申请采购）。
3. **我的领用**：当前成员看自己最近领用过什么、报过哪些缺、采购到哪一步了。
4. **采购清单**：周老师看所有报缺和低于补货线的东西，决定这次买什么，标成已下单、已到货；到货后要能入库成新批次。

## 已知情况

- 组员在实验台边上用手机查和登记，手上常戴着手套，只想几下点完；周老师在办公室电脑上整理采购。
- 领用按批次扣：先用快过期的那批。一个试剂可能有几批，有的已经开封。
- 有的试剂易燃、有毒或腐蚀，查的时候要让人看清楚。
- 每种东西有一条补货线，剩余低于它就该买了。
- “现在”是 2026-11-19（周四）10:00。当前成员是何雨桐；采购清单那一页的使用者是周老师。

## 数据

- `data/reagents.json`：8 位成员、50 种试剂和耗材（含批次、有效期、补货线）、最近一个月的 123 条领用记录、6 条报缺。`data/reagents.js` 内容相同，写成 `window.REAGENT_DATA = {...}`，可以用 `<script>` 引入（双击打开的页面读不了 json 文件）。
- 没有试剂照片。人名、批号、供应商都是示例。

## 要求

- 用 HTML、CSS、JavaScript 写，双击文件就能在浏览器里打开，不联网也能用。可以分成多个文件。
- 领用、报缺、改采购状态、入库之后，刷新页面还在。浏览器本地存储就够，不需要服务器。
- 成品放在当前目录，交付时告诉我怎么打开、做了什么取舍、哪些没做。
