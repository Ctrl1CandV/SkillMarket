# 多信息、多功能局部界面：实施与新旧对比

日期：2026-10-29。运行技能已完成定向补强，保留为 `frontend-craft 0.5.0-rc.2` 和 `product-design 0.2.0-rc.2`。本轮没有修复 PaperDesk 工程，没有安装全局副本或发布；用户验收后授权独立本地提交。

结论：新方法已形成可执行的指导、参考和样张；三个独立业务题均产出了可用的新版本原型。用户匿名选择 1B、2A、3B，并明确认为本轮已达到预期，本目标收口。第二题两版均获认可，旧版局部更紧凑；这不构成追加统一密度规则的理由。真实项目实践按用户决定延后。小样本仍不能证明新版在所有任务中全面、稳定地优于旧版。

## 实际改动

| 位置 | 已完成内容及目的 |
| --- | --- |
| frontend-craft 主入口与新 `references/local-interfaces.md` | 将局部结构重排纳入范围；按内容支持的判断、所属对象、依赖与动作后果组织画面，涵盖内容提炼、控件组合、动作组、容量和组合状态 |
| 内容、场景、布局、视觉与评审参考 | 增加必要路由、调整幅度与局部诊断；保持既有通用原则，不重复整套流程 |
| product-design 主入口及 3 份参考 | 补充对象与状态关系、局部重排边界、反馈对象及已否定决定的接续；新增共享文档访问管理推演 |
| 原创局部样张 | 虚构藏品借展安排，完整说明、条件字段、校验、保存/恢复/撤销；沿用既有 3 个主题，与独立验收分开 |
| 范例库 | 既有 14 条内容和顺序保持不变，筛选新增 10 条 `documented`：配置范围、继承来源、设置编辑、审查进度、阅读整理及表单/窗口组合 |

运行目录共修改 13 个现有文件、新增 4 个文件。没有新增独立 skill，没有规定固定字段数量、按钮比例或某类业务模板。不同控件仍按行为选用；筛选呈现不等于删除必要信息和能力。主要方法按需读取，主文件只保留触发条件及短路由。

外部案例已核对官方文字与图像入口，未实际操作或看图的部分仍标为 `documented`；没有新增外部 `verified_visual` 或分发许可未确认的图片。详细取舍见 [参考核查记录](../upgrades/2026-10-29-local-interfaces/reference-research.md)。

## 新旧对比怎么做

先保存旧包，再冻结候选规则、参考及样张；随后由未读被测技能和优化方案的独立代理编写三道业务题。六个原型分别在独立上下文中生成，继承同一模型设置，按相同任务、素材和 960×720 / 400×820 视口验收。原型生成方只做静态检查，由根任务统一看图和操作；双方均保留首轮输出，没有只修新版。

A 是旧版 `0.5.0-rc.1 / 0.2.0-rc.1`，B 是本轮 `rc.2 / rc.2`。另一个不知道版本映射的评审实际查看截图，结合统一实测记录按预注册锚点评分；根任务知道映射，不宣称整个评估双盲。

| 独立业务题 | 操作结果 | 可观察的设计取舍 |
| --- | --- | --- |
| 播客片段批量制作与交付 | 两版五条关键路径通过；实际 JSON 均正确包含有效产物和排除原因 | 新版以摘要、状态和异常支持批量核对，同屏能看到更多片段；旧版参数就地编辑，并有集中的交付清单预览，连续修改更直接 |
| 巡演无线设备维修处置 | 两版均正确处理确认条件、资料变化后过期、方案隔离、草稿保留与撤销释放 | 新版将维修史放在相关检查旁，缺项与方案状态更集中；旧版有检查/方案快速定位。整体能力相当 |
| 书店周末外摆选书 | 新版五条路径通过；旧版因“东店”“城市”缺少有效 option 标签，指定筛选路径不能完成；其他路径通过 | 两版均分开目录与完整清单，窄屏可切换。新版持续提供完整清单入口并就近解释超限；旧版目录内可直接改数量。代码漏项不等于旧设计规则必然较差 |

独立评审分数为旧版 **28/30**、新版 **30/30**；前两题都是 10/10，唯一分差来自旧版书店题的必要选项缺失。0–2 分维度比较粗，不能把总分差解读为新版审美提升幅度，也不能凭累计分让旧版书店题通过功能门槛。具体证据和判断分歧见 [匿名评审](../upgrades/2026-10-29-local-interfaces/evaluation/blind-review.md)。

## 验证与使用边界

- 两个技能及冻结副本格式有效；128 处本地引用、索引兼容性及样张 JS 检查通过。候选 36 个文件与工作区运行目录完全一致，旧包 32 个文件、候选和 5 份题目/评分材料在结束时重新核对哈希，均未变化。
- 原创样张实际检查三主题、桌面/窄屏、条件字段、日期错误、保存、恢复和撤销，未发现横向溢出。六个验收原型均实际打开并操作；窄屏未发现横向溢出。核心路径和下载核对见 [浏览器记录](../upgrades/2026-10-29-local-interfaces/evaluation/browser-observations.md)。
- 初次报告时尚无用户审美反馈；随后取得的选择和认可单独记录在[用户验收与收口](../upgrades/2026-10-29-local-interfaces/evaluation/user-acceptance.md)。本轮没有真人使用计时、跨模型重复采样或完整辅助技术测试。每题每版本仅一次生成，且省略了生成方的浏览器自修订环节，结论限于这个受控条件。
- 本轮保留 RC 改动并收口，真实项目观察延后。已有验收题不再充当未知题；如果据其调优规则，应另留新题检查迁移。下一轮配色与样式选择是独立目标，不回写本轮冻结包或重调对比原型。
