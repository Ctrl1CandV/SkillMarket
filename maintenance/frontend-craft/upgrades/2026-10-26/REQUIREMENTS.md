# 本轮逐项要求

这些要求同时包含“新增能力”和“修订旧内容”。文件名为相应技能内的简称；实际目录见 START_HERE。检查方式不是要求每次运行 skill 都建立整套记录，完整追踪只用于本次升级。

## 记录方式

补全执行者为每个 ID 记录 `implemented / verified / blocked / not-applicable`，分别给出实现文件与原始验证证据。仅修改了文件可以写 implemented，不能自动写 verified。not-applicable 必须说明为何本轮要求实际不适用，不能借此跳过约定的主要场景和外部参考补全。

独立终审可以合并说明相近条目，但所有 ID 都应有可定位结果。必须区分文本规则存在、运行时实际遵循、最终画面成立三个层次；第一个层次不能代替后两个。
