# 终审发现后的参考覆盖补充

六次配对构建使用 `evidence/candidate-snapshot/` 中的固定候选，哈希见 `candidate-snapshot-hashes.json`。该快照含 Tufte、Tabler、PhotoSwipe 四张原始画面；不包含此处后补的 Wikipedia 资源。构建者没有收到终审意见或该资源，既有成品没有因此修改或重选。

## 具体发现

独立终审者实际打开原图后指出：Tufte 的 Sidenotes 章节有连续正文与短编号旁注，却没有可核对的原始依据或来源定位过程。它能支持正文/旁注的设计关系，不能单独证明 ACCEPTANCE 的“连续阅读与证据核对”资源覆盖。此前 `--release` 通过只说明字段和文件结构符合要求，这个语义缺口必须补正。

保留该图及其实际看图状态，明确它的补充用途；不把已经观察的图片改称没有看过，也不改动原始检查器。最初尝试 Distill，浏览器连续读取超时，未取得合格的原始画面，其许可研究只保留在 maintenance。随后在 Wikipedia 原在线页面实际查看 Attention with seq2seq 正文，点击第一处 [21]，记录 Cho 等 2014 来源条目高亮，再实际点击第一回链返回正文引用。正文和来源两张未经处理的完整视口已入库，DOM 回链检查另存；没有以源文本或手绘图代替浏览器画面。

CSS 视口 1440×1000，原始 JPEG 1425×990。正文捕获的精确调用元数据在后续工具超时中丢失，所以仅保存日期、当时实读状态与文件保存时间，未编造精确起始时间。来源图和回链有独立 JSON 记录。回链目标紧贴视口顶边（top 约 -0.225px），作为迁移限制保留，未宣称理想上下文恢复。

Wikipedia 文字的 CC BY-SA 4.0、作者历史及固定版本、截图中页脚标识的教育性说明用途分别记录在运行资产 SOURCE/ATTRIBUTION 中。独立审查者实际查看了两图及回链记录。现在共十四个索引条目、六个 verified_visual 状态、四个独立发布主体；同一网站的不同状态不当成额外发布者。

## 对比较的边界

此变化属于外部资源与索引证据补充，没有改变两技能的主流程、条件规则、版式规则、样张源码或六个实现。原先构建者查看的 Tufte/Tabler/PhotoSwipe 图像保持原字节。

`evidence/post-freeze-diff.json` 与 `final-candidate-hashes.json` 保留受测快照和最终运行资源的精确差异。不能把新资源的存在当作六次结果改善的原因，也不能声称这些运行验证了它的后续使用效果。已取得的比较只直接检验冻结版本；本次追加的来源质量和覆盖由独立终审核对。是否仍足以支持本轮结束，由终审结合核心效果判断，执行者不据此自行通过。

实际补充状态见 `evidence/references/wikipedia-captures.json`、`wikipedia-source-capture.json`、`wikipedia-return-check.json`、当前范例索引及独立终审。R27 的资源缺口补齐不改变 R33 主要阅读改善仍不明确的事实。
