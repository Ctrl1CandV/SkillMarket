# 三场景配对比较与揭盲

六个独立首轮实现、22 张统一状态截图和独立关键路径复核已经完成。**本次结果不足以支持“新版在主要阅读任务上有意义地优于旧版”的结论。** 两边主要关系和已复核行为大体相当，局部各有得失；这不是把新版判为不可用，也不能将其包装成升级成功。

每位构建者使用全新无历史上下文、同一父模型且无覆盖、相同工具权限、原生 HTML/CSS/JS 空工程、相同字节任务和数据。共同约定为一次最多25分钟的实现机会，允许正常自检修复。没有把升级聊天、PLAN、REQUIREMENTS、验收答案或对方产物发给构建者。按各自技能自行查参考的机会相同，资源差异本身属于受测变量。

宿主未提供不可变模型 build ID、物理隔离容器或硬性预算锁。共同条件与完成观察是运行记录，不能冒称精确算力和耗时控制。初始两方同时收到8765不可用、改8766的环境修正；并发截图的视口干扰由最后串行捕获解决。原始工具调用在主会话，未另行导出逐字启动提示与精确开始时刻。详见 [builder-protocol](../evidence/builder-protocol.md)。

## 盲化及图像证据

独立盲评者只读原始任务/数据及中性 A/B 应用，未读技能、BUILD、映射、升级计划或执行结论。先写并冻结 [blind-comparison.md](blind-comparison.md)，随后才向另一位独立终审者提供映射。终审者此前已看技能并独立看过全部22图，可能推断身份；不将整个过程称作双盲或用户研究。

统一源为 `http://127.0.0.1:8766/`，CSS视口1440×1000与390×844。初始阅读均为paper-01/q-01，引用均定位paper-01-s2-p2；密集操作均为原始12项，混选003/006/002；展览初始均Y=0，大图均第二件。原始 JPEG 未经裁切、缩放或编辑。见 [captures](../evidence/canonical/captures.json) 与 [实际操作](../evidence/canonical/interaction-review.md)。

22张包含：阅读8张，密集操作初始4张及混合重试2张，展览8张。六条因旧提示、页首锚点或焦点轮廓而同路径重拍的旧元数据另存 [技术重拍记录](../evidence/canonical/superseded-capture-records.json)；旧字节已被覆盖，不宣称所有早期截图原件均留存。这些捕获校准没有修改应用或新增构建尝试。

## 揭盲后的具体判断

以下按“新版相对旧版”表达，原始盲评表使用“A相对B”，两者不可直接混读。

| 场景/维度 | 新版相对旧版 | 具体依据 |
| --- | --- | --- |
| 阅读：主要对象与整体构图 | comparable | 两者均为资料集合、连续原文、预置问答/笔记关系；长中文题名完整，手机切换工作区，来源身份不混淆。 |
| 阅读：文字与入口 | comparable | 新版问答视觉字号较大、手机笔记顶层入口更直接；旧版持久目录和阅读比例更显著。无衬线与衬线本身不能决定优劣。 |
| 阅读：引用定位辨识 | worse（局部） | 旧版黄色定位面与主色区分更强；新版浅绿与其他绿色面接近，但来源引用按钮变深绿，且两者定位都准确。此局部得失未显示功能阻断。 |
| 阅读：往返、编辑保护、刷新 | comparable | 两边都可定位2.2并回回答；编辑切换保护保留草稿，保存后文本及关联刷新仍在，当前资料和阅读区域继续。 |
| 密集：密度与活动说明 | better（局部） | 新版桌面约七行对旧版约六行，已处理/总数并置；活动使用中文动作名，旧版另露出内部英文事件词。 |
| 密集：排查信息与手机筛选 | worse（局部） | 旧版桌面编号直接可见，手机提交时间/详情字样更明确，失败与待复核入口更早；新版部分信息要进入详情或横向滚动。功能未因此缺失，未证明是新规则直接诱发。 |
| 密集：跨筛选选择和批处理 | comparable | 两边均保留隐藏选择，003/006重试成功、002进行中跳过，逐项解释结果，刷新后历史和状态正确。 |
| 展览：整体表达 | comparable | 两者都围绕八件不同图像比例的作品组织，无硬套论文工作台。旧版作品更早出现，新版展期、场地和行动层次更强。 |
| 展览：大图语境 | better（局部） | 新版深色查看器同屏保留作者简介；旧版作者简介在页面独立区域。两者连续浏览并返回原位置。未将未经测试的额外缩放入口算作优势。 |
| 展览：预约与持久化 | comparable | 同场次余1时，2人和1.5人均被拒绝；1人成功后满场禁选，刷新保留本地预约，均可恢复演示。 |

没有计算总平均分，没有“提升百分比”，没有只挑新版更好的局部替代主要阅读结果。完整逐维判断与未验证范围见冻结盲评。

## 限制与后补资源

这是三组有限样本、单一宿主环境的工程验收，不能证明长期阅读偏好、真实手机软键盘、完整读屏行为或所有错误分支。独立审查复核关键路径；各构建者更广的自测仍标为构建者记录，未自动升级成独立验证。

六次构建使用冻结的候选快照。终审发现 Tufte 单独不足以支撑外部证据核对覆盖后，启动了来源资源补充；这些后补材料不曾参与六次生成，也不能被用来解释既有结果。精确边界见 [后补记录](post-freeze-resource-supplement.md) 与最终资源差异清单。

主要效果门槛由 [独立终审](final-review.md)判断。若仍不支持有意义的阅读改善，应保留RC和当前证据，具体分析可见问题或取得针对性的新配对证据；不能把这里的局部优势相加后宣布本轮通过，也不能只修改成品截图来替技能制造胜出。
