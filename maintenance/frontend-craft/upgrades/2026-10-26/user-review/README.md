# 用户对比入口

打开 [index.html](index.html) 可查看三场景共 22 张已经保留的原始截图。页面只加载相邻目录中的本地文件，无外部依赖、fetch、服务端接口或评价收集。保持 `user-review/` 与 `evidence/` 的相对位置即可离线查看截图。

通过场景、视口、状态选择器同时切换两侧。宽屏包含初始及已经捕获的关键状态；手机仅提供实际存在的状态。默认预览只会缩小图片，不会放大窄屏截图填充栏宽。原始像素模式在浏览器缩放为 100% 时按 1 图像像素对 1 CSS px 显示，图像区域可横纵滚动；“打开原图”另开原文件。“实际体验”另开对应原应用，状态取决于该浏览器的本地记录，当前窗口也不自动变成截图视口。

实际操作应用建议继续使用已经验证的本机 HTTP 入口。从仓库根运行 `python -m http.server 8766 --bind 127.0.0.1`，访问：

<http://127.0.0.1:8766/maintenance/frontend-craft/upgrades/2026-10-26/user-review/index.html>

对比页不展示旧新身份或既有评审结论，用户可在聊天中按场景表达偏好、相当和可接受取舍。已有对话与页面记忆仍可能暴露身份，因此不能称为完全盲化。维护映射见 [mapping.json](mapping.json)，界面的甲乙与旧有 A/B 不是同一组标签。没有评分算法、自动通过判断、本地评价存储或上传行为。

原图和原实现没有被复制、编辑或替换。图片原始像素与采集 CSS 视口可能不同，页脚分别显示；原始捕获及操作证据仍以 `evidence/canonical/captures.json` 和 `interaction-review.md` 为准。此入口便于人工评价，其静态完整性检查不代替根执行者的浏览器验收。
