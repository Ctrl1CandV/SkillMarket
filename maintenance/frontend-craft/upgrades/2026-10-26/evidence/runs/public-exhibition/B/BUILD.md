# 未完成的路线 — B 实现说明

## 运行

无需安装依赖。入口为 `index.html`，原生 HTML / CSS / JavaScript，通过 HTTP 读取同目录 `data.json`。

已有仓库根目录静态服务时直接打开：

<http://127.0.0.1:8766/maintenance/frontend-craft/upgrades/2026-10-26/evidence/runs/public-exhibition/B/>

如需自行启动，在已安装 Python 的环境运行：

```powershell
python -m http.server 8766 --directory "D:\Program Project\SkillMarket"
```

已有服务占用该端口时直接使用已有服务。不要使用 `file://` 双击方式，因为浏览器可能阻止读取 JSON。

## 实现与取舍

- 展览介绍、八件作品、四位艺术家与参观预约在一个连续页面中完成。顶部提供展览、作品、预约锚点；桌面首屏让展览标题与第一件原始作品共同可见。
- 所有作品图直接使用数据中原始 SVG，完整显示原始比例，无裁切或占位替换。作品列表保留全部名称、作者、年份、媒介、尺寸和说明。不同横竖比例形成观看节奏，手机改为单列。
- 使用暖白纸面、墨色正文与赭红强调。较大标题和作品面积用于建立展览身份，正文保持常规可读字号，预约区域使用更紧凑的表单结构。未下载字体或额外图像。
- 原生 `dialog` 大图提供作品说明、艺术家资料、原创来源声明、前后切换、方向键、首末件禁用、原尺寸放大/适合画面、Esc 关闭。关闭恢复触发按钮焦点和原页面滚动位置。
- 六个场次全部显示日期、时间和剩余名额，满场禁用。表单校验称呼去首尾空格后的 1—30 个字符、人数 1—4 的整数、有效场次及最新本地余量。
- 成功时生成本地编号并保存称呼、人数、场次和提交时间；余量由初始名额减去已保存预约计算，防止负数余量。确认区和历史列表供查看结果。使用独立的 localStorage key `unfinished-routes-public-exhibition-b-v1`；支持刷新保留、存储失败反馈和恢复数据确认框。支持 Web Locks 的浏览器在提交时串行读写，另有 storage 事件同步逻辑。
- 展览、场地和预约的虚构演示身份在相关位置标明；预约不会发送到外部机构，也不产生真实入场资格。
