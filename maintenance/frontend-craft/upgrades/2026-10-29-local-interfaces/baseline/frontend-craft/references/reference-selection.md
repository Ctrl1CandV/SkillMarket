# 选择、查看与转用参考

优秀参考提供可观察的质量目标。选用时把任务关系、视觉表现和实现细节分开判断，再在当前内容中组合起来。

## 先判断匹配什么

按当前工作选择：连续阅读、查找、比较、编辑、操作或展示；再看主要内容是长文、列表、表格、图像还是混合内容，以及密度、状态、视口和语言。行业名称和流行度只能帮助发现候选，不能直接决定布局或色板。

先看项目中已经成立的整体关系。需要新的方向时，从[范例索引](exemplars.md)选一个能承担整体依据的案例，确有缺口再补局部参考。不要为每个组件分别挑一套不相容的样式。用户明确指定参考时尊重其目标，同时核对任务与内容差异。

## 查看画面再提取关系

实际打开可用截图、原始页面或项目画面。先看完整工作视口的主体、比例、疏密和明暗，再看与本次决定有关的细部及状态。工具页优先看填入内容后的工作画面，展示页同时看主视觉与后续内容；营销页里的产品截图不自动代表完整工作界面。

用简短记录说明：

- 当前任务与参考的哪些关系相似；
- 借鉴的整体关系，以及它会改变本次哪项决定；
- 真实内容、品牌、设备或语言要求哪些调整。

例如“借鉴连续阅读面与较窄旁注的分工；本次回答更长且需要核对图表，因此重定宽度和切换方式”。避免只记录“干净、现代、舒服”，也不为每个像素建立文档。

## 参考的状态与使用边界

[机器索引](exemplar-index.json)使用以下状态，供选择和维护：

| 状态 | 可以作什么依据 | 不代表什么 |
| --- | --- | --- |
| `candidate` | 寻找待核验的来源 | 没有完成内容或画面核验 |
| `documented` | 来源的方法或文字内容已核对，可用于推理 | 尚无已核验的本地完整画面包 |
| `verified_visual` | 已打开本地画面，记录了任务、视口、来源和迁移关系 | 不等于用户研究验证、跨任务通用或本次产出必然优秀 |

只有第三种状态可声称本地画面已核验。网页截图不是科研证据；官方设计文档也可能主要表达某个设计系统的选择。可见数据和原作者规则保持各自含义，不把测得的像素推断写成官方 token。

索引条目使用 `id`、`status`、`tasks`、`content_shapes`、`source_url`、`notes`；完成画面核验时补 `screenshots`、`capture`、`license`、`review`。`screenshots` 中路径相对技能目录。`review` 记录实际观察的关系和适用限制，不用单一分数代替说明。

为便于维护，可复用的本地外部画面按以下字段登记。填字段不证明事实成立，维护者仍需实际查看并核对来源。

| 字段 | 内容 |
| --- | --- |
| `source_origin` | 实际发布主体的短标识；同一主体不同子域不能算独立来源 |
| `release_categories` | 经画面支持的任务覆盖，可选 `reading-verification`、`dense-operation`、`public-display`；普通 `tasks` 继续使用更细任务词 |
| `screenshots` | PNG/JPEG/WebP 相对路径列表，包含有用的完整视口，必要时补细节 |
| `capture` | `captured_at`、`viewport: {width, height}`、`page_state`、`method`；日期为 ISO，视口为 CSS px |
| `license` | `redistribution: "allowed"`、可核对的 `basis`，必要时附 `source_url`；使用条件未明确时只保留链接，不据此登记可分发截图 |
| `review` | `viewed: true`、`reviewed_at`、实际观察的 `relationships` 数组、适用限制 `transfer_limits` 数组 |

同一条目的多张截图应对应登记的视口和状态；有不同捕获条件时拆成明确条目，避免一份记录混写多种条件。原创样张不登记为外部 `verified_visual` 案例。维护检查只能核对结构和文件，实际画面质量、来源独立性与使用依据仍由审查确认。

## 转用，而不是拼贴

先用真实内容落实继承关系。字体参与体量和断行，配色参与面积与主次，容器参与分组；不能一边继承样式、一边保留与之矛盾的旧构图。需要改变某项时，检查关联的角色，而不是给每个组件增加独立装饰。

完整模板只在内容和工作关系相近时使用。表格、阅读面、图表等本身有清楚语义，不为适配模板改写事实、缩短全部标题或隐藏必要字段。控件维持成熟语义；通用操作模式本身不是缺点。

已有布局明确且仅做样式精修时，选择能用于当前骨架的参考；保留明确锁定项，允许合理的字形与局部空间联动。新方向存在实际分歧时可作轻量比较，不要求每次提供多个候选给用户审批。

## 资料或工具不足时

图像工具不可用时读取方法说明和现有项目资料，准确标明本次没有视觉核验。来源不可访问时可选任务关系接近的其他来源；不要用生成图片冒充真实网站截图，也不要用重画的界面声称是原作。

新参考优先选择来源和使用条件明确的画面；保存来源、日期、视口及必要授权信息。许可未明确的素材可以保留链接供按需查看，不据“公开可访问”推定可再分发。

原创[样式样张](style-samples.md)可帮助确定实际颜色、文字与状态关系，但应与外部案例分开记录。实现后以当前任务和所选关系核对结果，过程见[看图与修订](review.md)。
