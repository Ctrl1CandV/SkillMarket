# 独立局部界面任务

依次使用 `tasks/task-1.md`、`tasks/task-2.md`、`tasks/task-3.md`。每题产出一个自包含 HTML，内联必要 CSS 和 JavaScript，可直接打开操作；每题独立，不构建整站。题内人物、记录及业务规则均为虚构。

HTML 和必要交互均须实现。实现方仅做代码静态检查，不自行进行浏览器验收或据此迭代；父任务统一浏览器验收，采用相同路径和修订机会。评分规则见 `scoring.md`。
