# 任务三：书店周末外摆选书

店员为周末社区外摆准备最多18册图书，需要跨筛选选择、调整携带数量并记录单书说明。实现一个自包含 HTML/CSS/JS 原型，遵守 briefs.md。只有内存草稿，不实际调拨库存；信息呈现和操作方式自行决定。

可携带数量＝在库−已预留。数据：

|编号|书名|作者/出版社|主题/取书点|在库/预留|
|---|---|---|---|---|
|B01|沿着消失的河流走：一座城市的水与人的记忆|许澜/青石出版|城市/东店|7/2|
|B02|阳台上的一年：从第一粒种子到最后一场霜|罗芮/慢木出版|自然/西店|5/1|
|B03|下班以后，我们怎样重新学会画画|周遇/斑点出版|手作/东店|4/4|
|B04|门牌号背后的人：老街口述生活史|沈宜/青石出版|城市/西店|6/1|
|B05|给孩子看的夜行动物观察笔记|岑禾/溪岸出版|自然/东店|8/2|
|B06|缝补不是为了遮住破洞：衣物修复小练习|林简/慢木出版|手作/西店|3/0|
|B07|骑车经过的二十四座小桥|姚青/溪岸出版|城市/东店|2/2|
|B08|落叶、苔藓和石头的名字|顾庭/斑点出版|自然/西店|6/0|

初选B01×2、B04×1、B06×2。活动说明：“来访者多为附近居民，请保留适合边翻边聊的书。西店图书由另一位同事带来，数量变化要能说清楚。”B01荐语：“适合从熟悉的街名谈起；附录较长，介绍时可引导读者先看旧河道地图。”B06备注初值：“请带封面无折痕的版本，现场会演示书里的布贴步骤。”其他单书备注为空，可编辑。

支持书名/作者/出版社搜索，主题、取书点、是否有余量筛选及书名/余量排序；条件取交集。选择跨筛选保留，携带数量为正整数且不超余量，总数不能超过18；所有越界尝试须说明原因并保留上一个有效值。无余量图书仍可查看内容，不能新选。

可仅取消当前结果中的选择，或取消全部选择；应能辨认筛选外的已选内容。支持对单本标记“本次暂缓”，使其不计入选择和携带量；可查看暂缓对象并恢复，恢复原数量仍须满足限额，否则保持暂缓并说明原因。支持保存当前选书草稿，后续改动使保存状态失效。

验收路径：

1. 初始3种5册；筛选东店时，B04和B06的选择仍保留。
2. 搜索“青石”并筛选西店，仅得B04；取消当前结果选择后仍保留B01、B06。
3. 尝试选择B03、把B01设为6或0均被阻止；累计超过18册也被阻止且数量不被静默改写。
4. 修改B06备注后暂缓，再恢复，数量与备注保留；容量不足时恢复失败并可纠正后再试。
5. 保存后修改数量显示尚未保存；清除筛选、排序不丢选择。两种窗口均可找到筛选外选择、编辑单书并保存。
