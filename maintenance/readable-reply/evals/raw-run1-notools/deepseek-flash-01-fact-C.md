**list vs tuple 主要区别：**

| 特性 | list | tuple |
|------|------|-------|
| 可变性 | 可变（可增删改） | 不可变 |
| 语法 | `[1, 2, 3]` | `(1, 2, 3)` |
| 可作 dict 键 | 否 | 是（若元素可哈希）|
| 性能/内存 | 较慢、较大 | 较快、较小 |
| 用途 | 同类元素集合 | 固定结构/记录、多返回值 |

**要点：**
- list 支持 `append`/`extend`/`pop`、切片赋值等；tuple 一旦创建就不能改。
- tuple 不可变，所以可哈希（如 `(1, 2)` 能当字典键，`[1, 2]` 不能），也可放进 set。
- 单元素 tuple 要带逗号：`(1,)`，否则 `(1)` 只是整数 1。
- tuple 迭代和创建略快、占用内存更少。
- 语义上：list 表示「长度可变的一批同类项」，tuple 表示「字段固定的记录」，例如坐标 `(x, y)`、函数多返回值。

```python
a = [1, 2, 3]
a.append(4)          # OK
t = (1, 2, 3)
# t[0] = 9           # TypeError

d = {(1, 2): "ok"}   # tuple 可做键
# d[[1, 2]] = "x"    # TypeError: unhashable
```

> 注：「tuple 更快」只在特定场景明显；常数级差异，选型更应看语义——需要修改就用 list，固定结构就用 tuple。
