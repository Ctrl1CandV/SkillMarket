主要区别：

| 特性 | list | tuple |
|------|------|-------|
| 可变性 | 可变，可增删改 | 不可变，创建后不能改 |
| 语法 | `[1, 2, 3]` | `(1, 2, 3)`，单元素需 `(1,)` |
| 可哈希 | 不可作 dict 键 / set 元素 | 元素都可哈希时可作键 |
| 性能 | 略慢、内存占用略大 | 更快、更省内存 |
| 语义用途 | 同质数据集合，需要修改 | 异构记录、固定结构（类似轻量 struct）|
| 方法 | 有 append/remove/sort 等 | 只有 count/index |

要点：

1. **不可变 ≠ 内容绝对不变**：tuple 里的 list 仍可修改，只是元组本身的引用不可换。
2. **函数返回多值**其实返回的是 tuple。
3. **`+`/`*` 会创建新对象**，两者都支持，但 list 还可 `+=` 原地扩展。
4. **元组可作 set 元素**：`{(1,2), (3,4)}` 可以，`{[1,2]}` 会报 `TypeError`。
5. **浅拷贝陷阱**：`a = [1,2]; b = a` 是同一对象；tuple 因不可变，这个坑影响较小。
6. **命名元组**：需要“有字段名的固定结构”时用 `collections.namedtuple` 或 `typing.NamedTuple`，比裸 tuple 可读性好。

选择建议：需要修改就用 list；表示固定结构、作 dict 键、或数据量很大只读遍历时用 tuple。
