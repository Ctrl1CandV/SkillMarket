核心区别：tuple 不可变，list 可变。tuple 不能增删改元素，也就不能作为可变状态容器用；list 支持 append、sort、`a[0]=x` 等操作。

由此派生的实际差异：tuple 可哈希，能作为 dict 的 key 或 set 的元素（前提是其中元素也都可哈希）；list 不行。tuple 通常更省内存、创建更快，而且能表达"这是个固定结构"的语义，比如函数返回多个值、`(x, y)` 坐标。

用法上：需要频繁增删改或迭代处理序列，就用 list；表达固定记录或需要当 key 时用 tuple。另外注意，虽然 tuple 本身不可变，但如果它含有 list 等可变元素，那些内部元素仍可被修改。验证哈希行为直接试 `hash((1,2))` 和 `hash([1,2])` 即可。
