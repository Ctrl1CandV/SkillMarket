主要区别：

- **可变性**：`list` 可以增删改（`append`、`remove`、`lst[0] = x`）；`tuple` 创建后不可改。
- **语法**：`[1, 2]` 与 `(1, 2)`，单元素 tuple 要写 `(1,)`。
- **用途**：`list` 用于同类元素的集合（需要变动）；`tuple` 用于固定结构，如坐标 `(x, y)`、函数多返回值、字典的 key（因为可哈希）。
- **哈希**：只有元素都可哈希时，tuple 才能当 dict key 或 set 元素；list 永远不行。
- **性能**：tuple 更省内存、创建更快，常量 tuple 还能被编译器优化复用。
- **解包**：两者都支持 `a, b = t`，但 tuple 更常用于这个场景。

简单记：需要修改就用 `list`，结构固定或要当 key 就用 `tuple`。
