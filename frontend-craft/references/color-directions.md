# 配色方向与可复用模板

当现有页面总落到相近色调、需要建立新方向或用户想比较更多搭配时，打开[配色与搭配库](../assets/color-studio/index.html)。它包含九组原创候选和三种可复用页面，不是行业配色标准，也不是经过真实产品证明的最佳方案。已有方向成立的局部修复直接沿用项目。

## 选择改变哪一层

- **整体方向**：改变主画面的明暗、冷暖、表面关系、品牌色面与内容的分量；颜色、字形和边缘处理一起看。
- **配色变体**：保留成立的构图与组件，在同一体系里更换配对颜色。用户需要更多选择时，这本身有价值；无需为了显得不同而重排页面。
- **局部适配**：同一产品的展示区可以鲜明，阅读或编辑区可以平静；继承身份，用各自完整的前景/背景配对承接内容。

先判断真正约束：用户已有品牌、内容/图片本身的颜色、持续阅读还是短时浏览、哪些状态必须醒目、是否需要深色。选出能解决当前关系的起点即可，不固定候选数、不随机分配行业色。方向分歧实质影响选择时，用同一份内容比较。

## 九组起点

| ID / 名称 | 整体关系与可借鉴处 | 适配时重点查看 |
| --- | --- | --- |
| neutral-cobalt / 中性钴蓝 | 冷浅底、白内容面、深蓝交互，清楚区分内容与操作 | 图片丰富时仍能退后；避免全页重复蓝色标签 |
| ink-cyan / 墨色冰青 | 冷深底、分层蓝灰表面、浅青操作 | 长文亮度与控件边界；浅青按钮使用深字 |
| paper-berry / 纸面莓红 | 带暖调的浅纸面、莓色强调、适量衬线标题 | 图片冷暖与中文字体回退；不强迫阅读产品采用纸张隐喻 |
| olive-linen / 亚麻橄榄 | 亚麻浅底与橄榄色面，低彩度内容区承托深色动作 | 品牌绿与成功反馈不要仅凭色相区分 |
| mist-teal / 薄雾青绿 | 清冷淡色表面与深青形成轻重，保留连续阅读面 | 大量青色数据图进入后，动作和图例的角色是否混同 |
| clay-rust / 陶土赭红 | 温暖浅底、赭色品牌面、深色正文，展示暖色与精确操作共存 | 红橙色素材、告警与品牌强调的邻接关系 |
| violet-mist / 雾紫深葡 | 紫调浅表面与淡紫品牌面延续底调，深葡文字和动作建立落点 | 染色表面不能淹没图像、状态或辅助文字 |
| graphite-lime / 石墨青柠 | 接近无彩的工作面、石墨品牌面与明亮青柠，强反差集中在需要的位置 | 明亮底色的深字配对；长篇正文不必沿用品牌面力度 |
| espresso-amber / 深咖琥珀 | 暖深底、咖色层次与琥珀操作，提供区别于冷深色的选择 | 金色强调与警告含义、暖浅文字和深色图像边缘 |

这九组不是封闭清单。可从中适配或建立新的配对，不要求每个项目安装九套主题。前三组延续旧样张的底调与强调关系；新库按模板用途补齐了品牌面与交互配对，不是旧 CSS 的直接替代版本。

## 用模板观察完整画面

| 模板 | 用来判断的关系 |
| --- | --- |
| [工作台](../assets/color-studio/workbench.html) | 列表、选中项、编辑控件与反馈同时存在，检查操作能否被找到，品牌色与状态色是否有分工 |
| [连续阅读](../assets/color-studio/editorial.html) | 中文长标题、正文、引用与章节的节奏，检查较长阅读中的底色、文字和局部强调 |
| [品牌展示](../assets/color-studio/showcase.html) | 大色面、标题、原创图形、内容段与动作共存，检查色彩面积和强弱转换 |

三类模板的职责与布局不同；同一个模板切换配色保持内容与结构。先选与当前内容关系接近的模板，再检查候选配色，不用换题材来掩盖配色问题。模板只演示本地行为，业务内容是虚构的；放入真实图片、复杂图表或真实数据以后，必须重新判断其表现。

## 复用与调整

1. 打开完整模板，在实际显示尺寸看正文、辅助信息、主按钮与状态，再看整页明暗；缩略卡片仅帮助筛选。
2. 从搭配库复制或下载当前方案的 CSS，或查看 [palettes.css](../assets/color-studio/palettes.css)。复用模板时连同其引用的本地 CSS/JS 一起复制；在已有工程中只映射需要的角色，不更换技术栈或覆盖无关组件。具体模板及资源关系见页面源文件。
3. `--cs-*` 是样例命名空间。背景/表面/文字映射到项目现有角色；`accent/on-accent` 与 hover/active 成组调整，`selected/selected-text` 表达持续选择，`brand/on-brand/brand-muted` 用于独立品牌区域，`success/warning/danger` 保持业务含义。字体与圆角是可选配方，不必捆绑使用。
4. 从一套关系开始调整。跨方案借用一组颜色时，把相关文字、控件、焦点和相邻表面一起带入检查；不要随机拼接每套最好看的单个色值。明亮强调色可能需要深字，不能统一白字。
5. 将实际内容和状态放回页面。辅助文字、按钮文字及反馈在真实背景上核对对比；选中同时有焦点、错误出现在染色面、品牌区嵌入表单等组合也要清楚。品牌绿不等于成功、品牌红不等于错误，用标签或形状维持语义。普通分隔线与必须识别的控件边界分别判断。

颜色数量、固定面积比例和对比合格都不是美观证明。具体对比适用条件与深浅层级见[视觉样式](visual-style.md)，看图和修订见[评审](review.md)。不因配色变化删除信息、缩小全部字体或重做已认可的内容组织。

## 方法依据与边界

- [Radix 色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)：按表面、状态、边界与文字用途搭配；本库是原创配方，没有继承 Radix 对特定色阶的保证。
- [Carbon 颜色](https://www.carbondesignsystem.com/building-blocks/foundations/color/overview)：语义角色可跨主题保持，表面的明度关系需按主题安排；本库没有声称是 Carbon 主题。
- [USWDS 主题色](https://designsystem.digital.gov/design-tokens/color/theme-tokens/)与[状态色](https://designsystem.digital.gov/design-tokens/color/state-tokens/)：主题与反馈各有用途；面积建议按内容判断，不写成固定配额。

来源用于方法参考，原创模板用于观察与复用，真实项目反馈用于判断适配效果；三类证据不相互替代。
