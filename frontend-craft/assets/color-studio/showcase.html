SHORELINE PROJECT / SEASON 04

把城市，
重新看见。

沿着河流行走，倾听边缘的日常。用声音、文字和图像，留下一份属于此刻的城市观察。

探索本季内容 ↗了解参与方式

三种方式，走近同一座城市。

本季原创内容提案 / 01—03

01 / 声音行走

听见风经过的地方

跟随一段河岸录音，从桥下的回声走到开阔的堤岸，让耳朵先于地图辨认位置。

查看内容安排

一份步行提示、三段原创声音构想和可供记录的观察问题。此样张不提供真实音频下载。

02 / 日常札记

留给细节的一页纸

一张椅子、一间修理铺和几句短暂的交谈，连接成城市里不太显眼的日常。

查看内容安排

阅读一篇完整示范文章，再记录一个愿意重访的位置。打开阅读样张。

03 / 共同整理

让记录可以被重访

为声音、图像和手稿留下清楚的名称与出处，让一次发现成为下一次观察的起点。

查看内容安排

使用本地演示工作台选择资料、核对状态与保存草稿。打开内容工作台。

从一个熟悉的位置开始

不必走得很远，也可以发现新的关系。

带上一本小册子，选一段常走的路，留出停下来的时间。
