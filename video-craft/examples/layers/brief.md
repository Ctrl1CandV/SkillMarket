# layers · 山谷入夜

10 秒，1920×1080，30 fps，只用 Canvas 2D，没有任何图片素材。用来看“代码画出的完成画面”是什么样子，也可以直接复制改成别的题材。

```text
node ../../kit/render.mjs index.html sheet out/sheet.jpg --times 0.5,2.5,4.5,6.5,9.8 --cols 5 --w 384
node ../../kit/render.mjs index.html video out/layers.mp4
```

## 看什么

- **从后往前分层。** 天空渐变 → 日落方向的暖晕 → 四层山脊（越远越接近天空色）→ 层间飘动的雾 → 对岸村灯 → 近岸和小屋剪影 → 光层（窗、村灯、萤火）加 bloom → 湖面倒影 → 暗角和颗粒。
- **一盏主光。** 全片唯一的暖色是窗和灯，其余都是冷的。观众的眼睛自然落在小屋上。
- **时间在走。** 天色从黄昏混合到夜里；星星按亮度先后出现；窗灯在 1.2 秒亮起并轻微闪动；村灯一盏一盏亮。
- **三种速度的运动。** 相机慢推（远层几乎不动，近层移得多，形成视差）；灯一盏盏亮起；雾、萤火和水波一直在动。

## 怎样改成自己的

| 想改 | 改哪里 |
|---|---|
| 颜色和时刻（晨、雪夜、沙漠） | `SKY`、`LAMP`、`NEAR` 三组颜色；`night` 的范围 |
| 地形 | `RIDGES` 的 `base`、`amp`、`scale`；`ridge(..., { steps: 40 })` 变成城市天际线 |
| 主体 | `CABIN` 和画小屋的那几行；换成灯塔、帐篷或一棵树的剪影 |
| 镜头 | `cam` 的关键帧：`x`、`y`、`z` |
| 跟着音乐 | 用 `songAt` 的 `kick` 调窗灯亮度，用小节线安排村灯亮起的时刻，见 [MV](../../references/music-video.md) |

工具函数都在 [`kit/draw.js`](../../kit/draw.js)，做法见[用代码画出完成的画面](../../references/drawing.md)。
