# 人声怎么选，出了问题怎么重做

**已有原唱。** 收到哪版录音就用哪版排镜，先核对艺人、时长、开头和结尾。把音频放在项目的素材目录，从本地音频量时间。想让副歌更有力，先改镜头和切点，保留原唱的力度、气息和立体声。全曲成片可用[原声合片](music-video.md#整首原声交付)。有演唱者的干声、伴奏要重新混音时，先留一份合并前的原件供对听。

**新录旁白。** 选片中最难念顺的一小段试两条。教学可以取一个需要观众动脑的问题，广告可以取一句临时通知，语速和重音在这句话里就能判断。把“19:15”这样的显示文字另写成适合口语的台词。按相邻的完整句组提供上下文，先保留自然停连，自然句尾与下一句距离太远时再修剪。重新量好实录后安排字幕和动作。可直接试[九枚硬币](../examples/worked-lesson/brief.md)和[倒场广告](../examples/product-spot/brief.md)里的声音入口。有一条合适的人声录音时，可直接接入同一套工程。

**原创演唱。** 先给歌手或歌声模型一整个乐句，带歌词、音高、每个音的起止、连音和气口。从干声听清楚后再叠伴奏。连续元音像断了电时，先看相邻音是否在中间被切断；句尾像被撕开时，单独听最后一个韵母与尾辅音。给持续音留平稳的中段和自然收束。单字逐个朗读、拉长、拼接很容易把每个字拼成一块独立的声响。能直接对着改的[《纸鸟》歌词和音符](../examples/sung-mv/brief.md)附原片母带。

## 先听是哪一层出了问题

| 听见什么 | 在哪里查，先改什么 |
|---|---|
| 念对了，但整句僵硬 | 连听前后两句。删掉书面腔，给说话者一个说这句话的对象；重录一个完整语义单位。调响度无法改变句子重音。 |
| 爆一下、缺一个字，或韵尾突然没了 | 原始人声、工作混音、导出的 MP4 各听同一句。在原始人声就有缺口，重生成整句或换 take。只在接缝出现，找回被剪掉的辅音，在接近静音的位置处理切口。只在最终文件出现，核对码率、重复有损转码和音画截尾。 |
| 连续沙声、电流声、抽吸声 | 独听干声以及句间空隙，再加伴奏。干声源有问题时优先换录音或重新生成。提高整轨增益会一起提高底噪。只在混音出现时，逐项试听混响尾巴、高频乐器和动态处理。 |
| 单听清楚，放回视频就被吃掉 | 把音乐和干声分开，先在有问题的几个字附近降低伴奏或改变配器。保留句尾和下一拍的关系，再回到视频里听。 |

## 同一句、相近响度，切换听

本包的[旁白生成器](../kit/narrate.py)支持使用微软在线神经声音，读入形如 `{"intro":"这次，轮到你来判断。"}` 的台词文件。安装 `edge-tts` 和 FFmpeg 后，运行 `python kit/narrate.py cues.json voice --voice zh-CN-XiaoxiaoNeural` 可得到逐句 WAV。在线路线会把所选台词发给该服务；已有录音可直接走示例的本地 WAV 入口。[edge-tts 项目说明](https://github.com/rany2/edge-tts)

从最终文件取同一句的两个版本。允许新版说得更短或更长。下例先放旧样，再留 0.8 秒空隙播放新样。起止秒数按两条实际录音分别填写。

```text
python kit/listen_pair.py old.mp4 4.1 7.2 new.mp4 3.8 6.6 compare.wav
```

脚本为两段分别计算固定增益，使响度可比，同时留出峰值余量。听样使用 PCM WAV，保留原有动态。先听句子是否像人在对别人说话，再听背景和接缝，最后听一次声画合在一起是否合适。转写、响度和频谱各回答一个技术问题；把确实听过或测到的现象写清楚，保留样音让别人可以作判断。

语音与背景分开听的思路可参考 [ITU-T P.835](https://www.itu.int/dms_pubrec/itu-t/rec/p/T-REC-P.835-202607-I%21%21SUM-HTM-E.htm)。不同 TTS 对句段、发音和停顿的支持各异，使用前可查所选引擎的说明，例如 [Microsoft 的句段与停顿文档](https://learn.microsoft.com/en-us/azure/cognitive-services/speech-service/speech-synthesis-markup-structure)。
