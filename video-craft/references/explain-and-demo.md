# 产品宣传、软件演示与操作教程

> 考研/大学例题精讲、公式推演与定量科普请走 **[课程与讲题制作指南](course-and-stem.md)**。本文聚焦**轨道 B1：产品痛点短片、真实软件功能演示、开发者/CLI 教程与实体硬件宣传**，按诉求分为两档：
> - **第一档 · 清晰实操与叙事档**（默认，适合重在界面证据、操作步骤与痛点对照的软件演示和日常产品短片，用 `stage.js` + `graphic.js` + `draw.js`）；
> - **第二档 · 重装绚丽大片档**（当需要**发布会级三维流光、阳极氧化金属/折射水晶微距掠光、空间阵列与震撼视效**时，在遵循本文“卖点兑现与证据同源”底线的基础上，合读 **[重装绚丽视效指南](spectacle-3d.md)** 启用内建 `stage3d.js` PBR/HDR 引擎或 `blender_bridge.py`）。

## 一、偏好外置与上游导演构思三问（先定切口，禁套模板）

有用户指定的品牌规范、参考片或 `docs/briefs/` 确认单时优先沿用；用户把产品或功能直接交给你发挥时，先在 `brief.md` 与 `scene.js` 顶部注释回答下面三问，并通过**“换产品证伪检验”**（把产品名换成另一个无关工具仍能原样套用的空话不算）：

1. **观众在哪个具体时刻被什么麻烦卡住？**
   - 不写“效率低、协作难”，写具体处境：“周五下班前，对着三十个散装命名文件一个个手动改名”“演出前二十分钟通知改期，后台六个工种时间全乱”“半夜报警响起，在五千行日志里肉眼找哪次提交改坏了配置”。
   - 卖点只挑解决这一个麻烦的核心一两项，其余功能再多也不塞进同一条短片。
2. **用哪一个看得见的交互动作或状态跃迁兑现承诺？**
   - 概念宣传与功能演示都必须有一处**可核对的因果动作**：输入什么 → 点下/敲入/感应什么 → 状态怎样变化 → 产出什么结果。用视觉变化证明卖点，而不是拿大字口号自夸。
3. **本产品的气质生长出怎样的空间、色调与声音性格？**
   - 严肃开发工具、日常消费小应用、演出后台调度、桌面实体小硬件，各自应有截然不同的光线、构图和声响。**严禁默认照搬单一示例的“微倾手机 + 印章红”或“暗紫卡片 + 120 BPM 四和弦”**。

## 二、三条硬底线（保真度、可读节奏与纯函数时间）

无论采用何种视觉风格，以下三条工程与观看底线不可突破：

1. **证据同源与时辰一致**：
   - 真实软件优先采集真实构建的录屏、截图或可复现输出（公开前脱敏）；用原生 HTML/Canvas 重建局部控件做特写放大时，所有金额、行数、耗时、前后状态必须来自同一份真实数据常量，严禁口播与画面数字对不上。概念原型或虚构产品须在对应位置标明。
   - 台词或文案提到具体时间与环境（如“赶早班的地铁”“下午三点闷在会议室”）时，**先按该时辰锁死画面主光与底色**，绝不出现“嘴上说早晨、窗外画月亮星空”的错位。
2. **操作可追踪、结果留足阅读期**：
   - 全景先交代窗口、终端或物件所在环境，特写保住目标控件、上下文标签与状态变化区。
   - 指针沿自然弧线提前落稳在目标旁（零过冲），按下时给简短触感反馈，**结果刷新后指针移开或淡出，留稳 0.8–1.5 秒让观众在手机尺寸和静音状态下也能读清发生了什么**，再切下一镜。
3. **100% 纯函数 `seek(t)`（严禁 CSS 过渡与关键帧动画）**：
   - 无头渲染器以 `animations: 'disabled'` 任意跳帧截屏。DOM、SVG 与 Canvas 的一切位移、缩放、透明度与数字滚动都必须由 `seek(t)` 直接计算写入行内样式或画布，**绝对禁止使用 CSS `transition`、`animation` 或 `@keyframes`**，否则导出的视频会卡死或跳帧。

## 三、开放的视觉与节奏方向（启发而非菜单）

根据产品形态与受众语境自由创造，下面四种方向仅用于打开思路，鼓励混搭或另辟新局：

| 方向参考 | 适合的产品气质 | 空间、光线与声音思路 |
|---|---|---|
| **清透工作台 / 终端实操流** | 效率软件、编辑器插件、CLI/API 开发者工具、数据库与文档产品 | 正视平铺的高清亮色或护眼暗色工作区，无花哨三维倾斜；靠精准局部裁切、代码高亮对比与光标键入推进；声音采用克制的机械微响（`uiClick`、`tick`、`swipe`）配干净人声，无需铺满鼓点音乐 |
| **印刷网格与大字数据对照** | 生产力方法、定价/性能对比、年度发布摘要、规则清晰的机制卖点 | 借 [`graphic.js`](graphic.md) 纸纹或净色网格，超大号结论字与等宽编号压在一侧，另一侧由占主导面积的动态图形把“杂乱输入 → 规整输出”演透；节拍利落，转场用 `wipe`/`iris` 从焦点扫开 |
| **2.5D 空间舞台与穿屏流转** | 多端协同应用、移动端产品、从外部混乱场景收敛进产品内部 | 开头在真实生活/沟通杂乱感中立住痛点，设备带柔和双层投影入场；演示核心操作时平滑转正放大，或经屏幕中心无缝穿入内部状态图再拉回；音乐随“混乱低通 → 豁然开朗 → 核心停拍揭晓”起伏 |
| **生活现场光影与实物隐喻** | 智能硬件、桌面小物、健康/家居/出行服务、情绪共鸣型品牌片 | 不靠屏幕堆界面，把镜头放在玄关、书桌、车窗或舞台侧幕的光影变化上（`draw.js` 的 `lightBeam`、`bokeh`、`withHandheld`）；用一件具体器物的明暗/颜色响应说明产品如何介入人的生活 |

## 四、按需取用的交互与转场零件（`kit/stage.js` + `sound.js`）

`kit/stage.js` 提供纯数学与可选绘制辅助，**不绑定任何配色或设备外壳**，DOM 与 Canvas 均可直接调用：

- **自然弧线指针与定点波纹（`cursorAt` + `drawCursor`）**：
  - 传入按时间排序的路标 `[{ t: 0.4, x: 1180, y: 640 }, { t: 1.3, x: 820, y: 460, click: true }, ...]`，`cursorAt(t, waypoints)` 用微弯二次贝塞尔弧线平滑接近，在点击前稳稳停住（绝不飞过小按钮），点击波纹 `ripple` 严格钉在点击坐标上不会随指针撤离而漂移。
  - Canvas 可直接调 `drawCursor(ctx, state, { kind: 'arrow' | 'dot' | 'ring', fill, stroke, accent })`；DOM 可直接读 `state.x`、`state.y`、`state.press` 赋给自定义光标元素。
- **圆角无漏边穿屏变换（`throughScreen` + `cssStageTransform` / `applyStageCamera`）**：
  - 当你选择做“推进穿过设备屏幕”或“从全屏内景拉回设备”时，`throughScreen(k, screenRect, viewport, { borderRadius, pose0 })` 会自动扣除圆角内接安全边距（`r * (1 - √1/2)`），在对数空间插值缩放并在 `k = 0.82` 前提前展平三维倾角，数学上保证 `k = 1` 时屏幕四边与四个圆角完全越出画幅，绝不露出一丝设备黑边；同时需保证屏幕底色与下一镜底色一致。
  - **注意**：穿屏只是众多转场之一；正视画面上的直接硬切、局部放大裁切、分屏并置往往更干脆，按内容需要选用。
- **双阶段原地形变与移位（`morphMoveRect`、`lerpRect`、`arcPoint`）**：
  - 需要把散乱元素收拢进列表或拓扑图时，遵循“先原地形变（约 0.35–0.45 秒），再沿轨迹飞入目标位（约 0.5–0.65 秒）”的分段原则，避免边飞边变形糊成一团。
- **不跳位的滚动读数（`rollNumber`）**：
  - 生成固定小数位与千分位的数字文本；画面字体务必配等宽字体或 CSS `font-variant-numeric: tabular-nums`，防止数字滚动时左右抖动。
- **触感界面微音效（`kit/sound.js`）**：
  - 点击用确定性机械瞬态 `uiClick`（比卡通音高上滑的 `pop` 更像真实按键/触控板），面板抽屉滑动用 `swipe`，状态完成可用清透泛音 `glass` 或轻盈 `pluck`。走 `audio.mjs index.html - out.webm` 纯旁白模式时，这些事件也可直接写进 `meta.sfx`。

## 五、两类典型分镜试写

### 1. 操作教程 · 教读者修正 CSV 日期导入（重在可复做与防踩坑）

1. **同屏立住问题**：正视界面同时露出被误判为纯文本的日期列与两条原始记录，保住文件名与列头供定位。
2. **推进核心操作**：平滑放大到日期格式下拉框，指针提前落稳在匹配格式上点下，配一声干净的 `uiClick`。
3. **留住同一条记录验结果**：等预览刷新，保持同一条记录在画面原位，高亮列类型与解析后的标准日期。若观众常选错格式，可补一个 3 秒的报错恢复镜头。

### 2. 功能短宣传 · 批量重命名（重在前后对照与边界诚实）

| 镜头 | 画面与剪辑 |
|---|---|
| 1 · 认出麻烦 | 文件列表占满可读主区，三个同项目散乱命名的文件依次亮起，保留其中一个文件的缩略图或大小供后镜追踪。 |
| 2 · 规则与实时预览 | 框选三条记录，输入重命名规则；镜头停在“旧名 → 新名”并列预览上，让观众亲眼核对匹配结果。 |
| 3 · 提交与可撤销证明 | 点下应用（`uiClick` + 轻柔 `glass`），留住同一条记录直至列表刷新；若宣传“一键撤销”，就真实录下撤销后原名恢复的那一拍。 |
| 4 · 收束签名 | 用文件名中的同一编号做视觉衔接切入品牌尾卡；承诺语只写前文已经亲眼兑现的那一件事。 |

## 六、如何正确向现有示例借骨架（禁抄皮）

- **[开场，提前十五分（product-spot）](../examples/product-spot/brief.md)**：值得借的是**“真实可运行网页（`product.html`）+ 自动采样截图与坐标（`proof.js`）+ 导出一份真台本兑现承诺”**的证据链闭环；**不要模仿**它早期试验留下的 `1536×864 @ 24fps` 非标规格、硬边多边形光柱和简笔歌手小人（成片一律交付 `1920×1080 @ 30fps`）。
- **[两清（promo）](../examples/promo/brief.md)**：值得借的是**“全部账目与最少转账笔数由同一份 `EXP` 数组算出 + 音乐随叙事收放（闷鼓→进鼓→停鼓揭晓→盖章）”**；它的倾斜手机、群聊飞票据和印章红只属于“熟人AA算账”这一个虚构题材，做别的软件或硬件时请从零设计专属舞台。
- **[图上挨着的两站（transit-map）](../examples/transit-map/brief.md)**：展示了完全不画三维设备、仅靠 `graphic.js` 印刷网格与核心动态几何就把机制讲透的版面路线。
