# 版面式动态设计

核心画面是图形、数字、界面或图标，而不是一个地方、一种天色时，画面不必画成场景，可以靠版面完成：网格、悬殊的字号、一个强调色、细节层和纸面质感。讲概念和数据、介绍产品功能、片头、发布会式宣传都适合。一条片子里可以和[画出来的场景](drawing.md)交替：场景给气氛，版面讲信息。

**版面不能代替核心画面。** 每一镜里都要有一张会动、讲清这件事的图形：线路被拉直，柱子长高，数字一格格跑，界面里的东西被拖动。盖住大字，画面仍在讲；只剩纸纹、网格、大标题和小标签的一镜，是换了衣服的幻灯片。完整示例是[地铁图](../examples/transit-map/brief.md)：讲清道理的，是街道上弯曲的线路被拉直、拉匀，变成地铁图。零件在 [`kit/graphic.js`](../kit/graphic.js)。

## 和幻灯片差在哪里

| 幻灯片 | 版面式 |
|---|---|
| 标题居中，下面几条要点 | 不对称：大字压在网格的一侧，另一侧是会动的核心图形或卡片；大的东西可以出到画面外 |
| 字号差不多 | 字号悬殊：标题 80–300 px 粗黑体，标签 18–24 px 等宽字、字距拉开 0.15–0.2 em，中间几乎没有别的字号 |
| 颜色多，分量平均 | 纸色、墨色加一个强调色，最多再加一个冷色。强调色只给要看的那几个字或那一个点 |
| 东西一起淡入 | 各有各的进场：线画出来，字从下面升起，标签逐字解出，卡片揭开。先后错开 0.1–0.2 秒 |
| 干净的纯色底 | 有纸纹或细颗粒、看得见的网格线、色条和角标、编号（01 / 02）、刻度和读数。这层细节让画面看起来是设计过的，但它只是陪衬 |
| 图片摆在正中 | 图片当卡片放进网格，带角标或偏移的色块阴影，卡片里慢慢推近 |
| 翻到下一页 | 转场从主体出发、用强调色：从要看的那一站打开一个圆，一条强调色的斜条扫过。一条片子只用一两种 |

## 一镜怎么搭

1. **底**：`paper(ctx, 纸色)`，或深色底。`grid()` 返回列线和行线的位置，所有东西都对齐到这些线上。
2. **核心图形**：占画面 40–60%，一直在讲：画出来、变形、计数、移动。
3. **大字**：`headline()` 压在网格左侧或上方，最多三行，说的正是图形此刻的变化。
4. **细节层**：`rule` 色条加 `label` 编号或英文小标题，`marks` 角标，`ruler` 刻度，`ring` 圆环，跳动的读数。
5. **收尾**：`finish(ctx, frame, { vignette: 0.1, grain: 0.035 })`，它来自 `draw.js`，不在 graphic.js 里。

```js
import { register, clamp } from '<kit>/kit.js';      // <kit> 换成到 kit 目录的相对路径
import { finish } from '<kit>/draw.js';
import { paper, grid, rule, label, headline } from '<kit>/graphic.js';
// …在 seek(t) 里：
paper(ctx, '#ECE7DC');
const g = grid(ctx, clamp(t / 1.2), { x: 120, y: 120, w: 1680, h: 840, color: 'rgba(22,24,29,.09)' });
rule(ctx, g.x[0], 150, 260, clamp((t - 0.2) / 0.5), { color: '#E2432E', width: 6 });
label(ctx, 'TRANSIT MAP / 01', g.x[0], 200, t - 0.3, { size: 22, color: '#16181D' });
headline(ctx, ['图上两站挨着，', { text: '走起来二十分钟。', accent: [3, 7, '#E2432E'] }], g.x[0], 300, t - 0.5, { size: 112 });
drawCore(ctx, t);   // 你自己的核心图形：占画面 40–60%，一直在动。少了它，上面几行只是一张幻灯片
finish(ctx, Math.round(t * 30), { vignette: 0.1, grain: 0.035 });
```

## 零件

- **`k`**：0–1 的进度，写成线性的 `clamp((t - 开始) / 时长)`。零件自己会缓动，不要再套 `seg()` 或缓动函数。
- **`s`**：零件开始后经过的秒数。负数时不画。
- **`exit`**：开始退场后经过的秒数。负数表示还没退场。
- **颜色**：写成 `'#rrggbb'`。只描边或填色的零件也接受 `rgba(...)`。

| 零件 | 做什么 | 可试时长 |
|---|---|---|
| `paper(ctx, color, {grain, fibres})` | 纸面底：固定的细颗粒和纤维。同一场景里颜色保持不变 | — |
| `grid(ctx, k, {x, y, w, h, cols, rows, color, width})` → `{x[], y[], col, row}` | 网格线画出；返回的位置用来对齐 | 0.8–1.4 s |
| `rule(ctx, x, y, w, k, {color, width, from})` | 细线、强调色条 | 0.4–0.6 s |
| `marks(ctx, x, y, w, h, k, {color})` | 框外的四个角标 | 0.4 s |
| `slant(ctx, x, w, {angle, color})` | 贯穿上下的斜色块；`x` 由你随 t 改变 | 进场 0.5–0.8 s |
| `label(ctx, text, x, y, s, {size, color, track, align, exit})` | 等宽小标签，从左往右逐字解出，数字只换成数字。中文短语可以，整句用 `headline` | 按字数自动定 0.45–1.4 s |
| `headline(ctx, lines, x, y, s, {size, color, align, mode, stagger, exit, exitMode})` | 大字，`(x, y)` 是字块左上角。`mode`：`rise` 逐字从遮罩里升起；`slam` 从 1.5 倍落下，带三帧震动；`track` 字距收拢；`glitch` 撕成横条后归位；`cut` 直接出现。要给几个字上色，那一行写成对象：`{ text: '走起来二十分钟。', accent: [3, 7, '#E2432E'] }`，下标从 0 起，不含止点 | `rise` 每字 0.6 s，字间错开 0.035 s；`slam` 约 0.4 s 落地；退场 0.35–0.45 s |
| `glitch(ctx, 画布, k)`、`shake(s)` | 把一张离屏画撕成横条再归位；落地后的三帧震动，返回 `[dx, dy]` | 0.4–0.6 s；3 帧 |
| `card(ctx, 图, x, y, w, h, s, {from, shadow, frame, pad, markColor, push, exit})` | 一张图当卡片揭开，卡片里慢慢推近。图可以是 `layer()` 画好的离屏画布（示例里的地图卡片），也可以是照片 | 揭开 0.8 s |
| `image(url)`、`cover(ctx, 图, x, y, w, h, {zoom, fx, fy})`、`scrim(ctx, {side, alpha})` | 读入照片：`image()` 返回 Promise，在 `register()` 之前 `await` 完，否则这一帧什么也画不出。`cover` 铺满一个框，`zoom` 大于 1 时围绕 `(fx, fy)` 推近。`scrim` 压暗放字的那一侧 | — |
| `ring(ctx, x, y, r, k, {sweep, ticks, rot, color, width})` | 圆环和刻度环，`rot` 随 t 慢转 | 0.6–1.0 s |
| `ruler(ctx, x, y, len, k, {n, major})` | 刻度尺、比例尺 | 0.6 s |
| `wave(ctx, x, y, w, h, values, k, {head, accent})` | 波形条，`head` 是播放头的位置 | — |
| `surface(ctx, f, {rot, size, burst, nu})` 与 `shapes.ribbon / sheet / torus` | 平面着色的 3D 形体：扭带、波面、圆环。`burst` 从 0 到 1 让它碎开，这时 `nu` 取 30–40。只在它就是主角时用，比如片头里一条扭带碎开、拼成标题；不当背景装饰 | 碎开 1.2–1.6 s |
| `wipe(ctx, k, 画下一镜, {color})`、`iris(ctx, k, 画下一镜, {x, y, ring})`、`halftone(ctx, k, 画下一镜, {color})` | 转场：先画上一镜，再调用它，`画下一镜` 是 `(ctx) => …`。`iris` 的圆心放在下一镜要看的东西上 | wipe 0.5–0.7 s，iris 0.6–0.9 s，halftone 1.0–1.4 s |

## 节奏

- 进场快，停得稳，退场更快：进场 0.45–0.9 秒，退场 0.35–0.45 秒。停住的时候，核心图形里要有东西继续动，比如列车点在走、读数在跳、圆环在转，整个版面也可以慢慢推近。
- 要落在拍点上的字，用 `slam` 时提前约 0.4 秒开始。
- 一镜只有一个主动作。标签、角标和刻度跟在主动作后面 0.1–0.3 秒。
- 说到什么就出什么：画面上的字和它所说的变化同时发生（示例里“线拉直”出现时，线正在变直）。
- 上一镜的字在转场开始前退完，转场里只出现下一镜；转场开到一半时，下一镜的主体和大字已经在里面，不要打开一张空纸。

## 照片

照片当卡片：`card()` 放进网格，带角标或偏移阴影，旁边配大字和标签。照片交代地方和东西，信息仍然由会动的图形讲。照片是用户给的，或者本机有 imagecraft 时可以生成，但不是默认路径。不要把整片做成一张张铺满的照片慢慢放大：那是另一种幻灯片。

## 检查

- **对“little changes”标记，在任务单里逐段写明哪里在动。** 版面的底是平的，`shotlist.py` 有时会在核心图形一直在动的段落上标“little changes”。看那一段的帧条，在任务单里逐段写清：哪个时段，画面哪个位置，什么在动（“4.2–9.2 s：右半边的线在画，红点沿尺寸线走，计时从 00:00 跑到 20:00”）。只有颗粒、慢推或一个转动的圆环，不算理由，要改。
- **看原尺寸。** 标签不小于 18 px（1080p）；细线不细于 1.5 px；强调色只出现在要看的地方。
- **字号分两类。** 标签是索引和装饰，不读也能看懂。观众必须读的字（结论、数字、距离）照字幕的规定，不小于画面高的 1/30。出处和“示意”这类附注可以小，但不小于 24 px。
- **字体和字重。** 一种黑体，最多两种字重，比如 900 和 400；另加一种等宽字做标签。
