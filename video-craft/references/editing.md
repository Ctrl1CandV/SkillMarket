# 先把镜头剪起来

在昂贵的动画、特效或调色之前，用关键静帧、屏录、低分辨率渲染和临时音轨拼一版能播放的片。最早要决定的是镜头有没有拍到需要的东西，动作是否接得上，以及停多久观众才看清。镜头次序与时长成立后，逐个将占位静帧换成最终素材。已有剪辑工程可以在原工程里做。

## 一个可以重排的剪辑单

把这份 JSON 存在素材旁边，文件名用自己的。每次调剪只改入点、时长或次序。下面是软件展示的一段粗剪。第一张是设计样帧，第二镜取真实操作，第三镜给观众留时间确认结果。

```json
{
  "width": 1280, "height": 720, "fps": 24,
  "audio": { "file": "sound/guide.wav", "in": 1.5 },
  "shots": [
    { "image": "board/context.png", "duration": 1.25 },
    { "video": "capture/action.mp4", "in": 3.5, "duration": 4 },
    { "image": "board/result.png", "duration": 2.75 }
  ]
}
```

```text
node <kit>/cut.mjs edit.json out/review.mp4
```

- 路径相对于剪辑单。每镜指定一张图片（PNG / JPEG 等常规静帧）或一段视频。视频的 `in` 是素材内的秒数，`duration` 是留在成片里的秒数。累积切点对齐到输出帧。视频素材过短会报出镜号。
- 默认把整帧放进画面，空处留黑。全屏构图可在相应镜头加 `"fit": "cover"` 居中裁满。人物偏在画面一侧或软件按钮靠边时，先在原工程单独重构图，再导入已取景的镜头。
- 有些录屏先有声音，图像稍后才开始。入点落在这段间隔时，首幅画面会保持到视频流开始，后续动作仍按原时码发生。
- 用统一母带时，`audio.in` 从原曲或录音的指定位置起播，短于画面的尾部补静音，长于画面则在片尾截断。歌尾的混响或淡出由剪辑者决定。
- 想保留录屏里的点击声、对白或现场声，省略顶层 `audio`，在对应的视频镜头中写 `"sound": true`。声音跟随该镜头入点和出点，静帧及其他镜头留静音。既用音乐又叠同期声、或想让对白跨过切点时，在声音工程混好母带后用第一种方式。全部省略得到无声片。
- 新片可先在小尺寸试剪，再按目标画幅和帧率出片。合成转场、移动遮罩或景深变化可以在单个镜头内完成后导入。剪辑单适合直接切换和镜头组装。
- 这个 MP4 输出用于常规 SDR。混用相机 Log、HDR 手机录屏或不同色域素材时，在各自的调色/转码阶段先转到同一交付色彩空间。

## 看粗剪时怎样下决定

先让声音连续走一遍。若下一句旁白已经解释结果，画面上鼠标还在寻找按钮，把说明后移或压缩寻找的过程。若副歌一响，最强的画面已经过了两拍，在乐句中挪切点，比给全段加速更容易保留动作质感。若空间关系在特写之间断了，把交代两者方位的全景挪到观众产生疑问之前。

可以用同一段音乐、同一批镜头只改变一个切点，连续播放两版。记下在哪一版先看到线索、哪一版冲击落在重音上，然后保留更接近意图的版本。回到制作清单时写具体修改，例如“门把转动在声音响起前一帧可见，把门后的反应再晚留半秒”。
