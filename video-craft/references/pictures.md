# 核心画面与结构

## 找到片子要靠什么成立

从观众真正会看到、听到或亲历的东西起步。写下一个具体画面或一段声画关系，说明其中什么变化值得观众注意。它可以是一次操作前后的状态、一个人物终于做出的动作、一段音乐使同一画面获得的新含义。

| 任务 | 可以先做出来看的画面 |
|---|---|
| 科普与数据 | 同一束光走过两种长度的空气路径，两条光束与路径同时在场。光束的变化与旁白提到的条件能逐一对应。 |
| 软件演示 | 用同一份输入跑一次真实操作，留下触发动作和可核对的结果。镜头可以直接留在成功后的界面。 |
| 教程 | 让观众先认出要改变的地方，再看到完整动作，最后停在实际照做时应看到的状态。 |
| 叙事短片 | 一盏窗灯每晚在同一构图中亮起。最后同一位置只剩室外反光，让观众先察觉人物缺席，再用下一镜交代发生了什么。 |
| MV 与视听作品 | 同一轮廓随四句乐句反复出现，前三次在句尾断开，最后一次跨过休止。随乐句重现的图形让这一处变化被听见和看见。 |
| 艺术短片与片头 | 闭合的金属环推进到几乎占满画幅，切到同构的空洞，材质与比例的反差给出作品的第一个感觉。 |

科学、数据和教程可以做一次遮字试验。画面能否让人找对对象、看见动作或比较结果？数字、坐标、单位、适用条件和准确的命令仍靠清晰的标签、字幕或旁白交付。叙事、纯视觉和音乐作品可以分别看无声版本、听纯音轨，再看它们怎样在一起成立。

科普、教程和软件产品的具体分镜见 [讲解、教程与软件演示](explain-and-demo.md)。需要用一个连续跨尺度镜头解释现象时，看 [sky 的分镜](../examples/sky/brief.md)。虚构产品如何把一个卖点做成视觉对照，可看 [promo 的分镜](../examples/promo/brief.md)。

## 让细节来自题材

找一件反复出现就有含义的东西，如排队演示里同一个人的橙色上衣、软件操作里始终可认出的那一行数据。只给需要追踪的对象稳定的颜色、形状、位置或声音。跨尺度时保留一个共同轮廓或运动方向，给观众认出同一个对象的时间。

道具、材质和声音也可以承担结尾。虚构的「两清」用一枚有旧账单意象的印章收束“结清”。天空一片给各波长分配音高，蓝光逐渐离开光束的同时，配乐里的高音退去。选用这种对应关系时，辨明哪些是观众要从片中学到的事实，哪些是为了观看而选的表现手法。

对有事实主张的片子，在任务单里记下实测、来源、模拟参数和舍入方式。画面、字幕、口播复用同一取值。需要用夸张尺寸、不同时间尺度或合成条件说明机制时，在会被误读的那一刻加说明。

## 让开头和结尾完成各自的工作

开头给观众一个值得继续看的对象、声音或问题。选择封面帧可以单独考虑。画面可以一开始就清楚明亮，也可以从声音、黑场、一个细节或有意的留白开始，看片时核对观众实际何时得到第一个线索。

结尾留在有意义的状态上。教程给观众读完结果或抄下命令的时间，产品片让品牌或操作结果在发布尺寸下读得完，MV 可以把最后一拍的余音留给仍在动的主体，也可以干脆切黑。2–3 秒可以作为单独结尾卡的试做起点，根据内容和平台画面判断。
