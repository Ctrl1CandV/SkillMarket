# 电影感短片与栏目片头

> 适用**轨道 B3：氛围叙事短片、视觉与材质奇观、播客/频道/发布会片头**。含蓄光影叙事可走第一档（`draw.js` + `graphic.js`）；需要**三维物理材质、折射水晶/薄膜虹彩、光线步进流体或 Blender 级 HDR 震撼奇观**时，直接联用 **[第二档：重装绚丽视效指南](spectacle-3d.md)**（`stage3d.js` / `shader.js { sdf: true }` / `blender_bridge.py`）。核心是在不绑死暗夜灯塔或单一模板的前提下，用清晰的视觉因果、空间光影和声音层次立住作品性格。

---

## 一、偏好外置与上游导演三问

有用户指定的母题、色板或确认单时优先沿用；自由创作时，先在 `brief.md` 与 `scene.js` 头部写下三条**“因为本片具体情境/栏目气质 → 所以专属空间材质 / 镜头因果链 / 声音与留白”**（换一部无关短片或栏目仍成立的空话不算）：

1. **谁（或什么主体）要改变什么、阻力在哪、最后留下什么可见变化？**
   - 叙事短片哪怕只有 15–25 秒，也要有一条可拍的动作链（人影、船、门缝的光、桌上的钟表、一片转动的鳞翅）；片头则要有一个从局部细节或几何张力收束到栏目签名的视觉母题。
   - 关掉声音把分镜缩成四五张关键帧，观众仍能一眼看出前后的状态反转。
2. **主光与视觉语言属于哪一个世界？**
   - **开放方向启发**（绝不默认锁死雾夜海岸）：
     - **日常室内与建筑光影**：午后百叶窗切过桌面的光带（`draw.js` `lightBeam`）、走廊门缝开合、车窗掠过的树影与散景（`bokeh` + `withHandheld`），克制而有生活悬念；
     - **微距物理与材质奇观**：晶体折射、水面焦散、金属/鳞翅随入射角变色（`shader.js` 或 WebGL），先在微距证实表面随光变化，再拉开揭示全貌；
     - **高反差动态版面与三维形体片头**：借 [`graphic.js`](graphic.md) 的网格、等宽编号、`surface` 多面体扭带碎裂重组与 `wipe`/`iris` 遮罩转场，适合科技、设计与文化播客片头；
     - **开阔自然与晨昏调度**：山谷流雾、雨幕海岸、航灯转向，靠多深度视差层（`view(ctx, cam, depth, fn)`）拉出空间尺度。
3. **声音如何先于或反衬画面？**
   - 环境底噪（屋内闷风 vs 屋外开阔风声）、近处器物拟音（开关咔哒、纸张摩擦）与克制的乐音各司其职；安静与留白同样是镜头语言的一部分。

## 二、用镜头交代空间与因果

| 镜头职责 | 观众应当看见 |
| --- | --- |
| **全景立局面** | 主体、目标与环境关系在哪儿，主光从哪一侧来 |
| **中景见准备** | 视线或光束投向何处、停顿多久、动作如何蓄力 |
| **近景定触点** | 开关合上、光束扫过、线条咬合或字块落位的那一帧，必须给出远景没有的新细节 |
| **回望见余韵** | 变化传到整个空间后，开头的哪个关系已经不同；留够余音与画面呼吸再收束 |

- **轴线与视线顺畅**：相邻镜头沿同一侧拍时保留一致的左右方位与来去方向；需要越轴时，在画面内完成转向或插入中性正面/全景镜头过渡（如 [《回光》](../examples/short-film/brief.md) 让船头在画内转过再回远景）。
- **动作接点带前后量**：切在动作上时，切前留足准备，切后留住惯性、余震、烟雾或水波继续走完；静止长镜头用 `withHandheld(cam, t, { amp: 4 })` 或环境光尘保持呼吸，避免画面像死机冻结。
- **纯函数时间铁律**：所有画布、WebGL uniform 与 DOM 元素严格由 `seek(t)` 纯函数驱动，外层背景与山脊留足安全出血余量（`≥ 200px`），确保运镜与手持微晃绝不露出画布黑边。

## 三、光、材质与分层合成

1. **先做无特效色块稿**：拿掉辉光和颗粒，单看明暗剪影与前中后景是否分明。把全画面最高亮的一小块留给当前动作焦点；暗调片在普通屏幕亮度下也要认得出主体轮廓，亮调片用投影与色温冷暖差（而非发白失效的 `lighter` 叠加）拉开层次。
2. **光走四层**：分别画发光体本身、空气中的光柱/雾气（`lightBeam`）、受光面边缘高光、地面或水面反射，最后统一叠 `bloom` 与 `finish` 颗粒，编码成 MP4 后再抽帧核对暗部有无色带。
3. **跨引擎与外部素材边界**：代码擅长光影、几何、流体着色器、建筑剪影与版面动效；涉及写实人物表情或复杂肢体时，用剪影、背影、局部光影或用户提供的实拍/图片底版分层合成（显卡繁忙时严禁擅自调起本机 ComfyUI 生图）。

## 四、审查与参考拆解

- 先静音连看一遍：标出观众第一次认出处境、核心动作完成与状态反转的秒数；再合上声音核对拟音方位、切点提前量与尾音收束，跑 `shotlist.py` 与解码抽帧复核（见 [审查](review.md)）。
- **多方向参考示例**（只借镜头逻辑，不抄原片题材与配色）：
  - [《回光》（short-film）](../examples/short-film/brief.md)：五个镜头完成“驶向礁岸 → 合上开关 → 透镜点亮 → 船头转向 → 远景脱离”的完整因果链与空间声音转换。
  - [《显色》（iridescence）](../examples/iridescence/brief.md)：微距鳞片随动光由青紫转金再拉出蝶形轮廓的材质片头。
  - [《山谷入夜》（layers）](../examples/layers/brief.md)：纯 Canvas 2D 八层景深、大气透视与水面逐行倒影的轻量基准。
