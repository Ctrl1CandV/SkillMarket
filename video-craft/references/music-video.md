# MV：跟着一首歌拍

一支好 MV 让歌里那种处境的人认出自己：画面演的是那个人的生活和心情，把时间留给最戳人的那几句。段落一换，故事往前走一步。副歌回来时，同一样东西已经变了。歌词字幕跟着唱。切点落在拍子上，鼓点让光跳一下，最后一个长音留给最后一个镜头。

做法：给歌做地图，做内容设计，定视觉世界和段落表，排镜头表，在页面里跟着歌画、配字幕，审片。

## 1. 先给歌做一张地图

```text
python <kit>/songmap.py media/song.m4a out/song --lyrics            # 英文歌加 --language en
```

默认每小节 4 拍。作者说明、乐谱，或 `songmap.png` 上低频重击每 3 拍才一次，表明是 3/4 拍时，加 `--meter 3` 重跑，不在页面里自己重算小节。

输出到 `out/song/`：

- `songmap.md`：段落表。每段的起止、第一个小节的序号（`first bar`，在页面里用 `SONG.downbeats[n]` 取时间）、小节数、听起来和前面哪段相同（`same as #n`，回来的副歌、主歌或乐句）、响度、性格，以及这段唱了什么。
- `songmap.json` 和 `songmap.js`：拍点 `beats`、小节线 `downbeats`、段落 `sections`；低/中/高三个频段的重击 `hits`，以及从中挑出的重音 `accents`（大约每小节一个，给灯光和镜头用）；逐帧的响度和低频/高频能量 `env`；带时间的歌词 `lyrics.lines`。
- `songmap.png`：波形、能量、段落和歌词的总览图。

先核对三件事：

- **速度**：听前奏数拍。快一倍或慢一半时，加 `--bpm` 重跑。
- **段落边界**：在你准备切的边界附近听一遍。
- **歌词**：机器转写会听错，也会把纯音乐段落写成“oh oh”之类的重复。改法见[歌词字幕](#歌词字幕)。

自己听不到声音时（只能读文件的模型），这样核对：

- 速度：看 `songmap.png` 上低频重击的间隔，和 `beats` 的间隔比，一小节里通常有 2 或 4 次底鼓（3/4 拍通常 1 次）。差一倍时用 `--bpm` 重跑。
- 段落：看能量曲线的台阶是否和段落边界对齐，副歌通常更响、高频更多。
- 歌词：转写有大段重复、意思不通时，向用户要歌词，或查官方歌词，时间仍用转写的。
- 切点：没法试听时，切在小节线或第 3 拍（半小节）那一帧。

## 2. 内容设计：这首歌唱给谁，说中他们什么

MV 的观众多半是这首歌的听众。反复听一首歌的人，常常就在歌里的处境中：想念一个见不到的人，刚分开，毕业后散了。MV 要让他们认出自己，所以内容放在歌里最让他们难受或心动的那些时刻上，不放在好看的道具和奇观上。

把整首歌词读完（外语歌先逐句译成中文，意思对就行），写下面几件事，放进 `brief.md`：

1. **谁在听，处在什么境况。** 写一个具体的人。
2. **用自己的话逐段复述，写出每句底下的原因。** 歌词常常只说半句，原因在底下。矛盾的句子最戳人：想要又害怕，说放下其实放不下，求你别走又说别再来。把两头为什么都成立写透。
3. **一句话写出它疼（或甜）在哪里。** 写感受，不写情节。
4. **温度。** 淡淡的、压着的，还是撕心裂肺、热烈的？淡淡的痛不用奇观，副歌也不炸开，最重的情绪落在最小的动作上；热烈的歌才配大场面。温度也决定节奏、景别和颜色。
5. **给歌里的人一段具体的生活。** 他们是谁，经历了什么；在一起或失去之前，有哪两三件日常小事：一个杯子、一条路、一句常说的话。观众要先看到他拥有过什么，才会疼他失去了什么。挑听众自己也有的那种细节。
6. **戳人的句子，各配一个让人心里一沉的画面。** 挑两到四句，写下唱到那句时观众看到什么。逐句检验：这一镜里有一件具体的物件或动作（不是天空、粒子或光效）吗？换一首歌，这一镜还成立吗？成立就说明它没有说中这首歌。
7. **唱的人怎么看这件事。** 渴望、后悔、不甘、自嘲、放手……用一句话写下这个态度。高潮和结尾要落在这个态度上，不能替歌手把结局改好：一首讲失去和后悔的歌，高潮画成两人终于重逢，就把歌唱反了。器乐没有歌词，态度从标题和曲子的形状里找：`songmap.md` 里哪段最响，哪段鼓停了（`quiet, drops`），回来的副歌（`same as`）比第一次更满还是一样，结尾落在重拍上还是慢慢散掉。听不出大调小调、又拿不准时，问用户这首歌在讲什么。

用户常常比你更懂这首歌对听众意味着什么。用户交代任务时没说直接做完，就在动手画之前把内容设计列在回复里，请用户看一眼，只停这一次；用户说了直接做完，或者没人能回复（批量、定时、评测任务），就写进任务单接着做，交付时一并列出。

**比喻留在歌词里。** 标题和歌词里的比喻（时间机器、星星、大海）是唱的人形容心情的方式，不是要搭出来的道具。把比喻造成一台机器、一座宫殿，观众的注意力就跑到道具上，那个人的心情没地方放。要画的是比喻所指的东西：“梦像回到过去的机器”，画的就是梦把他带回去的那段日子。

**每一段是故事里不同的一刻。** 段落表的每一行写一个具体的时刻，例如下面那首歌里的下班路上、回到出租屋、翻到合照、想起面馆、打了字又删掉，不要同几个镜位换个光重复。副歌回来时，同样的旋律落在故事更往后的一刻上。

例：一首唱毕业后渐渐失联的朋友的歌（虚构）。

- 谁在听：毕业三五年，在别的城市上班，翻到老照片会愣一下的人。
- 复述一句：“又路过那条街”底下不是想回学校，是想起那时候身边有人。
- 疼在哪里：没有吵翻，只是慢慢不联系了，想起来时已经不知道怎么开口。
- 温度：淡，怀念多于难过。不哭，不淋雨奔跑。
- 具体的生活：宿舍楼下那家面馆，两个人分着用一副耳机，群聊里最后一条消息停在三年前的生日祝福。
- 戳人的一句，“我们没有说再见，只是没再见”：他打下“最近好吗”，看了一会儿，删掉，把手机扣在桌上。
- 态度：怀念，不怪谁，也不会真的去联系。

## 3. 视觉世界和段落表

内容定了，再定怎么画：

1. **视觉世界。** 从故事里来的一个地方和一种光，要能用代码画好（见 [drawing.md](drawing.md)）：那间宿舍、那条回家的路、夜里的车窗。有人的镜头写明人怎么出现：剪影、背影、手，或者只拍他留下的物件。
2. **反复出现、每次不同的东西。** 从第 2 步那几件日常小事里挑一样，例如那副耳机。每回来一次，它在故事里的意思就变一次：两个人一人一只，后来只剩一只挂在他耳朵上，最后收在抽屉里。

然后写段落表。每行一个段落，时间取自 `songmap.md`：

| 段落 | 时间 | 这段唱了什么，底下的原因 | 故事里的哪一刻 | 观众新看到什么 | 光和颜色 | 镜头力度 |
|---|---|---|---|---|---|---|
| 主歌 1 | 0:14–0:42 | 又路过学校那条街；不是想回去，是想起那时候有人一起 | 下班路上，公交车窗外闪过学校的围墙 | 车窗上一个侧影，耳机线只垂下一边 | 傍晚，车厢冷白，窗外暖黄 | 慢，长镜头 |
| 副歌 1 | 0:42–1:10 | 想问一句近况，又怕对方早就忘了 | 回到出租屋，翻出那张合照，想起面馆 | 面馆桌上两只碗，两只手的剪影抢最后一块肉，一副耳机一人一只 | 回忆暖黄，现在冷蓝 | 1–2 小节，随每句歌词换 |
| … | | | | | | |
| 最后的副歌 | | | 他一个人坐在当年那家面馆，打下“最近好吗”又删掉 | 对面的座位空着；手机屏幕上那行字一个个退回去 | 夜里的暖灯，屏幕的冷光 | 最大的变化来自故事，不来自特效 |

每一段都要有新东西，`same as` 标出的重复段落也一样。全片最大的变化放在最后一次副歌或桥段，而且是故事里的变化。

写完对照读两遍：

- 把第 2 步第 7 条那句态度和高潮、结尾两格对照：画面说的结局和歌手说的结局是同一个吗？
- 把第 2 步第 6 条那几句和段落表对照：每句都有画面吗？这些画面是在演那一刻的心情，还是只把字画了出来？

**关键句要落在那一刻。** 标题句、钩子句、情绪转折句唱出来的时候，故事里对应的那件事正好发生：不是把字画出来。唱到“只是没再见”时，他删掉的那行字刚好退完最后一个字。把这些句子和对应的画面写在段落表下面。

## 4. 镜头表落在小节上

镜头的起止取自 `songmap` 的 `downbeats` 和 `beats`。不要用 BPM 从 0 秒开始自己算：歌曲第一拍往往不在 0 秒。算错一个弱起，所有切点都会整体偏掉。

- **长度跟着段落变。** 主歌 2–4 小节一个镜头，预副歌逐渐变短，副歌 1–2 小节，偶尔插一个只有一两拍的短镜头或一个长的停留。桥段可以很长。不要连续四个以上同样长的镜头。
- **切在小节线或重拍上。** 跟人声走的切点可以落在某个词的起音上（歌词有时间）。同一处切点做提前两帧、同帧、滞后两帧三个版本，看哪个舒服。
- **每个镜头里有一个变化。** 可以是相机在动，主体做一件事，或光在变。动作做完了就切。
- **切到近景时，要给出新的细节。** 远景看到他坐在桌前，近景看到手机屏幕上那行打了又删的字。只把上一镜放大不算新镜头。
- **鼓点驱动小东西，不驱动整个画面。** 低频重击让光源亮一下，高频让星星闪，只取最强的那些击。每一拍都让整个画面跳动会很廉价。
- **黑场和静止是有意的一拍，不是填空。** 片头第一帧就要有画面。全片的黑场加起来通常不超过一两秒，除非歌曲本身在那里停住。

## 5. 在页面里跟着歌画

```js
import SONG from './out/song/songmap.js';
import { register, songAt, kf, ease } from '<kit>/kit.js';

const bar = (n, beat = 1) => {                   // 第 n 小节第 beat 拍的歌曲秒数（n 见 songmap.md 的 first bar）
  const d = SONG.downbeats, a = d[n], b = d[n + 1] ?? a + (a - d[n - 1]);
  return a + (beat - 1) * (b - a) / SONG.meter;
};
const T0 = bar(55);                              // 成片 0 秒对应的歌曲秒数；整首歌时为 0
const SHOTS = [                                  // 起止在小节线或第 3 拍上；长度不等
  { a: bar(55), b: bar(58), draw: room },
  { a: bar(58), b: bar(59, 3), draw: throughWindow },
  { a: bar(59, 3), b: bar(60), draw: closeUp },
  // …
];

function seek(t) {
  const s = T0 + t;                              // 歌曲秒数
  const m = songAt(SONG, s);                     // beat, bar, section, energy, kick, snap, line…
  const shot = SHOTS.find((x) => s >= x.a && s < x.b) ?? SHOTS.at(-1);
  shot.draw(s, m);                               // 例：灯的亮度 *= 1 + 0.4 * m.kick
}
```

`songAt` 返回：

- 拍和小节的序号与相位（0–1）；
- 当前段落和段内进度；
- 平滑后的响度、低频、高频；
- 低频重击的衰减脉冲 `kick` 和高频的 `snap`；
- 正在唱的那句歌词 `line`。

节奏型动作（每八分音符亮一颗星）用拍点数组算，不要用 `t * BPM`。

成片要截取一段歌时，先用 `ffmpeg -ss <T0> -t <时长>` 裁出音频，加很短的淡入淡出，再交给 `render.mjs … --audio`；审片时给 `shotlist.py` 加 `--offset <T0>`，否则切点会按成片秒数去对歌曲的拍点。整首歌用下面的原声合片。

## 歌词字幕

MV 默认带歌词字幕，观众也这样期待。

1. **文字。** 用用户给的歌词或官方歌词。`songmap.py --lyrics` 每次都会重写 `lyrics.draft.srt`：时间来自转写，文字是草稿，一条是转写的一段，可能含几句。把它复制成 `lyrics.srt` 再改：逐句对照正确的歌词改文字，保留时间；一条里有两句就按 `songmap.json` 里逐词的时间拆开，转写漏掉的句子照逐词时间补上，写着 `(repeated, check by ear)` 的条目一定要改。用户没给歌词、自己又核对不了时，向用户要。
2. **译文。** 外语歌在原文下一行加中文译文。译意思和语气，不逐字译；译文和原文同进同出。
3. **转成时间表。** `node <kit>/captions.mjs out/song/lyrics.srt lyrics.mjs`。截取一段歌时加 `--from <T0> --to <T1>`，时间就从成片的 0 秒算起。字幕只取这个 `lyrics.mjs`，不用 `songAt` 返回的 `line`，那是没改过的转写。
4. **样式。** 全片一个位置（通常在画面下方三分之一内居中），一种字体；原文不小于画面高的 1/24，译文不小于 1/30；浅色字加柔和阴影，字后面垫一团边缘透明的淡暗晕（下面的 `::before`），白枕头、亮天空上也读得清，但不加底框。每句在自己的时间里淡入淡出（各约 0.15 秒），淡出在这一条结束前完成，下一句再进，前后两句不会叠在一起。间奏里不留字。主体经过字幕区时，调构图让开，不要把字幕挪来挪去。
5. **片头。** 可以在第一句之前用一两秒小字给出歌名和演唱者（照任务单里抄的来源写）。
6. **片尾署名。** 照任务单里抄的来源写，放在画面上没有别的字的地方。

原文和译文要分别设字号，所以按换行拆成两个元素：

```html
<div id="lyric"><div id="lyric-en"></div><div id="lyric-zh"></div></div>
```

```js
import cues from './lyrics.mjs';
const [box, en, zh] = ['#lyric', '#lyric-en', '#lyric-zh'].map((s) => document.querySelector(s));

function drawLyrics(t) {                       // 在 seek(t) 里调用；t 是成片秒数
  const cue = cues.find((c) => c.start <= t && t < c.end);
  const [a = '', b = ''] = cue ? cue.text.split('\n') : [];
  en.textContent = a;
  zh.textContent = b;
  const edge = cue ? Math.min(t - cue.start, cue.end - t) : 0;
  box.style.opacity = Math.min(1, edge / 0.15);   // 0.15 秒淡入，结束前 0.15 秒淡出
}
```

```css
#lyric { position: absolute; z-index: 1; left: 0; right: 0; bottom: 9%; text-align: center; color: #f4efe6;
         text-shadow: 0 2px 14px rgba(0, 0, 0, 0.8), 0 0 4px rgba(0, 0, 0, 0.6); }
/* 字后的暗晕。z-index: 1 让它留在画布之上、文字之下 */
#lyric::before { content: ""; position: absolute; z-index: -1; left: 50%; top: 50%; width: 73vw; height: 22vh;
                 transform: translate(-50%, -50%);
                 background: radial-gradient(closest-side, rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.28) 55%, rgba(0, 0, 0, 0)); }
#lyric-en { font-size: calc(100vh / 22); }
#lyric-zh { font-size: calc(100vh / 28); opacity: 0.85; margin-top: 0.3em; }
```

字幕是给观众读的，不替画面讲故事：画面已经演出那一刻，字幕只让人听清唱了什么。

## 6. 先做最难的一段，再铺开

1. 先做一个 8–12 秒的有声小段。它要包含全片最关键的转换，通常是进入第一次副歌的那几小节。
2. 渲染带声音的视频，从头看到尾。再用 `strip` 看切点前后几帧。
3. 定下美术和镜头语言，再按段落表铺满全曲。
4. 铺完以后，按每个段落中点各取一格做联系表：`--times` 填段落中点的秒数。看全片是否在发展，有没有两段长得一样，每一格是不是故事里不同的一刻。

## 7. 审片

先关掉声音、不看字幕看一遍；看不了视频时，按每个段落中点做联系表（`--times`），逐格写下观众此刻看到他在经历什么，和第 2 步对照：每一段对应的那一刻到了吗？戳人的句子那几镜里，有第 2 步写下的那件物件或动作吗？高潮落在人的心情上，还是落在道具和奇观上？全片有几个场景，每个回来了几次？同一个场景回来而故事没有往前走，是内容不够，不是剪辑的问题。

然后跑镜头表：

```text
python <kit>/shotlist.py out/film.mp4 --song out/song/songmap.json              # 截取的一段：加 --offset <T0>
```

它列出每个镜头的起止和长度，以及镜头长度的分布，并标出这些情况：

- 连续同样长度的镜头；
- 一半以上的镜头同长（说明剪辑在走网格，没有跟歌）；
- 切到近景时只放大了上一镜；
- 黑场和白场；
- 超过 2 秒几乎不动的段落；
- 偏离拍点超过 120 ms 的切点，以及切点和拍点的中位距离。

被标出的每一条，要么改掉，要么在任务单里写下为什么故意这样做。然后带声完整看一遍，再看段落联系表。

## 常见问题

| 看到的 | 原因 | 改法 |
|---|---|---|
| 每 4 秒一切，从头到尾 | 镜头表按固定网格排 | 按段落表排，长度随段落力度变 |
| 所有切点都早或晚两百多毫秒 | 用 BPM 从 0 秒推算拍点，没有用实际的第一拍 | 用 `songmap` 的 `beats`/`downbeats` |
| 画面和歌词无关，换首歌也能用 | 只按情绪选了氛围素材 | 回到第 2 步，给戳人的句子设计画面 |
| 画面很美，听众却不难过也不心动 | 没写谁在听、疼在哪里；把标题的比喻造成了道具（机器、宫殿、星空奇观），人的生活没进画面 | 回到第 2 步，给歌里的人一段具体的生活，比喻留在歌词里 |
| 画面很美，却和歌的意思拧着 | 只读了情境，没读唱的人的态度；把遗憾拍成了团圆 | 回到第 2 步第 7 条，让高潮和结尾落在歌手的态度上 |
| 同几个镜位来回切 | 内容设计里的时刻太少，只好拿同一组画面填满整首歌 | 每一段写成故事里不同的一刻，再排镜头 |
| 没有歌词字幕 | 以为歌词不能放进成片 | MV 默认带字幕，见[歌词字幕](#歌词字幕) |
| 灯光和画面每一拍都在跳 | 用了全部 `hits` | 用 `accents`（`songAt` 的 `kick`/`snap` 默认就是），只让一两样小东西响应 |
| 副歌三次长得一样 | 复用了同一组镜头 | 同一主体，换尺度、光线或关系 |
| “新镜头”只是放大上一镜 | 用缩放代替切镜 | 换角度，加新细节，或让主体做下一件事 |
| 一段画面长时间不动 | 动作做完后没有后续 | 相机、光和环境继续动，或提早切 |
| 大段黑场 | 用黑场填补没想好的段落 | 给这段一个画面，黑场只做有意的一拍 |
| 颜色和别的片子一模一样 | 照搬了示例的调色板 | 从这首歌的情境里取颜色 |

## 已有的 MV 示例

- [《最后一盏灯》](../examples/last-light/brief.md)：器乐，手里只有一段录音时怎样用歌曲地图。镜头切在 `downbeats` 上，对岸的窗随重音亮、随桥段的钢琴音灭。拿到别人的歌，从这个工程改时间和切点的代码；内容和画面按第 2、3 步重新设计，不要沿用它的湖、星空和银河。
- [《纸鸟》](../examples/sung-mv/brief.md)：原创演唱，逐字的音高和时值。可以听两句“飞呀”之间画面远近怎样变化。
- [《回潮》](../examples/music-film/brief.md)：器乐。看同一个圆在旋律重现时怎样换拍法。

自己写歌、没有录音时，演唱合成见 [voice.md](voice.md#原创演唱)，配乐用 `sound.js`（[sound.md](sound.md)）。

## 整首原声交付

总帧数由完整录音的实际长度决定。先在 `songmap.md` 的段落表旁边写下每段观众会新看到什么，前奏、间奏和最后的余音也各自要有画面。然后用开头、一次中段副歌和结尾各做一个小段，连起来看能否看出发展，再补齐中间。

从任意渲染器导出与歌曲等长的画面，再合入完整原声。命令按一帧的容差核对两者时长，确认输出确实包含整首歌。AAC、MP3、ALAC 直接复制原音频包，其他编码转成 AAC 一次。

```text
python <kit>/mux_original.py out/picture.mp4 media/song.m4a out/film.mp4
```
