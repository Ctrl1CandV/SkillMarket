# 运动、镜头与节拍

## 时间只由 t 决定（严禁 CSS 过渡与关键帧动画）

- 用工具包时，场景实现成 `seek(t)`。给定时间 `t` 就能立即算出这一帧所有元素的位置、缩放、透明度和颜色；**严禁在 DOM/SVG 上使用 CSS `transition`、`animation` 或 `@keyframes`**（无头截帧器默认关闭浏览器动画，且任意跳序取帧时 CSS 过渡会失效卡死）。选用带种子的 `rng(seed)`，需要逐帧变化时从帧号取种子；视频纹理等有内部时钟的素材也按同一 `t` 定位。
- 把跨画面、声音和字幕共享的时刻集中定义，例如 `const T = { reveal: 4.0, focus: 9.0, … }`。内有细分的动作直接用镜头的局部时间计算。
- 连续量用关键帧轨道（`kf(t, [[t0, v0], [t1, v1, ease]…], log)`）。大跨度缩放、高度这类跨数量级的量设 `log = true` 在对数空间里插值。

## 连续镜头与剪切

- **按叙事关系选切还是连**：需要强调同一对象跨尺度或因果连贯时用连续推拉；需要时间省略、视角反转或干脆利落的信息推进时，**直接硬切或局部特写裁切往往比花哨转场更有力**。
- 现有示例里的不同镜头结构（各属其题材，勿当成固定套路）：
  - [sky](../examples/sky/brief.md)：山谷 → 上摇太阳 → 沿光线推进空气微观分子 → 拉回日落 → 升入太空看臭氧层（服务于跨尺度物理机制）；
  - [product-spot](../examples/product-spot/brief.md)：舞台时间牌 → 后台旧纸质台本 → 正视软件操作与局部特写 → 导出新台本（靠题材物件硬切串联，不用穿屏）；
  - [promo](../examples/promo/brief.md)：群聊 → 设备入场 → 穿入屏幕看关系图 → 拉回结清盖章（服务于“外部混乱收敛进应用”的单一卖点）。
- 平稳推拉可试 `ease.inOut`；穿越式推进试加速曲线 `x²`。要读界面、公式和数据时，让镜头和指针先停稳再展示变化。

## 转场：让形状、位置或动作接上

| 转场方式 | 做法与工具 | 要点 |
|---|---|---|
| **直接硬切 / 动作顺接** | 在重拍、唱词起音或手部/指针动作落定那一帧直接切换景别 | 最耐看的主力做法；切入近景必须给出远景没有的新细节，不能只把上一镜放大 |
| **版面几何遮罩（`wipe` / `iris` / `halftone`）** | `kit/graphic.js` 从焦点位置打开圆环或扫过斜色块 | 打开一半时下一镜的主体已就位，上一镜文字提前退净 |
| **穿入/拉出屏幕（可选）** | 用 `kit/stage.js` 的 `throughScreen(k, screenRect, viewport, { borderRadius, pose0 })` 对数放大并在切前展平倾角 | 自动扣除圆角安全内接框，确保切前绝不露出设备黑边；屏幕底色须与下一镜底色一致；拉出时内景随屏幕同比例缩小淡出 |
| **先原地形变，再沿弧线移位** | `kit/stage.js` 的 `morphMoveRect` 或两段 `seg()`（先改尺寸/样式，再位移） | 变形与飞行同时进行会糊成一团；先原地变清楚再飞向目标 |
| **跨尺度匹配** | 选好缩放锚点，让下一镜轮廓从上一镜同一位置长出（如地平线接地球弧线） | 锚点不对齐会凭空跳出怪异图形 |

选能实现当前用途的转场。直接剪切、声音提前进入、匹配剪切、叠化、移动镜头都有各自的时机。镜头间要交给观众比较的东西足够稳定时，剪切就可以完成这件事。画面过渡可以试着只让物件、色面或背景叠化，观察文字和关键轮廓是否容易识别。

字幕、标签、画面和声音在同一点切可先用同一个时刻。做有意的声画错开或文字延后时，把先后关系也写进分镜。两个镜头的标签意外叠在一起时，可以把标题设为直接切换，或等上一句淡完再入场。

## 缓动与时长

| 用途 | 曲线（kit.js 的 `ease`） | 可试时长 |
|---|---|---|
| 入场 | `out` = bezier(0.16, 1, 0.3, 1) | 0.4–0.6 s |
| 出场 | `in` = bezier(0.7, 0, 0.84, 0) | 入场的 60–75% |
| 镜头与移动 | `inOut` = bezier(0.65, 0, 0.35, 1) | 0.8–2 s |
| 数字滚动 | `inOutSoft` | 1–1.75 s |
| 弹出（气泡、节点、金额） | `spring`，刚度 220–320、阻尼 14–18 | 自然停 |
| 实物落位（手机升起） | `spring`，刚度 120、阻尼 17 | 约 0.8 s |

- 节拍型片子的元素可按半拍或十六分音符逐个出现；要读懂每项时，节奏由实际阅读所需的时间决定。
- 冲击可以有短衰减抖动，例如振幅 `14·e^(−14·Δt)` px，用帧号确定方向。文字和界面可固定在画幅上，或等镜头安定后再出现。
- 高潮前可试短暂停顿。读字、观察证据、等实际回应、看人物迟疑也是保留静止的理由，用实时播放判断停留长短。

## 字幕

- 需要遮罩入场时让文字从 `.ln { overflow: hidden }` 中升起，里面的 `span` 从 `translateY(105%)` 移到 0；可试 0.55 秒 `out`，多行之间错开 0.12 秒。持续可读的普通字幕也可以直接切换。
- 遮罩要留出内边距，再用负外边距抵消：`padding: 40px 80px; margin: -40px -80px`。否则文字阴影会被切出硬边，编码后看得到一个方框。
- 同一位置上的两句字幕要能分辨，可直接切换或等上一句退出再进。有歌词、翻译、说话人等多条字幕需求时，给每条字幕自己的位置，避免覆盖关键主体和操作反馈。
- 片头标题可以试短时模糊，入场结束把 `filter` 设回 `none`。留足清晰可读的时长，把叙述字幕的效果降到当前需要。

## 节拍网格

由音乐驱动时，先听段落、拍点和重音。现成歌曲先跑 `songmap.py`，切点取它给出的实际拍点和小节线，不要从 0 秒按 BPM 推算（歌曲的第一拍很少正好在 0 秒），见 [MV](music-video.md)。自己用 `sound.js` 合成、从 0 秒起拍的配乐才可以用拍号换算，比如 120 BPM 的四四拍里一拍 0.5 秒、一小节 2 秒。考虑为什么在某一拍切、为什么有一句要跨拍，避免所有镜头同样长。

- [promo](../examples/promo/brief.md) 把大的切换放在小节重拍（4.0、10.0、22.0 秒），忙乱段逐渐加密（0.5 → 0.25 → 0.125 秒），总时长取 14 小节。
- MV 可以让一组反复出现的镜头跟着乐句变化，间隔插入完整的长镜头。紧接休止时，保留上一动作的尾声或空画面都能改变力度。
- 旁白驱动的段落以实际说话时长和物件动作定点，观众需要观察、阅读或跟做的位置留出空间。音乐的进出也可以在词尾或动作结束后。

无节拍的氛围段可以按空间与听觉变化分段，例如在开门时让环境音先出现，镜头再经过门缝。安静、黑场和静止可以是分镜的一部分。用正常速度看它们有没有改变注意力或情绪。
