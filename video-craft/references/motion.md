# 运动、镜头与节拍

## 时间只由 t 决定

- 场景实现成 `seek(t)`：给定时间，算出这一帧所有元素的位置、透明度和颜色。不用 CSS 动画和过渡，不读 `Date`，不用 `Math.random`；随机数用带种子的 `rng(seed)`，需要逐帧变化的就用帧号作种子。
- 所有时刻写成常量，集中放在一处，例如 `const T = { reveal: 4.0, push: 9.0, … }`。声音事件、字幕和画面都从这里取时间。
- 连续量用关键帧轨道（`kf(t, [[t0, v0], [t1, v1, ease]…])`）。缩放、高度这类跨数量级的量在对数空间里插值。

## 一条相机路线

- **同一个模型，画两种细节**。近景画人和收银台，远景画格子里的点。拉远时按缩放比例在两种画法之间交替淡入淡出，就成了一个连续镜头，不需要额外的转场规则。
- **跨尺度的推拉代替翻页**：

  | 片子 | 镜头路线 |
  |---|---|
  | 天空 | 山谷 → 上摇到太阳 → 沿光线推进到空气内部 → 拉回天空 → 延时到日落 → 升入太空 → 俯冲回山谷 |
  | 宣传片 | 群聊 → 手机 → 推进屏幕看关系图 → 拉回手机 → 印章 |

- 镜头运动用 `ease.inOut`；穿越式的推进用加速曲线（`x²`），让速度在穿过的那一刻最快。

## 转场：让形状接上

| 转场 | 怎么做 | 要点 |
|---|---|---|
| 推进穿过屏幕 | 手机以屏幕中心为原点放大到约 6.6 倍，同时转正、移到画面中心；屏幕底色铺满画面后，下一个画面才出现 | 推进要在新画面出现前完成，否则会看到手机边框；两边底色必须相同 |
| 从屏幕里拉出 | 新画面跟着屏幕同比例缩小，同时淡出；屏幕里的新内容稍后淡入 | 不要先撤掉全屏画面再缩手机，边框会隔着半透明画面透出来 |
| 拉远换尺度 | 选好缩放中心，让下一镜的关键轮廓从上一镜的同一位置出现：地平线变成地球顶部的弧线 | 不对位时会凭空冒出一个怪圆 |
| 亮暗切换 | 浅色层用 `clip-path: circle(r at x y)` 从主体中心扩散，0.55 秒，`inOut` | 新主体等亮色铺开大半再弹上来 |
| 变形后移动 | 先原地变形（聊天气泡变成白色票据，0.4 秒），再飞到目标位置（0.6 秒，逐个错开 0.125 秒） | 变形和移动同时进行会糊成一团；目标位置用 `getBoundingClientRect()` 实时读取，带三维倾斜也准 |
| 示意图进场 | 从上一镜的形状里拉出来；画面一角注明示意 | 不要硬切 |

一部片子用 2–3 种转场就够了，方向保持一致。

## 缓动与时长

| 用途 | 曲线（kit.js 的 `ease`） | 时长 |
|---|---|---|
| 入场 | `out` = bezier(0.16, 1, 0.3, 1) | 0.4–0.6 s |
| 出场 | `in` = bezier(0.7, 0, 0.84, 0) | 入场的 60–75% |
| 镜头与移动 | `inOut` = bezier(0.65, 0, 0.35, 1) | 0.8–2 s |
| 数字滚动 | `inOutSoft` | 1–1.75 s |
| 弹出（气泡、节点、金额） | `spring`，刚度 220–320、阻尼 14–18 | 自然停 |
| 实物落位（手机升起） | `spring`，刚度 120、阻尼 17 | 约 0.8 s |

- 列表项逐个出现时，间隔取 0.1–0.125 秒（120 BPM 的十六分音符）。
- 冲击之后加一点衰减抖动：振幅 `14·e^(−14·Δt)` px，用逐帧的随机数做方向。混乱段的抖动随时间增强。
- 高潮之前留 0.3–0.75 秒的静止。

## 字幕

- 每行文字从一个遮罩里升起：`.ln { overflow: hidden }`，里面的 `span` 从 `translateY(105%)` 移到 0，0.55 秒，`out`；多行之间错开 0.12 秒（标题可错开 0.5 秒）。
- 遮罩要留出内边距，再用负外边距抵消：`padding: 40px 80px; margin: -40px -80px`。否则文字阴影会被切出硬边，编码后看得到一个方框。
- 下一句等上一句完全退出（0.3 秒，`in`）再进。两句交叉淡化会叠在一起。
- 标题入场可以带 6 px 以内的模糊，结束时把 `filter` 设回 `none`；叙述不加模糊。

## 节拍网格

有节拍音乐时，先定 BPM，再把所有时刻写成拍的倍数。120 BPM 时一拍 0.5 秒，一小节 2 秒。

- 大的切换和冲击放在小节重拍上（4.0、10.0、22.0）。
- 逐个出现的元素放在半拍或十六分音符上。
- 混乱段的节奏越来越密：0.5 → 0.25 → 0.125 秒。
- 总时长取整数小节：28 秒等于 14 小节。

没有节拍的氛围音乐也给全片定一个慢速的网格（例如每 0.84 秒），旋律音落在网格上，画面的关键时刻尽量靠近网格。

## 开头与结尾

- 第 0 帧就有标题和主体；首屏元素的入场时间可以设成负数。
- 每段开头 0.5 秒内必须有东西在动或出现，不要留空。
- 结尾卡停 2–3 秒，保留一点缓慢运动，例如 4% 的推近；声音在最后 1.2–1.4 秒淡出。
