# 声音

## 声音讲同一件事

- **把规律变成声音**。天空那一片里：
  - 每种颜色对应一个音高，红色最低，紫色最高；
  - 白光是六个音同时响，光被拆开时六个音依次弹出；
  - 日落的光束丢掉蓝光时，高音逐个消失，最后只剩红色那个低音；
  - 散射段的蓝光每弹开一圈响一声，红光的音量是蓝光的 1/5.9。

  观众即使没注意到这些对应，也会觉得声音“对”。
- **音乐的结构跟着叙事走**。宣传片里：
  - 开头的鼓被低通滤掉一半，消息提示音越来越密；
  - 画面变亮的那一拍，鼓组全部进来；
  - 揭晓核心卖点时停一小节鼓，只留和弦和逐拍上行的音；
  - 卖点揭晓完，鼓组回来；印章落在重拍上。
- **动机回收**：开头问题处的旋律（A–D–E–F#）留一个没走完的尾巴，到结尾补完。

## 一张时间表

场景页导出事件表，配乐只读这张表：

```js
// scene.js
register({ …, meta: { events: [{ t: 4.0, type: 'reveal' }, { t: 15.0, type: 'bold', k: 0 }, …] } });
// score.js
function score(m, events, duration) { for (const e of events) switch (e.type) { case 'reveal': impact(m, m.sfx, e.t); break; … } }
install(score, { reverb: 0.2, irSec: 2.4 });
```

事件里带上声音需要的参数：序号（决定音高）、屏幕横坐标（决定声像）、颜色、持续时间。改了画面的时间，声音自动跟着改。

## 两种配乐

| 类型 | 适合 | 做法（kit/sound.js） |
|---|---|---|
| 氛围型，无鼓 | 科普、自然、宇宙 | `warmPad` 和弦随段落变化，`tone` 做低音，`piano` 做稀疏旋律，`wind` 做环境底噪；混响时长 3–3.5 秒 |
| 节拍型 | 宣传、产品、快节奏 | 120 BPM：`kick` 每拍一下、`clap` 落在第 2、4 拍、`hat` 打反拍、`bass` 按十六分音符的切分型、`pluck` 做琶音；铺底和弦随底鼓侧链压低（每拍压到 0.35，0.24 秒恢复）；`riser` 放在进鼓之前，`crash` 放在进鼓那一下 |

和弦用简单、明亮的进行：I–V–vi–IV，或者 Imaj7–IVmaj7–vi9。铺底的低通截止设在 900–1600 Hz，免得刺耳。

## 音效词汇

| 画面事件 | 声音 |
|---|---|
| 元素出现、弹出 | `pop`（音高随序号上行） |
| 界面点击、计数 | `tick` |
| 揭晓、成功、打勾 | `chime` / `pluck`，音阶上行 |
| 镜头移动、飞入 | `whoosh`（推进时频率由低到高，拉出时由高到低） |
| 推进、升空、进鼓之前 | `riser` |
| 盖章、落地、画面翻转 | `impact`，可加 `crash` |
| 下落、减弱 | `glide` 下行 |
| 场景的底噪 | `wind`（换中心频率就能做室内底噪） |

## 配音

1. 每句旁白一个文件：`vo/01.wav`、`vo/02.wav`……，与场景里的 `LINES[i].id` 对应。
2. 用 `node <kit>/vo.mjs vo vo/vo.js` 量出每段的长度。场景里 `import` 这份结果，用它生成时间线，每句之后留 0.3–0.7 秒的间隔。
3. 在 `score.js` 里用 `voice(m, t, id)` 把每段放到对应的位置，再用 `duck(m.music, 说话区间, { depth: -9 })` 在说话时压低音乐。
4. 渲染和检查时都加上 `--vo vo/`。

配音来源：用户提供的录音，或者 TTS 服务。浏览器的 `speechSynthesis` 在无头环境里通常没有可用的声音（`doctor.mjs` 会显示）。有配音时，音乐比人声低 15–20 dB，屏幕文字只留关键词和数字。

## 听不到也能混音

用 `mixcheck.mjs` 画出音乐、音效、人声和总混音四条瞬时响度曲线，再叠上事件线。读图的规则：

- 关键音效（揭晓、冲击、打勾、要表达的那个声音）在事件处比音乐高 3–9 dB。界面点击这类短促的声音，曲线上至少和音乐持平；它们只有几十毫秒，在 400 毫秒的窗口里会被平均掉。
- 想让音效更突出时，优先在那一段压低音乐（ducking，约 4 dB），而不是一味加大音效。
- 有人声时，人声在说话区间里始终是最高的那条线。
- 峰值因数是原始峰值减去原始积分响度，要控制在 16 dB 以内。超过就说明有冲击音或底鼓太大，`audio.mjs` 的限幅器会把整段压扁，这时降低冲击音和底鼓。
- 曲线上不该有长时间的空洞（除非有意静音，比如太空段），也不该有贯穿全片的平顶。

`audiocheck.mjs` 能从成片解出声音，画出频谱和包络。用它确认事件线和起音对齐、低频不过满。贝斯根音放在 65–110 Hz，笔记本扬声器放不出 50 Hz 以下的声音。持续的长低音要比短音轻。

## 响度与格式

- `audio.mjs` 先把音轨归一到 −16 LUFS（BS.1770 积分响度），再用前瞻限幅器把峰值控制在 −1.5 dB 以下。发 B 站、YouTube 可以用 `--target -14`。
- 加 `--stems` 会分别报告音乐、音效、人声各自的响度和峰值。
- 输出 WebM（Opus）；`render.mjs --audio` 用流复制合进视频，目标是 `.mp4` 时转成 AAC。

## 常见问题

- `exponentialRampToValueAtTime` 的目标值不能是 0；工具包的包络已经加了下限，自己写的时候也要注意。
- 分轨静音要用总线之后的独立节点（kit 里的 `bus.mute`）。如果直接改总线增益，会和配乐里对这条总线的自动化冲突。
- 消息提示音这类频繁的音效要有变化：音高随序号上行，声像左右交替。
