# 轨道 A：课程、讲题与硬核科普制作指南

面向数学推导、工程物理与力学分析、计算机算法与系统机制、概率统计及定量科普。本指南把**工程底线、导演构思提问、无风格工具底座与开放视觉启发**分开——提供把画面、声音与推理做扎实的武器，但**绝不规定统一的版式或配色模板**。

---

## 一、动笔前的导演构思与讲稿设计

项目中有开工确认单（`docs/briefs/`）或用户明确提出风格倾向时，直接沿用。未指定时，动笔写渲染代码前先在 `brief.md` 与 **`scene.js` 顶部注释**定下三件事：

### 1. 本题专属导演三问（换一道无关题仍原样成立的空话不算）
- **核心视觉隐喻（盖住文字靠什么顿悟）**：写出本题让观众一眼看懂本质的具体动态画面——例如线性变换是“整张基向量网格被剪切拉伸时唯独特征方向箭头不转弯”；贝叶斯更新是“人群样本格按先验切分后再高亮假阳性与真阳性面积比”；状态机/协议是“时间轴推进到异常时刻切入收发信令实况”。
- **空间与时间组织（随内容形状生长，不锁死左右分栏）**：因为本题的对象关系如何，所以选哪种舞台组织？（居中全幅几何演化、上下时序对比、主图配推近/遮罩切入的全屏微观专场，或双区联动推演）。
- **学科气质与语义色**：定下贴合本题气质的底色与 **2–3 个严格绑定数学/物理含义的语义色**（同一变量跨图形、曲线与公式 `\id{key}{...}` 全程同色，不作无意义装饰）。

### 2. 按题材选叙事弧（不硬套单一八股）
- **直觉反差型**（适合极值、悖论、反直觉定理）：亮出错误第一反应 → 动态对照推演因果 → 收束适用边界或高频误区。
- **苏格拉底探案型**（适合组合推理、算法构造，见 [`worked-lesson`](../examples/worked-lesson/brief.md)）：摆出实验局面 → 留白短问 → 逐支排除与收敛。
- **具象到抽象型**（适合微积分、信号、连续科普，见 [`transit-map`](../examples/transit-map/brief.md)、[`sky`](../examples/sky/brief.md)）：真实场景或具体小算例 → 连续变形抽离出数学结构 → 给出通式与尺度感。
- **单一数据源**：所有坐标、函数值、状态序列与对比读数必须由同一个 `data.js` 计算导出，严核边界条件，绝不手写两套数字。

### 3. 有呼吸节奏的讲台口语（防蹦词电报腔与提纲报幕腔）
配音模型按单条 `cue` 规划整句呼吸：主体推演句宜写成 **35–75 个汉字（2–3 句主谓齐全、因果顺畅的话）**，同时**允许在开场悬念、转折提问或收尾定音处穿插 15–25 字的利落短句**拉出快慢层次（篇幅与总条数随内容复杂度自由决定）。

| 场景 | ❌ 破碎蹦词 / 提纲报幕腔（`narrate.py` 自动拦截） | ✅ 自然有呼吸感的老师口语 |
|---|---|---|
| **悬念起手** | `"线性变换矩阵特征值，方向不变，凭什么？"`（词组堆叠 + 噱头反问） | `"整张平面网格都被矩阵扯歪了，为什么偏偏有两条直线上的向量连方向都没变？"`（15–35 字完整设问钩子） |
| **过程推演** | `"网格划分，每次折半：一、二、四、八；误差收敛。"`（四字缩略 + 冒号顿号点名报数 + 短分号） | `"接下来我们把区间一轮一轮对半加密，从两段细化到四段和八段，可以看到折线围出的面积正稳稳贴近真实曲线。"` |
| **收束点睛** | `"两个坑：零特征值不可逆；重根未必能对角化。口诀：看秩看维数。"`（冒号报幕 + 对仗口号） | `"最后留心两处容易混淆的边界，一是只要出现零特征值矩阵就不再可逆，二是遇到重根时还得核对特征向量的个数够不够撑满空间。"` |

- **口播硬规范**：① 禁用三四字一逗的电报碎词与 `：一、二、四、八` 顿号点名报数串；② 禁用“凭什么？”“两个坑：”“口诀：”等报幕套话；③ 代码标识符（如 `max_len`、`delta_x`）在口播中说中文名称，小数与比值写准确汉字读法（如“零点六”“四比三”）；④ 有全片口播并挂载 `.srt` 软字幕轨时，**不在画面底部重复烧录黑底硬字幕**（无旁白纯画面科普或用户要求硬字幕除外）。

## 二、三条构图不变量（提下限，不限画风与版式）

无论选什么学科、配色或排版，成片必须同时满足以下三条结构不变量：

1. **主体统治力（严禁“多卡片网页后台”）**
   - 画面主角必须是**正在演化的核心图形**（几何构造、物理场、数据结构、天平/电路等），占据舞台主导视野；**严禁把画面切碎成 ≥5 个圆角信息框拼成监控看板**（`boardcheck.mjs` 会报 `card_soup` 警告）。
   - 当宏观全局图里需要讲清一个复杂局部机理时，**不要缩在角落画迷你框**——用 `cameraAt` 大幅推近，或用 `graphic.js` 的 `iris`/`wipe` 遮罩切入**全屏微观专场**讲透后再退回全局。
2. **同屏聚焦与有序清场（严禁公式与旧步骤堆积）**
   - 无论公式放在顶部、底部、侧栏还是居中画布，**同一时刻同屏展示级主公式严控 ≤ 2–3 个（字号建议 38–52 px）**。
   - 已完成使命的过渡式要么通过 `morphFormula` 原地平滑变形为下一步结论，要么随 `actAt(t, ACTS)` 干脆退场清净（图内短变量标注可传 `role: 'label'` 免计入主公式上限）。
3. **具象层次与尺度质感（拒绝裸线草图）**
   - 禁止在纯色底上只画两根单薄细线加 `opacity: 0.06` 半透明方块充数（`boardcheck.mjs` 会检查过低视觉密度）。
   - 核心对象无论手绘还是调库，都应具备三层完成度：**体量/材质层**（渐变、剖面斜线、阴影、网格或纸纹）+ **时间动态层**（运动粒子、扫掠轨迹、波纹、插值变形）+ **精确读数层**（标尺刻度、角度弧、实时状态值）。

## 三、开放视觉方向启发（按题材定调，严禁照抄单一示例）

**观看体验提示**：在没有发光轨迹、光学暗室或全屏专场明暗撞色等特定理由时，长时间跟读公式与几何推导**通常可优先考虑清晰明快的亮色画面**，阅读负担更轻、更接近精印讲义与板书；需要表现辉光、波包干涉或做节奏反差时，深色舞台更有张力。

下面五种方向仅作打开思路的起点（`kit/lesson.js` 已内置对应的 `THEMES.ivory / paper / blueprint / chalk / slate`，且**所有原语均支持传入任意自定义语义配色对象**）：

| 视觉方向思路 | 适用题材启发 | 色彩与质感关系（可自由变奏） |
|---|---|---|
| **清透现代讲义（`ivory` 或纯白系）** | 微积分、线性代数、概率统计、通用课程推演 | 象牙白/冷白底 + 极淡坐标细网 + 墨黑主字 + 钴蓝/琥珀/绯红语义色，留白充足、边缘利落 |
| **暖纸学术图解（`paper` + `graphic.js`）** | 离散算法、系统时序、拓扑与数据故事 | 米白纤维纸纹 + 建筑细线分割 + 粗黑章节字配等宽编号 + 青绿/赭石克制强调 |
| **工程制图蓝图（`blueprint` 或浅灰制图）** | 理论力学、电路信号、计算机体系结构、几何公差 | 浅蓝灰制图纸底 + 工程标尺 `svgRuler` + 剖面斜线 + 深海蓝主线与朱红极值标记 |
| **石版粉笔黑板（`chalk`，见 `worked-lesson`）** | 组合数学、逻辑智力题、课堂一步步板书证明 | 墨绿石版底 + 象牙粉笔线 + 鹅黄/浅青手写感重点圈注，温和沉静不刺眼 |
| **暗场光学实验室（`slate`，见 `stem-lesson`）** | 几何与波动光学、电磁场、天体轨道、暗场机制专场 | 深海蓝黑底 + 局部聚光与 `#vc-glow` 光学辉光 + 高饱和发光轨迹扇 |

自定义任意学科配色与非分栏舞台只需几行（`resolveTheme` 会自动补齐面板、网格与明暗自适应暗角，不会出现白字隐形或纸面黑角）：

```js
import { resolveTheme, drawStageBackground, loadMath, compileFormula, drawFormula } from '<kit>/lesson.js';

const T = resolveTheme({
  bg: '#F7F9FC', panel: '#EDF2F7', ink: '#0F172A', muted: '#475569',
  accent: '#D97706', primary: '#1D4ED8', danger: '#DC2626', success: '#059669',
});
document.body.style.background = T.bg;
await loadMath();
const eq = compileFormula(measureHost, String.raw`\det(\id{A}{A - \lambda I}) = 0`, { size: 46, theme: T });
// seek(t) 内：drawStageBackground 会根据 T.bg 明暗自动采用轻柔纸面暗角 (0.05) 并绑定默认墨色
drawStageBackground(svg, T, { gridStep: 56 });
drawFormula(svg, eq, 960, 170, { anchor: 'center' }); // 居中顶部悬挂公式，下方全幅留给几何网格线性变换
```

## 四、固定音色人声 + 逐词同步与事件微音效

```bash
# 1. 先跑 doctor 探测环境与显卡负载：
node <kit>/doctor.mjs
#    - 显卡空闲（gpu.voxcpm15_safe === true）：本地离线 VoxCPM1.5 克隆声音卡（默认自动做口语流畅度检查）
python <kit>/narrate.py cues.json vo/ --voice teacher --style lesson --takes 2
#    - 显卡繁忙（gpu.busy === true，无人值守时）：
#      首选 CPU 跑本地 VoxCPM1.5（零显存占用、保住自然人声）：
python <kit>/narrate.py cues.json vo/ --voice teacher --style lesson --device cpu --takes 1
#      或改走零显存 Edge 语音快速合成（同样导出逐词时间戳）：
python <kit>/narrate.py cues.json vo/ --voice teacher --style lesson --engine edge

# 2. 传 '-' 无需手写乐谱页，直接把 vo/ 干声与场景 meta.sfx 合成为 -16 LUFS 音轨并导出软字幕：
node <kit>/audio.mjs index.html - out/audio.webm --vo vo/ --srt output/captions.srt
```

在 `scene.js` 中通过 `buildTimeline` + `TL.word(cueId, '关键词', fallbackRatio)` 把公式变形、高亮框、几何扫掠与微音效精准钉在说出口的那一瞬间。

## 五、`kit/lesson.js` 能力分层速查（区分「通用底座」与「可选模具」）

| 层级 | 函数 | 定位与用法 |
|---|---|---|
| **通用硬底座（任何画风皆宜）** | `loadMath`、`compileFormula`（支持 `\id{k}{...}`、`theme`、`role: 'label'`）、`drawFormula`、`morphFormula`、`highlightPart` | 离线 MathJax v3 SVG 出版级公式、子表达式语义着色、跨步弧线平滑变形、下划线/信号框聚焦 |
| **时间线与空间相机（通用）** | `buildTimeline`（`TL.word` 逐词锚点）、`actAt`（无重影分幕清场）、`cameraAt` + `applyCamera`、`makeCamera3D` | 词级声画同步、多阶段干净切换、2D 世界推拉摇移与 3D 透视投影 |
| **自适应舞台与排版辅助（按需）** | `THEMES` + `resolveTheme`、`drawStageBackground`、`drawChapterTitle`、`svgCard` | 亮暗自适应背景/细网格/光学滤镜、章节标题栏、信息读数牌（可不用卡片，直接在画布留白处排字） |
| **几何、函数与力学基元（按需组合或自绘）** | `svgAxes`、`svgPlot`、`svgRuler`、`svgArrow`、`svgMorphArrow`、`svgLocusFan`、`svgAngleArc`、`svgSurface`、`svgBlock`、`svgSpring` | 坐标系与动态函数曲线、工程标尺、矢量箭头与空中平滑移位、极坐标轨迹扇、剖面斜线、刚体与弹簧 |
| **专项参考模具（合题才借用，不合题请自绘）** | `svgMediaTank`（分层介质槽）、`svgStepColumns`（离散积木/柱状阶梯）、`svgNodeBox`、`svgArray`、`svgConnect` | 仅当题材恰好涉及双层介质、离散轮次计数、状态节点或一维数组指针时选用；遇到树、图、矩阵网格、电路、相图等题材请直接用 SVG/Canvas 原生绘制专属图形 |

## 六、快渲调优与交付前硬体检

1. **改稿用 `--draft`（`960×540@15fps`），交付必出 `1920×1080@30fps` 母带**。
2. **三项必过核验**：
   - `node <kit>/boardcheck.mjs index.html --every 3`：清零 `formula_crowding`（同屏主公式堆积）、`overlap`（文字公式碰撞）、`line_crosses_label`（无底衬实线穿字）、`margin_overflow`、`tiny_text` 与 `nearly_empty_frame`，并核查是否存在 `card_soup` 或 `low_visual_substance` 警告；
   - `node <kit>/render.mjs index.html stills out/stills <关键秒数>`：实际打开 `1920×1080` 静帧看主体比例、色彩层次与公式清晰度；
   - `python <kit>/shotlist.py output/final.mp4 --mode lesson` + `ffmpeg` 解码抽帧复核成片。
