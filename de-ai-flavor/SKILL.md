# 去 AI 味：剥掉机器习气，留住活人温度

把僵硬、表演化或冷冰冰的机器腔洗干净，换成主语明确、节奏错落、温度贴合场合的现代汉语。

**守事实，放手改表达**：原文的数字、单位、专名、否定、时态（将要/正在/已经）、阶段限定词（如“初测”“仅”“尚未”）及固定按钮文案原样留住，改写时不顺手补造新时间或新细节；至于空洞概念词、假二分骨架、每段拍桌金句、口号收尾和报幕起手，大刀阔斧拆掉重写，绝不照抄原稿句壳。

**去 AI 味绝不等于把所有文体洗成 37°C 冷淡白描**——先按载体定准温度：
- **报错 / 通知 / 规范**：冷峻干脆，直说状态与动作；
- **评论 / 评审 / 分析**：锋利实在，靠算账与真实处境立威，不靠段段金句表演；
- **口播 / 课程讲稿**：带讲台现场感，顺口可念，直面学生真卡点；
- **叙事 / 故事 / 情感**：留住烟火气、反差幽默与高潮张力，绝不把人物洗成等权重的动作录像机或办事流程。

## 一、有样稿时：先抓声线再动笔

提供作者原稿或样稿时，先抓四项特征照着写：
1. **起手与收束**：样稿第一句直接立规矩或抛现象，新稿也照样起手，不按材料条目先铺背景；结尾照同样劲道收住。
2. **句长与停顿**：看单句分句数及长短句如何交替。
3. **衔接方式**：看句间靠语序和承前省略直接咬合，还是留特定过渡词。
4. **人称与口语颗粒度**：样稿带鲜活口语与吐槽劲道（如“别一上来就……”“多半是……”）时，直接沿用同档颗粒度，绝不洗成温吞书面语。

## 二、两极 AI 习气与直接改法

| AI 习气 | 典型病灶 | 直接改法 |
| --- | --- | --- |
| **1. 虚词外壳与抽象主语** | “进行……的处理”“在……层面呈现出”“这一现象折射出”“被……所……” | 剥掉虚词壳，把真实的人、系统或对象放回句首，具体动词直接做谓语 |
| **2. 欧化长定语与连接词拐杖** | 名词前连套三层“的”字定语；句句挂“因此、然而、此外、与此同时、值得注意的是” | 拆成汉语流水短句；顺承与明显因果靠语序和承前省略咬合，只在真转折处留连词 |
| **3. 假二分、破折号瘾与卡片碎片** | “不是 X，而是 Y”“是 X，而非 Y”“与其说……不如说……”；频繁塞破折号；连贯文章切碎成连续 `**粗体标签：**` | 拆掉对称壳单线直说；连贯文章与讲稿用自然段推进，删去机械卡片小标题 |
| **4. 金句中毒与伪具体** | 每段结尾必甩警句反转（“连资格都没有”“习惯每天扫地”）；无真实数据时随手捏“第 12 页、47 个模块、20%”装细节 | **千字长文最多留 1–2 处短句定音**，其余段平实落到后果、条件或下一问；无数据时用真实处境写实，不编随机整数 |
| **5. 节拍器节奏与段尾微闭环** | 句句 20–30 字、段段等长；每段戴概括帽、末尾加“可见……”“只有当……才会……”复述扣题 | 长推演句后接 5–12 字短句定音；一两句说完的段独立收住；道理讲完立刻停笔 |
| **6. 播音员腔与报幕起手** | “你有没有想过……？”“听起来抽象？别急……”；用“先给结论：”“结论先说：”“先看一个具体的问题：”“压成一句话：”先报幕再说话 | 直接抛结论、对象或真卡点，删掉所有报幕冒号与廉价拟人；口播用自然口语（“不是”替“并非”） |
| **7. 冷 AI 流水账与客服/制作痕** | 叙事平铺“拧杯→点头→擦桌→办手续”等权重动作、抹平高潮；报错写成公关软文；正文混入“v3.1 新增、三栏布局” | 过渡事件 1–2 句快剪，把温度与笔力灌进主场景；报错直说原因与恢复动作；直接删去制作话语 |

## 三、执行路径与按需对照

**先看对应文体的长段对照**：处理千字评论、金句表演初稿、口播讲稿或冷淡叙事改写前，先打开 [跨文体范例与前后对照](references/exemplars.md) 看同类病灶怎么动刀；拿捏不同载体格式与篇幅时，查 [按用途选表达](references/genres.md)。

- **从零撰写**：先定温度与读者 → 第一句直接踩进核心问题或具体现场 → 用真实机制/推演推进（提对策时精简到 2–3 条，连同落地坑点写透，不退化成 5 条粗体清单）。
- **修改已有文本**：① 破结构与表演（拆假二分、砍段段金句、把加粗卡片融回自然段、压缩流水账过场）→ ② 顺句法与呼吸（剥虚词壳、放回主语、拉开长短句参差、贴合目标温度）→ ③ 快核原文数字、时态与阶段限定词（如“初测”“仅”“尚未”），不遗漏也不脑补。

## 四、交稿前 3 秒扫三处“一票否决区”

1. **扫第一句**：删掉任何报幕起手（“先给结论：”“结论先说：”“先看一个具体的问题：”“先把账算清楚：”）和万能背景铺垫，直接说正事。
2. **扫全篇骨架**：确认连贯文章、讲稿、评审里没有连续 `**粗体标签：**` 卡片，千字内破折号和反转短句克制稀少，无后半段反弹。
3. **扫首尾出口**：确认最后一段已删去“压成一句话：”“只有当……才会……”和任何尾注备注；**只输出可直接使用的成品正文**，从正文第一句起笔、最后一句结束（仅在用户明确要求审校或解释改动时例外）。
