# 用词复核表

这些词没有天然的“AI属性”。先确定它在这句话中承载了什么，再决定保留、解释、删去或重写。不按出现次数自动替换，不设跨文体禁词。

## 先复核功能

| 表达线索 | 要问什么 | 处理方向 |
| --- | --- | --- |
| 赋能、打造、抓手、底座、生态、闭环 | 是专业概念、作者原话，还是没有具体内容的赞美？ | 有材料就写动作与对象；概念准确则留；不要替成“助力”“加值” |
| 旨在、探索、证明、体现 | 是目的、研究动作、论证结果，还是虚抬意义？ | 保留真实含义；不把“旨在”改成已达成的结果 |
| 首先、其次、最后、因此、此外 | 是否帮助读者理解顺序或逻辑？ | 必要连接保留；连续模板起句且不承担关系时删 |
| 综上所述、总而言之、一句话总结 | 总结是否新增决策、复习重点或可执行任务？ | 空复述可删；保留有用小结与指定的正式格式 |
| 不仅……而且、不是……而是 | 两部分是否有真实递进或纠错关系？ | 有关系则留；若前半是凭空树立的对立，直接说后半 |
| 关键、重要、核心、本质上 | 是否随后说明它怎样影响结果？ | 用依据支持判断；必要提醒可留；不强迫每句都补理由 |
| 可能、通常、初测、仅在、未验证 | 是否分别限定概率、范围或证据？ | 独立限定保留；只合并同一层面的重复措辞 |
| 深入、全面、无缝、显著、颠覆 | 是否有明确程度或效果依据？ | 按证据写；主观评价别改成客观测试结论 |
| 据悉、专家认为、研究表明 | 材料是否包含可核对的归因？ | 用已有出处；不能编专家。普通未引文不等于无依据 |
| 好问题、当然可以、希望有帮助 | 是社交礼貌还是包住正文的固定套话？ | 独立产物删包装；对话可简短礼貌，不牺牲回答速度 |
| 先说结论、我直接说、说人话就是 | 是否只是宣布下一句话？ | 能直接给内容就直接给；有实际消歧功能时留 |

## 课程口播中的已确认例子

保留原意后按场景调整，不复制为全域替换规则。

| 原表达 | 可用说法 | 必须注意 |
| --- | --- | --- |
| 立六个全局约定 | 先说清楚这六条约定 | 数量以当前稿件为准 |
| 那句话的真实含义，用今天学的东西翻译 | 这句话的意思是…… | 后续解释不能丢 |
| 路线报一下 | 这节课先讲……再讲…… | 短稿可能无需报顺序 |
| 试图在脑子里构建这个画面 | 脑子里要有这样一幅图 | 实际需要看图时直接指图 |
| 先按现在的值办事，办完再加 | 先用当前值，用完再加1 | 仅限已确认语境；后缀自增不宜无条件扩展到所有复杂表达式 |
| 两套写法完全互通，你能自由翻译才算真懂 | 这两种写法要能互相改写 | 以确实等价为前提 |
| 回车的编号 | 回车的ASCII码 | 核对指的是CR还是LF，不能照词表误改 |
| 这一讲结尾一下 | 好，我们来小结一下 | 修搭配，不造新口头禅 |

旧表中的“%c不做任何跳过”不能作为无条件替换：单独的`%c`通常不跳过输入空白，但格式串中前置空白会改变读取行为。旧表中的“a是固定地址”也不能替代数组语义。风格表不能绕过技术核查。

## 需要解释时才改的专业词

- **统计口径**：可能指对象范围、去重方法、时间窗口或数据来源，按本句意思展开，不能一律换成“打分方法”。
- **接口**：程序接口保留；“导师接口”若实际说的是联系导师，就直接说联系。
- **宿主**：运行环境的技术词可留；公众说明按需要补“运行这个程序的应用”。
- **心智模型**：在认知或设计讨论中有专门含义；面向课程学生时可解释成“理解这个过程的一幅图”，不能随意改成“想法”。
- **切口、落点、双轨**：有明确对象时可用；无对象的口号改成实际问题、结果或两个并行事项。

## 格式不是词表

斜杠先辨认关系：并列改“和”，选择改“或”，比值、路径、网址、日期与代码保留。课件上的`O(n)/O(1)`是对比速记，若放进口播正文，需要分别说清两者。

破折号、加粗、表情、短标题、列表与表格按用途保留。用户或项目规定的格式阈值只在该项目适用，不扩为所有文本的字数或符号配额。

## 英文与中英混排

留意空泛使用的`delve`、`leverage`、`holistic`、`seamless`、`tapestry`以及“in today's fast-paced world”“Let's dive in”等套式开场。它们承担实际含义或作者风格时不机械删除。技术含义的`robust`、地理含义的`landscape`保持准确。

英文标点按目标文体处理；不把英文引号规则套到中文，不改连字符构成的固定术语、版本号、命令参数或标识符。中英术语重复使用同一名称，别为避免重复轮换出不同概念。
