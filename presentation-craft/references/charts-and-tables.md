# 数据图表与表格：选择和展示

用于**已有数据需要制作新图或新表**的页面。这里帮助决定用什么图、怎样组织比较和阅读，不讲数据清洗、统计建模或绘图库 API。先确定听众要判断什么，再选图；“图表种类多”不要求一份汇报用遍所有类型。

目录：选型索引 → 常见图的展示配方 → 放到幻灯片 → 表格 → 生成与检查。

## 先决定图、表还是组合

- **看形状、趋势、差异、分布或关系**：优先图；例如训练走势、方法的效率权衡、错误集中在哪些类别。
- **查精确数值、多个指标或条件**：优先表；例如主结果、消融开关、实验配置。表格不必为了“有图”再转成柱状图。
- **既要看规律又要核对数字**：主图配少量关键数值或紧凑表；完整表放附录。避免同页重复一整张图和一整张同数据表。

在源稿里简短明确“本页问题 → 数据能支持的比较 → 所选图/表 → 需要强调的观察”。这个决定通常由 AI 自己完成，不把选型菜单全部交给用户。

## 图表选型索引

| 听众要看什么 | 可选图形 | 选型与展示重点 |
| --- | --- | --- |
| 随时间、迭代或有序参数怎样变化 | 折线、阶梯线、带区间的折线、小多图 | 连线需要有序关系；保持真实横轴间隔，关键区段就近标注。类别无连续意义时用点图/柱状。 |
| 哪个类别/方法更高，差多少 | 柱状、条形、分组柱状、点图、棒棒糖 | 长方法名优先横向；类别多时点图更省空间。只有需要比较的系列才并组。 |
| 同一对象改变前后如何 | 配对点图、哑铃图、坡度图、差值图 | 保留对象/seed 的配对关系；差值明确参照，不能用均值掩盖方向不一致。 |
| 指标相对基准的偏离 | 发散条形、差值点图、森林图 | 基准线可见；点与区间分开表达估计和不确定性，不把误差线当装饰。 |
| 整体由哪些部分构成 | 饼图、环形、堆积柱/条、100% 堆积、树图 | 先核对分母与整体；少量份额可用饼/环，精确比较或跨组比较优先条形。 |
| 总量怎样一步步形成 | 瀑布图、堆积面积、累积曲线 | 瀑布用于有意义的增减分解；面积用于有序过程的构成，不用来精确比较中间层。 |
| 样本集中、离散和长尾怎样 | 直方、密度、箱线、小提琴、原始点、ECDF | 取决于是否有原始样本及样本量；少量运行优先直接显示点，不由均值捏造分布。 |
| 两个变量如何关联/权衡 | 散点、气泡、带拟合的散点、二维密度/六边形分箱 | 轴和单位清楚；气泡按面积编码并给尺寸图例。点多时用透明度、分面或密度，相关不等于因果。 |
| 哪些行列组合形成高值/低值 | 热力图、带数值的矩阵、混淆矩阵 | 行列有明确含义；色标与归一化口径可见，缺失不当零，比较页共享色阶。 |
| 两个参数共同怎样影响响应 | 热力图、等高线、响应面、切片小多图 | 看最优区域常用二维热力/等高线；需要解释曲面形状时用三维，保持参数与单位明确。 |
| 三个空间坐标或轨迹的关系 | 三维散点、三维轨迹、曲面/线框、二维投影 | 三维用于真实第三维；选择能看清关系的视角，遮挡时配投影或切片。 |
| 多组相同任务或条件怎样不同 | 小多图、分面图、对齐点图、紧凑比较表 | 保持图轴、类别顺序和标记一致；共享图例，按读图顺序排布。 |
| 方法间多指标的轮廓 | 对齐点图、归一化热力、平行坐标；必要时雷达 | 单位不同先解释归一化；雷达面积受轴顺序影响，不据此宣称综合领先。 |
| 关系、流量或空间位置 | 网络图、桑基、节点连线、地图 | 数据本身确有关系/流量/地理含义时选；限制可见节点并定义编码，不能用复杂度代替证据。 |

这些是候选，允许组合和其他图形。区分柱状图（类别比较）、直方图（连续分布分箱）与箱线图（分布摘要），不能只按外形命名或互换。用户称“热点图”时结合材料判断是否指热力矩阵或空间热点。

## 常见图的展示配方

### 趋势与折线

先让听众看清横轴、变化方向和当前讨论的阶段，再看方法差异。使用清楚的线宽、稀疏刻度和少量直接标签；方法以颜色加线型/标记区分，必要时在线末写名称。同一系列的线、点和图例语义一致，不保留相互冲突的默认配色。曲线过多先选关键对照，其余分面或附录，不缩成细线团。

非等间隔时间/参数按实际数值定位。普通 PPT 折线的类别轴可能把数值标签等距排列；这时选带连线的 XY 散点或其他能保留间隔的数值横轴实现，不能把分类标签当成连续坐标。缺测位置保留间断，不自动补零连线；平滑与原始曲线区分并说明。局部放大可作第二面板，但保留全局定位。折线轴可按数据范围取值，不能用未说明的截取夸大小幅变化。

### 柱状、条形、点图与配对

柱长承担数值编码时从零开始；若差异很小且零基线让比较困难，换点图、区间图或明确的差值图。不要为放大差异截断柱轴。自然顺序（时间、档位）优先，其余可按值或共同的基线顺序排；对照页不能各自排序导致方法位置漂移。

控制组与关注方法保持可分辨，避免每根柱都换颜色。组内留小间距、组间留更明显间距；长中文标签放横向，不依赖大角度倾斜。只给需要读到的值加标签。少量重复结果用配对点/原始点比均值柱更能暴露波动；只在确有依据时显示误差并注明含义。

### 热力图与矩阵

先选行列的含义、顺序与单元尺度，再选色标。强度/概率通常用顺序色；有明确中心的正负偏离可用发散色，并让该中心对应中性色。热力色阶承担数值含义，不把主题强调色机械铺满整图。

颜色条标出数值范围和单位；跨实验比较共用色阶，若范围不同必须说明。混淆矩阵标明真实/预测方向，以及计数、按行归一还是按列归一。小矩阵可加数值并按底色调文字对比；密集矩阵只标关键单元，或拆成可读子矩阵。缺失单元使用独立样式/符号并解释。不要把类别排序造成的“块状结构”当成新的统计结论。

### 三维、响应面与等高线

当三个空间坐标或两个参数加响应值本身需要共同理解时，三维散点、轨迹、曲面或线框是可选表达。普通柱状/饼图不靠添加透视、圆柱或厚度改善表达；这些效果会改变可感知的长度和面积。

固定能看清关键结构的视角和轴范围，坐标、方向、单位与色标完整；多页比较保持视角一致。遮挡、透视与深度难读时，配同范围的二维投影、等高线或切片。用颜色编码 z 时解释其与高度的关系，不再无意义地叠加其他编码。离散观测不能不说明地插值成连续光滑曲面；示意函数曲面要标“示意”，不称实验结果。

交互旋转只在实际播放环境支持时使用；静态 PPTX/PDF 本身应能支持结论，不依赖报告者临场拖动才看见证据。

### 饼、环形与构成

适用于非负份额、共同分母、完整且有意义的整体；类别少且有明显大份额时更容易讲。类别很多、份额接近或需要比较多个组时，优先有共同基线的条形或 100% 堆积条。

饼/环直接标类别和份额，保持稳定顺序与配色；不把多选比例或不同分母硬凑成 100%。避免透视、爆炸扇区和无意义厚度。环中央只放有用的总量/说明。堆积图中间片段缺共同基线，精确比较时拆成分组或小多图；组成比例和绝对总量不是同一问题。

### 分布、关系与不确定性

直方的分箱、密度的平滑、箱线的须和小提琴的估计都会影响读图，需要时在图注说明；跨组比较使用相同口径。小样本优先显示原始点及配对；不要仅凭一个箱体就推断统计显著性。ECDF 适合比较阈值以下的比例，长尾可考虑明确标识的对数轴。

散点先明确两个变量与比较对象，注释放在关注点旁，避免给所有点加重叠标签。拟合线不能被当成因果证明；气泡编码用面积而非半径。效果—成本图可标预算线或被支配关系，但“前沿”只限实际观测与当前比较集。

两种不同单位不自动意味着需要双纵轴；优先上下分面或分别呈现。确需双轴时两轴清楚标单位与系列，不调轴使两线人为重合，也不让这种视觉重合暗示相关。

误差棒/置信带、点区间和森林图适合展示估计与不确定性；注明中心统计量、区间含义和 n 的定义。多次 seed、数据样本和重复测量不能混为一个 n。缺原始样本或区间时如实说明，不为画得完整补造区间、箱线或小提琴。

## 让图成为可以讲的一页

- **主次面积。** 通常把约 65–80% 内容区给主图，剩余位置给直接支撑的观察；这是起点，不把横向长图硬缩进固定栏。标题说本页问题或有条件结论，图旁保留轴、比较条件和证据。
- **阅读入口。** 在需要先看的轴、阶段、阈值或重点类别旁标注。图内箭头、基准线或一处局部放大优先于右侧再列一整段复述数据的文字。注释不能遮住原始点、误差或图例。
- **颜色与层级。** 常规系列保持同义同色，关注对象适度突出，对照仍可辨认；类别用可区分色，连续数值用有序色阶，偏离中心用发散色。补充线型/标记，避免只靠红绿或浅色区分。
- **轴和标签。** 重要图内文字按最终幻灯片尺寸检查，通常从约 18–22 pt 起排。控制刻度数量、补齐单位、解释科学记数与对数轴；图例贴近图或用直接标签，不能比图本身占更多注意。
- **多图对照。** 共享轴范围、色阶、类别、比例与图例；需要不同范围时显式说明。大图加一个必要局部通常好过四个读不清的小图。小多图有共同问题时保留同构。
- **现场与静态。** 可先显示坐标/基线，再出现关注系列或注释；上下文保持稳定。不逐根柱子、逐个点播放无助理解的动画，静态版保留完整证据。

样式参数来自 [主题库](styles.md)，但数据的语义色和色阶优先于装饰配色。以 [图表样张](../assets/chart-gallery.pptx) 和 [总览](../assets/chart-overview.png) 比较常见呈现；它们使用演示数据，不可作为用户实验结果。样张只展示部分图型，不是全目录模板。

## 表格也需要选型

| 本页用途 | 表格组织 | 展示重点 |
| --- | --- | --- |
| 主结果与方法比较 | 方法为行，指标/数据集分组为列 | 先交代指标方向、单位与可比条件，再强调当前要讨论的少量单元。 |
| 消融与组件组合 | 组件开关/变体 + 结果 + 必要预算 | 符号有释义，保留完整模型与参照，不让一排勾号代替解释。 |
| 实验配置与公平性 | 任务/数据、设置、基线与当前方案 | 把差异与保持项区分开；完整配置进附录，关键条件留页上。 |
| 进展与配对实验 | 条件或 seed 对齐，前后值与差值相邻 | 保留配对和状态，区分未运行、失败与零；差值注明参照。 |
| 下一步与决策 | 问题、最小验证、判别信号/状态 | 每行支持一个可讨论决定，避免宽长段落和虚构进度。 |
| 属性与适用范围 | 对象 × 比较维度的文字矩阵 | 明确单元语义与例外，不把不确定性压成是/否勾号。 |

### 表格展示配方

1. **先定阅读方向。** 想比较方法就让方法位置稳定；数据集/指标分组表头简短清楚。不用复杂合并单元格隐藏关系，不为对称添加无意义列。
2. **按数据类型对齐。** 方法名与文字左对齐，数值右对齐或按小数点对齐；开关和状态可居中。同一列有效位数一致，单位优先放表头，保留对解释有意义的精度。
3. **靠间距建立结构。** 表头、组间留白和少量水平线通常够用。竖线、全格粗框、斑马纹按实际分组需要使用，不给每个单元加边框或渐变。列宽按内容而非机械等宽。
4. **控制高亮。** 可比组内用加粗标最优，必要时另标次优并给规则；也可只强调本页讨论的方法。两者选有用的一种，不把每个单元同时涂色、加粗、画框。最好值不自动意味着稳定优势或显著差异。
5. **就近解释口径。** `↑/↓`、单位、运行次数、区间/误差含义、不同设置组与重要限制随表可见；标准差、标准误、置信区间不能互称。`—`、未报告、未完成、失败和数值 `0` 区分，必要时给符号说明。
6. **密集表做取舍。** 先保留回答本页问题的指标和必要对照，完整表进附录。按指标组或方法组拆页时重复方法列、表头和条件；不删掉改变结论的基线/反例。仍太密可换差值图、点区间或热力图；不要靠缩字解决。
7. **与图配合。** 表承担精确值，图承担规律。正文页可只列关键数值并配清楚的图；不是每页同时塞完整表、完整图和三段解释。

## 从已有数据到可交付成品的边界

制作前核对字段、单位、分母、排序、重复/聚合口径和缺失；可视化不能修补不存在的数据。必要的聚合、归一化或筛选在源稿中可追溯，影响解释的部分写在图注。任务需要实质统计分析且材料不足时先解决这个缺口，不用美化掩盖。

普通线、柱、饼和散点等优先原生 PPT 图表，表格优先原生表格，保留实际数据与后续编辑能力。热力、分布和三维等可按可用工具选择原生形状或由数据绘制的矢量/高分辨率图；**代码根据数据生成再插入的图是有效路线**，不等于截图或用现成图片冒充数据。外部图需留数据和绘图源稿，并准确说明其在 PPT 中是图形资产，不能声称支持原生“编辑数据”。不要为了可编辑性牺牲必要图型或科学表达，见 [工具与运行](toolchains.md#数据图表的制作边界)。

检查最终输出时，先核对图中值/聚合与来源一致，再看尺度、色阶、图例、遮挡、文字与布局。原生图还要核对类别顺序、系列、缓存/嵌入数据与标签一致；对照页核对共享尺度。表格核对单位、精度、分组与高亮规则。看图和结构检查不能代替数据核对，细则见 [质量检查](quality.md)。
