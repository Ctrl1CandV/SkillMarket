# 内容与证据

## 选择讲述顺序

先确定听众听完后应理解、质疑或决定什么，再选择论证顺序。默认优先服务论文组会与自己的实验进展；下面是可调整的路线，不是固定章节模板。

| 场景 | 讲述主线与信息取舍 |
| --- | --- |
| 论文组会 | 问题与缺口 → 核心方法及为何可能有效 → 最有判断力的证据 → 局限 → 对本组的启发。背景只讲理解方法必需的部分，不逐节复述论文。 |
| 实验进展 | 上次问题 → 本轮改动与假设 → 设置及结果 → 能/不能下的结论 → 下一步决定。失败和未完成工作也可成为主证据，不包装成成果路演。 |
| 开题 | 研究问题与已有证据 → 缺口 → 可检验的研究问题/假设 → 拟采用的方法 → 验证方案、可行性与风险。计划和预期结果不能写成已完成贡献。 |
| 中期 | 原目标 → 已完成证据 → 偏离与障碍 → 调整后的研究范围及剩余验证。让进展与最初问题对应。 |
| 答辩 | 主问题 → 已完成贡献及证据 → 各贡献关系 → 可靠性与边界 → 总结与备份问答。按贡献组织，不按做事时间堆砌。 |
| 课程汇报 | 理解目标 → 必需背景 → 核心概念 → 推导/实例 → 比较和理解检查。知识讲清楚优先于制造创新主张。 |

“内容丰富”体现为证据完整和解释有层次。页面给出主旨与可观看的证据；完整设置、补充推导和问答放备注或附录。无需每套报告都有目录、章节页、三点总结或谢谢页。具体页面读 [学术版式](academic-layouts.md)。

## 用时决定取舍

先分开报告时间与问答时间，再按讲解难度估算每段用时，不套用“一分钟一页”。熟悉的背景可快速过渡，新机制、复杂图或公式需要更长解释；动画步骤也消耗讲述时间。

- 论文组会可从“问题与背景约两成、方法约三成、证据约三成、局限与讨论约两成”起步；理论论文可增加推导，方法熟悉时把时间给证据。
- 实验进展可从“目标与改动约两成、设置及结果约四成、解释与不确定性约两成、下一步讨论约两成”起步。8 分钟汇报不必补齐论文式章节。
- 用实际讲述复核预算。超时时先移走重复背景、次要数据与完整推导，保留支撑主结论的条件和证据。不能为了准时只留下醒目数字。

这些比例用于起稿，不是验收门槛；用户的议程与要求优先。

## 每页先有可讲的骨架

在工作笔记或源稿中用短句记录以下内容，再选择版式；无需把这些字段全部放上幻灯片。

| 字段 | 要回答的问题 |
| --- | --- |
| 作用与主旨 | 本页解决哪个问题？听众应带走的一句话是什么？证据不足时主旨可以是问题或不确定性。 |
| 必要条件 | 结论依赖哪个任务、设置、比较对象或适用范围？哪些条件必须留在页上？ |
| 证据与归属 | 用哪张图、哪组数据或哪段推导支持？来自论文作者、本组实验还是报告者解释？ |
| 读图路线 | 先看哪个轴/模块，再比较什么，最后注意什么？提示应靠近证据。 |
| 讲述与过渡 | 本页解释到什么程度、约用多久？下一页为何自然接着出现？ |

例如主结果页的路线可为“先确认纵轴与比较设置 → 比较主要方法 → 看误差和例外 → 得出有条件结论”。不是先读完所有图例再宣读标题。不要用长段正文代替读图路线。

## 材料处理

先读摘要、目录、图注/表注和用户笔记，再深读支撑核心结论的部分。扫描件、复杂公式或密集图表确有需要时再用 OCR 或专门解析；不默认把全文交给外部服务。已有宿主 PDF 工具可直接复用，无需再装论文解析 MCP。

明确区分“论文作者主张”“报告者理解/推测”“本组结果”和“待验证假设”。可能混淆时在页上用自然标签说明，如“作者实验”“我的理解”“本轮实验”“待验证”；不能把作者的提升写成本组成果，或把自己的解释写成论文证明。记录来源、页码/图号或实验文件；正文不需要每句话都脚注，关键数字和证据必须可追溯。正式报告不嵌入脚本路径等无关实现信息。

有用户要求清单时，在工作笔记里建立“要求 → 对应页面/备注”的映射，检查内容遗漏。没有精确页数要求时，给密集证据足够页面，不将详细要求压成同样的短摘要。

## 图表与数据

已有数据需要制作新图或新表时，先读 [数据图表与表格](charts-and-tables.md) 选择表达大小、趋势、分布、关系或组成的图型，以及表格的组织方法。图型服务本页判断，不以凑齐图种代替证据。

- 优先原图，或者由原始数据确定性重建。生成图只能承担概念说明，不能冒充实验数据、原图或精确系统结构。
- 选择最支持论证的图/子图。裁切后保留必要的坐标轴、单位、误差、图例、面板标签、样本数和比例尺；密集多面板图可拆页。
- 多面板图先以总览交代面板关系，再放大当前证据，最后回到本页结论；放大页保留面板编号与必要定位，不假定听众记得上一页。总览只是导航，不能拿看不清的缩图完成证据讲解。见 [多面板图版式](academic-layouts.md#09-多面板原图总览与局部)。
- 可获得原始值时，普通图表优先原生 PPT 图表；仅有论文图时保留清晰原图，不能反推或捏造准确数值。
- 尽量直接标注数据；同一类别保持颜色和顺序一致。不要因风格美化改变坐标比例、有效位数、统计含义或排序逻辑。
- 表格列头注明指标方向（如 `Accuracy ↑`、`Latency ↓`）与单位；可比组内再标最优/次优，不跨数据集、训练预算或不同设置挑选“冠军”。主指标适度加粗即可，不把每列都涂成彩色。
- 说明重复次数以及误差的含义（如 mean ± SD、SEM 或置信区间），区分独立运行次数与数据样本量。只有一次运行时写“单次运行”或 `n=1`，不编造标准差，不用 `±0` 假装稳定。原论文未报告时如实说明。
- 小幅差异不能单凭两个数认定稳定提升；说明目前支持的观察、仍缺的验证及可能混杂因素。百分点差与相对百分比变化分别表达，不混写。
- 标明“来源”“改绘自”“本实验”“示意”或“演示数据”等适当归属。模板不能被当成新的事实来源。

## 讲稿与修订

结论式标题适用于有明确结论的页；背景、提问和讨论页可用问题式标题。不要为了标题显得有力夸大结果或抹掉条件。

备注补充图表解释、逻辑转折和易被追问的限定条件，不逐字重复页面。名称、缩写、方法、数据集、符号和指标在全稿保持一致。局部修改时同时核对相关备注、页码和交叉引用。
